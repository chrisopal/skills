# 版本变化

## v1.2.0 — 2026-09-28

依据作者本轮语言偏好，增加自然、直接的专业中文规则；修订对象包括作者讲解、小标题、章末总结和评审报告自身。

- 核心Skill增加chapter-revision模式与表达规则入口。
- 新增neutral-professional-chinese.md，区分评价式导语、标题套式、价值总结与有效业务对比；明确不做统一同义词替换。
- 新增逐章意见模板与实际应用任务范本。历史实录、字段、代码与模态力度继续保护。
- 修改核心规则与评审模板中的“最值得保留”等同类指令，防止评语再次出现同样口吻。
- 盘点脚本增加有限字面检索项，仍不判质量、不自动改稿；增加6项确定性测试。
- 语义回归由24项扩展为40项，新增16项状态为not_run，未宣称模型评测通过。
- 配套逐章意见以当前正文定位原句，并纠正前版评语中串章或数量概括问题。

本次未修改原书，未在用户宿主导入Skill；候选句未经过独立模型A/B或真实读者试读。


## v1.1.0 — 2026-09-28

基于完整书稿审读修订，并非另一个模型独立A/B评测。

| 原版基础 | 全书试用暴露的问题 | 本版实际调整 |
|---|---|---|
| 已有book-audit模式、覆盖提醒 | 长稿规则只有简短原则，容易凭局部外推 | 连续审读、实际目录、覆盖台账、块类型统计 |
| 已有章节职责与语言规则 | 每章都能成立，整本仍重复；进阶内容挤进入门路线 | 新增学习点、主讲章与提醒章、按岗跳读 |
| 已有完成状态保真 | 前言与新增实操不同步；作者与工具、原版与修订混写 | 对象/动作/版本/执行者/时点组合核对 |
| 已有保留未知 | “更安全”可能扩大禁令，影响合法已授权工作 | 双向保真：不虚构批准，也不抹掉已知与许可 |
| 已有不改代码、路径 | 全长实录与读者练习的根目录混在一起 | 四种提示词身份、路径映射与原件保护 |
| 已有图文未审说明 | 可能将“这次没上传附件”判为整书缺配套 | 明确未提供/未读/明确缺失三种状态 |
| 已有移位规则 | 只从正文删掉记录却没有目标位置 | 保留迁移表，区分提出与执行完成 |
| 旧例描述PPT新增实操未完成 | 新全文已有部分实操，旧例可能污染新判断 | 历史示例加范围标识；新全文重新核对 |
| 8个短场景 | 缺全书状态、案例分支、跨章更新测试 | 扩展为24个语义回归场景；另有盘点脚本单元测试 |
