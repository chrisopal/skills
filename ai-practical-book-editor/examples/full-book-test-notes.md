# 本次全书试用：规则应当分清的几件事

来源：2026-09-28用户上传书稿。这里只记可重复的编辑问题，不附全文或带授权码链接。

| 观察 | 应怎样判 | 不能怎样判 |
|---|---|---|
| 总目录列三项附录，正文实际有四个 | 同步目录标题与数量 | 判原书没有附录四或生成替代附录 |
| 前言说PPT新增实操待补，正文有模板/HTML实作，部分风格仍未完成 | 分别更新对象状态 | 全部称已完成，或沿用旧例全称未完成 |
| 第46章称提示为实际提交完整文本，结尾又称待执行范本 | 标记实录身份冲突，待作者选正 | 编辑自行认定任务已执行 |
| 工具生成源码，作者独立完成运行 | 分别归属生成与执行 | 合成“工具完整跑通” |
| 第32章银行期初50000，第31章预测起点26000，正文明确不同来源 | 保留区别 | 为数字一致改成同一个值 |
| 同名活动在后章出现另一初始日期而未标分支 | 请求作者确认分支并加说明 | 将所有日期替换为第一章的日期 |
| 第42章预告沿用顾客资料，第43章另设青禾经营数据 | 修章间过渡 | 强行把两个公司的数据拼接 |
| 第38章新到账后可以更新状态 | 核对象、截止日、新证据 | 永久禁止出现“已结清” |
| 书中语句已经具体易懂 | 保留作候选样文 | 为体现工作量改成口语或文艺腔 |

这些是同一助手基于书稿的编辑判断，不是独立模型回归结果。完整问题定位在本次全书审核报告中。
