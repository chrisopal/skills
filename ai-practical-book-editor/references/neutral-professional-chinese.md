# 自然、直接的专业中文

## 1. 适用范围与风格依据

作者在本轮明确不喜欢“下一步最值得做的……”这类口吻，偏好“接下来重点……”“需要处理……”“优先解决……”等直接说明工作安排的表达。该偏好用于本书以及本Skill生成的评语，不作为所有中文文章的客观质量标准，更不用于判断文章是否由AI生成。

目标不是把词汇“清零”，而是让读者直接看到问题、动作、条件及其理由。作者给出的替代形式是表达方向，不是每段必须套用的开头。审美偏好与事实错误分别标注。

## 2. 先判断句子在做什么

| 句子作用 | 适用写法 | 需要保留的条件 |
|---|---|---|
| 指出当前问题 | “这里需要核对日期与星期是否一致。” | 没有确认前不直接改日期 |
| 安排已有依赖 | “核对字段后，再生成汇总表。” | 先后由任务依赖支持 |
| 说明可选改进 | “可以把重复检查整理成Skill。” | 不改成必须，不称已创建 |
| 提出明确优先级 | “先解决输入冲突，再调整图表。” | 输入冲突确实影响后续结果 |
| 解释方法 | “来源列用于定位原始记录。” | 保留后面的例子与解释 |
| 报告本次结果 | “本轮修改了两处状态表述。” | 依据真实记录，不加虚构效果 |
| 结束一节 | 概括本节具体结果、未决问题或下一章新任务 | 已说完则直接结束，不强制升华 |

“接下来重点聚焦问题处理”仍然没有说清做什么。应改为“接下来核对三家报价的运费说明”，或按上下文给出同样明确的对象。

## 3. 需要检查的五类表达

### A. 评价式引导

例：“最值得记住的是”“这一点尤其值得看”“更有价值的回答是”。

先判断后面是否已有具体内容。有则删除引导或直接改成相应动作；没有则回到本段补清对象，不能凭空编一个所谓关键点。最高级只在确有比较范围与依据、且符合作者用途时保留。

### B. 固定心得标题

例：“三个最值得记住的操作心得”“最值得注意的操作心得”。

按实际内容命名：统计章可写“记录时间、去重依据与人员变化”，咨询章可写“访谈陈述、字段语义与指标口径”，经营章可写“转化分母、金额口径与角色工时”。这是示例，不是必须出现的章名；新稿必须重新读内容。

不要把所有标题统一改为“三个重点”“关键事项”“需要注意的问题”。标题要帮助查找内容，编号和目录同步另外处理。

### C. 泛化的价值总结

例：“真正的价值不在于生成文件，而在于……”或“这才是AI的真正价值”。

能说明作用就直接说明作用；已经说明过则删掉重复。保留有实际区分的对比，例如“订单金额不是已支付金额”，它承载业务含义，不是空泛升华。

### D. 反复证明自己的讲解很重要

例：“这个例子再次告诉我们”“到这里你应该明白”“最值得带走的经验”。

改写为本节具体结论，或并入实例解释。不要把编辑点评放入读者正文，例如“这样写更专业”“这段解释最有价值”。

### E. 替换后产生的新套话

连续使用“接下来重点聚焦”“需要进一步强化”“优先解决相关问题”，仍然会掩盖任务。检查相邻段落和不同章的收尾，不以同义词轮换掩盖重复。不要添加“赋能、抓手、闭环、底座”等原文没有且不帮助理解的词。

## 4. 文本分区与修改权限

| 区域 | 默认处理 |
|---|---|
| 作者讲解、标题、章末总结 | 可以给候选改写；revise模式另存执行 |
| 教学整理范本 | 可给标明身份的新版；保留原约束与所需字段 |
| 历史逐字提示词或仅替换路径的实录 | 不因风格偏好直接改原文；在旁边给复用版或编辑建议 |
| 故意设计的错误示例、被评论的坏句 | 保留示例身份，不当作作者当前主张 |
| 字段名、文件名、ID、代码、命令、公式 | 不因语言润色改写；确需改动时单列影响及授权要求 |
| 图注与可见截图文字 | 图注按可见文字审；没取得图片不宣称图中也已改 |
| 附件、外部链接 | 不因正文引用就默认读取或执行 |

普通“下一步”可以是台账列名、商机跟进内容或时间顺序。本版不禁止这三个字。讨论投资价值、使用成本或方案收益时，“价值”有业务含义，也不自动删去。

## 5. 改写后的语义核对

逐项比较主语、对象、动作、来源、时间、数字、范围、条件、否定和完成状态。重点查：

- “可以”是否被改成“需要”或“必须”；“建议”是否被改成确定安排。
- 需要核对的事项是否被改成已确定事实；“未提供”是否误写为“没有”。
- 一次测试是否被改写成全部验证；作者独立完成是否被归给工具。
- 不同口径是否被误称矛盾；不同章节的规则是否被串用。
- 删除引导句后，原有解释是否仍能连贯读懂。

有依据的安全限制不因去套话而弱化；有条件允许的工作也不能被改成永久禁止。语气直接不等于判断更强。

## 6. 逐章意见怎样交付

每个重要意见使用当前文件中的原句锚点；允许只摘一部分，但明确只替换该片段。行号可能因导出变化，应同时给章名、小节和原文。只见目录则标“正文未读”，不能给虚构的逐句修改。

区分表达调整、结构调整、含义修正、跨章同步、待作者核定与可选润色。每章可以只有保留意见，不设最低修改数量。候选稿不等于已经修改原稿，迁移建议不等于附件已经建立。

交付前还要读一次评语自身，删除报告里同样的评价式导语和机械收尾。原句、反例和引用中的目标短语可以保留，不能为“零命中”篡改证据。
