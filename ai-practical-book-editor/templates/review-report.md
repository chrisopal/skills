# 书稿审核报告

## 结论与范围

一句主要判断，明确需要先改什么和哪些不用改。
实际取得、读过、计算过什么；未审图片/附件/外部事实及未执行程序。

## 应保留的内容

用原文锚点说明具体解释如何帮助读者，不泛泛称赞；表达采用自然、直接的专业中文，不以“最值得”组织结论。

## 按优先级的问题

| ID | 必须修正/建议调整/可选润色 | 位置与原文锚点 | 读者影响 | 建议动作 | 证据强度/待核 |
|---|---|---|---|---|---|
| | | | | | |

范围限制单列，不假称发现了源文件缺陷。一个已证实的结构冲突与一个审美偏好不能混用确定语气。

## 结构与读者路线

主线、进阶或配套材料的调整，保持现有章节映射。分清主讲与提醒，不提出没有目的的大比例删稿。

## 局部示范

标“候选编辑稿”，列原文锚点、保留事实、修改范围；不虚构产物或经历。没有修改的好段落也可展示。

## Skill 本身的调整（仅在用户要求时）

原版已有能力、全书应用缺口、实际修改文件、确定性验证、同助手试用、未做的独立评测分别报告。

## 修订安排

说明先改哪部分、怎样验收、哪些需要作者决定。不要把建议当成原文已修，也不要求用户重复提供已有正文。
