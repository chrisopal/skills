# 人工确认点与真实授权

G1理解确认：原件完整性、附件优先关系、范围、强制要求和规则适用。
类型识别和模板匹配先形成候选。明确范围的03—06理解提取可继续；类别、组合或参与标包的重大歧义须由用户决定。进入响应策划/方案与正式承诺前确认选定标包、投标主体和规则，具体见TENDER_ROUTING.md。不为每个无歧义自动识别设置重复确认。
G2方案与证据确认：设计边界、能力证明、适用证书、资源、进度与风险。
G3承诺与内容采纳：技术正文、资格表、价格和商务偏离，由相应授权人确认。
G4成稿交付：当前评审、实际Word/PDF视觉与文本、签署状态、对外披露范围。

AI可列问题、准备表单和签批草稿，不得假冒用户批准。重大风险接受不能改变明确不满足的强制条件。告知“继续”只允许继续既有任务范围，不自动授权对外上传、付款、签署、联系招标方或递交。

确认记录应能回到真实用户消息或有权审批系统，记载对象、版本、决定、决定人、时间、范围与证据引用。本地JSON仅承载记录，不能独立证明身份。示例与测试中的TEST-ONLY确认全属程序测试夹具，不能复制进真实项目。

等待人工决定时保存当前产物并停在明确位置，给出待确认问题，不宣称后台会继续。用户要求仅草稿时可继续探索，但始终保留草稿和未核验状态。
