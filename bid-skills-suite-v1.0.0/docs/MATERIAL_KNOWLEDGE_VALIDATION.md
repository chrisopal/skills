## 指定知识库边界

配置→生成检索任务→宿主返回原文→校验资源范围/项目/查询/工具/权限范围→保存快照→Wiki→按章引用，已用显著模拟协议数据跑通。配置不是授权，保存JSON不是执行远端调用证明。

自动回归覆盖无命中、权限失败、工具不可用状态、来源越界、请求不匹配、连接改版、敏感查询拒绝、逐条快照过期、同文档新快照替代和撤权后不得由无关查询恢复旧资料。来源仍保留`host_call_verified=false`及`remote_freshness=NOT_CHECKED`。

用户本轮未指定真实客户知识库资源，因此真实第三方授权、远端版本变化、WorkBuddy模型执行和真人协作均为`Not run`。此功能通过现有宿主工具交接，不是新建飞书/腾讯/Office的专有API客户端或全库自动同步器。

## Word/PDF与审核门禁

每份项目另生成1页专项DOCX/PDF样张：2张原生可编辑表格、1张合成图片；两份共2页、4张表、2张图。真实文件检查和全部2页渲染回读通过，合并表、中文、黄色缺料提示和图注均可见，内部知识链接未泄漏。这里没有重新导出两份整本投标书，也没有把专项样张当作完整标书。

首次发现PDF文字可抽取但中文渲染缺字：在本机为实际导出引擎配置字体发现路径及已安装的中文字体后重新导出、逐页检查；本机路径未写入通用Skill。导出Skill补充了“文字提取成功不等于字形正确”的检查要求。

核心审核检查确认模拟知识材料阻止正式交付；既有材料缺口、未重新完成的整本评分评审和质量计划复核仍保留，不填成通过。本轮未重跑整本AI专家语义评分，不形成新的总分或正式发布结论。
