# 场景组合与领域包扩展

## 四层输入

招采规则配置回答如何确认适用流程与提交；领域包回答关注哪些技术事实与证明；版式配置回答如何组织文件；企业素材回答本投标主体实际拥有什么。四者不能互相冒充。

本包提供政府采购、企业采购2个招采检查种子；智能工厂、工程、设备、专业服务、电缆供货5个领域种子；中性A4、暗标2个版式检查种子。readiness均为seed_requires_project_validation，不代表发布或资格认证。

## 组合原则

以命名空间并列保存，不做隐式覆盖。例如智能工厂项目含设备供货，可同时加载smart-factory与equipment-supply；相同字段语义不同时分别保留，再由02／07确认。客户需求仍只能来自实际招标依据，配置中的关注词不会自动变成需求。

法律适用与合同／文件效力不是简单merge顺序。发现矛盾先记录冲突的两条来源、可能影响和需由谁判断，不机械说“最后文件优先”或“招标文件覆盖所有规则”。

## 新增行业

复制一个domain配置种子，取新的id；补充领域术语、事实字段、方案维度、证据类型与已知误判。保持17个技能不变，优先改配置。确实新增专业计算或执行能力时另加受控工具，不在提示词中伪装算法已经实现。

先准备正例、缺资料反例、跨领域负例和真实评审真值；用相同技能执行并记录漏项、误项、引用与成稿问题。示例通过结构校验并不证明领域泛化或真实交付。

## 电缆特别提醒

保留复合电压、芯数与截面原文；证书覆盖关系不自动按大小推断；独立合同份数不按页数计；AND／OR不混淆；原文调价公式只保存为文本，在明确授权和输入齐备时用确定性工具验证，不能eval任意原文代码。
