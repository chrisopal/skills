原生解析器刻意保守：有图片的PDF页、少字页、疑似编码异常都可能需复核，包括正常logo或空白页。OCR显式开启后按页补读，低置信度、空结果与失败范围继续保留；仍需核对表格结构及关键数字。宿主视觉补读后也应创建新版产物，不能无证据清除标记。

Python依赖按requirements安装，OCR推理服务、系统软件与字体按官方说明配置。本包不附字体，不从用户原件执行代码，不在后台下载模型。包含17技能规程及本地辅助工具，不包含独立投标软件、数据库或任务worker。

在无文件写入、无脚本、无图像或无导出能力的聊天环境中，按规程形成可读草稿与结构化文本，并真实说明未执行能力；不能假装已生成文件或已完成自动化。
