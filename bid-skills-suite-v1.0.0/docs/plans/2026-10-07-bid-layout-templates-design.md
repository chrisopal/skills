# 投标版式模板设计

用户授权查找投标版式依据并形成可复用模板，同时保留SVG/宿主生图的当前任务。模板以项目招标文件及有效补遗为权威；官方公文标准只用于解释适用范围，不能作为所有投标文件的强制标准。

选用可执行JSON候选模板和项目覆盖记录，与14现有document-spec衔接。拒绝只存一篇规范说明，因为无法核验字号、缩进和段间距实际生效；不建立新排版引擎。扩展现有python-docx生成器的明确样式字段，保留基本工作稿边界，不引入依赖。

验收包括真实DOCX读回、坏参数拒绝、通用模板Word/PDF渲染，以及真实招标格式覆盖后的青草沙章节与配图。正文与13产物保持原版本，文档另存新版本。暗标、固定表、自动目录、采纳与正式投标成稿仍走原有门禁。
