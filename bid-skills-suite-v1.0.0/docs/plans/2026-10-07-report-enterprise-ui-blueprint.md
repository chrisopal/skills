# 招标HTML报告 UI Blueprint

模式：enterprise-ui-design Upgrade。基线：4c94f0d；标准及tokens.json版本1.0.0。范围：单一离线HTML报告及17总控生成器，不改业务JSON、抽取、权限或应用界面。

- Keep：项目名称、八个业务分区、全部条目与证据、原PDF物理页链接、交集筛选、键盘展开、打印完整内容、版本与哈希绑定。沿用自研HTML/CSS和标准库，不引入框架、字体或网络依赖。
- Adapt：一个report作用域的语义Token适配；220px侧栏、48px文件工具栏、24px标题与同处状态、16px分区标题；14px/1.7正文，24–32px分区间距，4px控件/6px面板/3px标签。浅深色使用真实规范颜色配对。
- Retire：30px展示标题、胶囊标签、面板阴影、重复页面说明与实现术语、装饰滚动。长标识符和分析范围按需展开，缺资料/确认/冲突保留在相关分区。
- 实际操作：打印报告为主按钮，查看原件为次按钮；外观选择支持跟随系统、浅色、深色及原版浅色。旧CSS与历史HTML保留回退，操作8px组间距，窄屏换行；导航持续可见，移动端不设隐藏侧栏。
- 来源：把enterprise-ui-design的tokens.json随17总控分发；CSS、报告脚本读取同一JSON；报告默认采用该标准，独立安装可离线运行。保留原始数据完整性，不以说明文案填充空白。
- 验证：基线截图；1366/1440/1920/390的浅深色、长内容、原文展开、零结果、所有分区、键盘、打印、外观切换与回退；实际文字/控件对比度和hover/focus/disabled样式探测。静态报告没有登录、鉴权、Portal、加载或业务禁用分支，这些不造假界面。
- 门禁：现有Python测试、编译、Skill验证及独立分发检查；无前端工程，因此npm lint/typecheck/build不适用。HTML真实生成/浏览器核验作为构建证据；业务E2E和部署分别记录，不借视觉通过宣称完成。
