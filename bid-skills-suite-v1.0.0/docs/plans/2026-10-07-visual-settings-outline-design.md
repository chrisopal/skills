# 生图配置与目录显示修正

用户授权：新增配图/生图配置，修复写作报告中的混合编号和层级显示。当前基线e0b0fc6b，目录数据有parent_id，但报告平铺，编辑器state未传递父级；东台子编号为“一.1/三.2.1”，青草沙采用9.1等数字编号。

## UI Blueprint

- 保留：企业浅深主题、章节ID/正文/需求关联、保存冲突机制、原件强制格式与现有30节点。
- 调整：由parent_id构建前序目录，父节点下展开子级并缩进；一级中文编号呈“一、”，混合中文小数子编号仅在展示层转为1.1/3.2.1，正确数字编号和客户特殊编号保留。标题与状态分列，长标题正常换行；不重写08原始文件或触发无意义版本更新。
- 补充：写作设置中的配图启用、技术图渲染方式、概念图启用/宿主工具、模型偏好、风格、比例和最多图片数。默认沿用宿主能力，不接收Key，不假装配置后已生图；当前工具不可用时保留缺口。关闭时禁用子字段但保留配置。
- 同源：共享目录展示helper供编辑器与可复用HTML报告生成器使用；资源进入11/17独立包，生成报告留本地。

## 选择

使用展示派生层和已有设置保存接口。直接修改08并重绑所有下游会扩大为内容版本变更；仅替换HTML字符串又不能修复编辑器和其他文件。新增独立生图API/凭据界面不在本轮范围，生成仍由当前Agent实际工具执行。

## 验证

先覆盖中文混合编号、三层结构、数字编号、客户特殊编号、非法父级/循环和不修改输入的回归。生图设置验证旧设置补默认、嵌套校验、保存刷新、关闭禁用、冲突与秘密字段拒绝。两个真实项目重生成报告并浏览器检查父子顺序、编号、长标题、浅深色、展开/折叠、切换不丢正文及设置回读。独立ZIP缺依赖不能通过；真实图像生成与外部传输按实际工具可用和既有授权单独记录。
