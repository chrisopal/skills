# 逐项业务评审与导出版式配置

用户已要求修复评审 Skill 并验证，另要求可配置封面、目录和排版。实现范围仅为 chrisopal/skills 的投标套件及独立技能，不修改 Bid Agent 应用 API 或数据库。

评审新增三张逐项表：计分叶子、合规条款、材料选用。原文规则、正文定位、材料身份、逐维检查和结论均保留。生成计划一律待核验；结构链接不自动成为满足。正式交付核对当前上游集合、正文引用、来源哈希、材料硬条件与评审覆盖；评分缺口和否决条件分别处理。模拟资格不能通过正式门禁。缺少矩阵的旧报告需重新评审，不继承旧通过状态。

导出复用 build_docx 的正文样式并新增项目配置，包含封面、TOC 和页眉页脚；目录使用真实 Word 域，实际渲染后再核对页码。招标强制格式优先，配置在评审前保存到 profiles，修改后重新审核。保留 draft_only 与正式签署授权边界。

验证：缺材料、失效/主体不符、数量/重复证明、签章、评分遗漏、否决遗漏、证据伪定位、过期版本及模拟正式发布的反例；实际 DOCX 结构和渲染后的封面、目录、排版。套件全量回归、独立安装资源及 Schema/ZIP 一致性验证。案例和导出文件保留项目 output 下，不提交生成产物。
