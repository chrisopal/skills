# 篇幅与界面图检查展示调整

## UI Blueprint

- 对象：已有写作编辑器右侧只读检查区，使用现有 enterprise-ui-design 色彩、字体及深浅色变量。
- 将37章按实际 blocking_issues、issues 分为需整改、建议调整、无缺口；默认只展开需整改组，章节数和问题数分开统计。
- 章节名称可跳转；实际字数、目标范围、补足或超出字数、已插入界面图数量分行显示。未设目标明确标注，不以无缺口表示评分或正文已通过。
- 原始检查依据置于原生 details，支持键盘；导航复用现有章节选择与加载禁用行为。
- 仅将已知历史 CLI 渲染记录缺失提示改为人可读说明，匹配真实图名并提供图源入口；原始诊断完整保留于展开详情。其他警告和错误保留内容与级别。
- 不修改项目正文、字数目标、图片计数、追溯状态、审核与导出。无依赖或接口变更。
