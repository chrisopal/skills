# 商务与资格文件编制｜专项操作手册

## 目标与完成边界

受约束地填报商务和资格文件，保留签署与价格授权边界。。这里的完成是当前职责产物形成且检查清楚，不是对整个投标项目作通过判断。

## 核心操作细则

### 1. 商务与资格文件编制子步骤1

按06逐表建立FORM-ID与字段映射，区分固定文本、可填字段、附件和签署区，不重写原模板条款。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 2. 商务与资格文件编制子步骤2

每个填值关联准确企业素材或人类决策来源；统一公司全称、统一社会信用代码、授权代表与项目名称。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 3. 商务与资格文件编制子步骤3

资格材料按照05规定的投标主体、有效时间和对象核对；提供的证照不能因“格式齐全”自动视为适用。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 4. 商务与资格文件编制子步骤4

价格、数量、币种、税率和舍入由用户明确提供；用Decimal或可靠表格工具校验乘积和合计，不用语言模型心算。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 5. 商务与资格文件编制子步骤5

缺失价格、账号、证书号或日期留null和待填任务；禁止用示例数字、同类企业资料或AI估值填正式表。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 6. 商务与资格文件编制子步骤6

商务偏离保留原条款、响应值、差异和授权状态；涉及责任或合法性的争议转人工专业审核。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 7. 商务与资格文件编制子步骤7

输出需签字、盖章、电子签署或保证金动作清单，不自动执行。签署空白区保留，不能贴生成的印章或签名。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 8. 商务与资格文件编制子步骤8

交付填报草稿和字段来源表，经授权审核采纳后进入14；身份信息脱敏只用于内部演示，不擅自破坏正式模板要求。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

## 场景差异怎么处理

智能工厂：关注业务范围、接口、数据、部署与验收；工程：关注工作范围、工序条件、资源与专业审查；设备供货：关注型号、数量、规格、交期与证明范围；服务：关注SLA、人员、交付物与考核。只有原文明确要求才进入explicit；场景知识只决定“检查什么”，不决定“客户一定要什么”。

政府或企业采购配置独立于行业配置。规则适用需确认，补遗与原文冲突需保留双方来源，不按名称或文件顺序机械裁决。可将多个领域包并列使用，但同名参数冲突应保持命名空间并发出澄清。

## 错误输出与改正

**错误风险 1：** 身份证号、账号和证书号不能推测。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

## 缺工具时的降级

没有脚本权限：按输出契约填写并人工核验，声明脚本NOT_RUN。没有联网权限：不获取或宣称最新法规。没有图像／OCR／渲染能力：保留涉及区域待复核；已读文本可作限定范围探索，不作全面合格结论。
