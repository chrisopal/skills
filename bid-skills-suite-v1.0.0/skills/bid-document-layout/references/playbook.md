# 标书排版与文档编排｜专项操作手册

## 目标与完成边界

组织可编辑文档工作稿，落实格式、目录、图表、附件与分册要求，并生成渲染检查清单。。这里的完成是当前职责产物形成且检查清楚，不是对整个投标项目作通过判断。

## 核心操作细则

### 1. 标书排版与文档编排子步骤1

读取06的明确规则，确认分册、纸型、样式与固定表；没有要求时提出保守默认值并标proposal，不能覆盖已指定格式。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 2. 标书排版与文档编排子步骤2

建立标题样式、编号规则、表题图题、正文、页眉页脚与页码，不用大量空行模拟分页；编号与业务SEC-ID保持独立。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 3. 标书排版与文档编排子步骤3

按08锁定目录组织已采纳正文，填入客户规定表单，附图按FIG-ID插入正确位置，缺失图片不能静默跳过。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 4. 标书排版与文档编排子步骤4

设置表头重复、关键行跨页策略、长表与宽表页面方向；保留表格可编辑，不能为省事全部转图片。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 5. 标书排版与文档编排子步骤5

安排原始证明插页与附件清单，标明哪些需要保持原件版式；PDF原页无法嵌入当前Word工具时明确方案与待处理项。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 6. 标书排版与文档编排子步骤6

检查目录域、交叉引用、图表编号、页码和分册连续性；无法自动更新域时标待更新，不能编造实际页码。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 7. 标书排版与文档编排子步骤7

渲染当前文档并逐页检查裁切、溢出、孤标题、乱码、图片清晰度和签署空位，缺渲染能力则输出待检查而非通过。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 8. 标书排版与文档编排子步骤8

保存排版工作稿与内容清单摘要，交15复核后由16导出；排版造成文字、模板或附件变化也需要重新审核。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

## 场景差异怎么处理

智能工厂：关注业务范围、接口、数据、部署与验收；工程：关注工作范围、工序条件、资源与专业审查；设备供货：关注型号、数量、规格、交期与证明范围；服务：关注SLA、人员、交付物与考核。只有原文明确要求才进入explicit；场景知识只决定“检查什么”，不决定“客户一定要什么”。

政府或企业采购配置独立于行业配置。规则适用需确认，补遗与原文冲突需保留双方来源，不按名称或文件顺序机械裁决。可将多个领域包并列使用，但同名参数冲突应保持命名空间并发出澄清。

## 错误输出与改正

**错误风险 1：** Word页数与PDF页数不必天然一致，需各自检查。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**错误风险 2：** 字体替换可能导致分行与页脚变化。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**错误风险 3：** 暗标还要检查文档属性与图片信息。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**错误风险 4：** 没有渲染工具时不可声称版式已验收。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

## 缺工具时的降级

没有脚本权限：按输出契约填写并人工核验，声明脚本NOT_RUN。没有联网权限：不获取或宣称最新法规。没有图像／OCR／渲染能力：保留涉及区域待复核；已读文本可作限定范围探索，不作全面合格结论。
