# 企业素材与证明材料匹配｜专项操作手册

## 目标与完成边界

建立要求与真实企业证据的对应关系，明确适用、待核验和缺失，而非只有相似度结果。。这里的完成是当前职责产物形成且检查清楚，不是对整个投标项目作通过判断。

## 核心操作细则

### 1. 企业素材与证明材料匹配子步骤1

建立M-ID素材台账，保留主体、来源、修订、哈希、授权范围和附件位置；不同客户／投标主体资料不得混用。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 2. 企业素材与证明材料匹配子步骤2

从要求提取约束：类型、证书类别、对象型号、范围、有效期、人数、独立合同数量、证明页和所需签章。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 3. 企业素材与证明材料匹配子步骤3

先按硬条件过滤，再做相关性检索；语义相似不自动代表合格，未见完整原件只标candidate。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 4. 企业素材与证明材料匹配子步骤4

按对应关系记录accepted、candidate、rejected、missing及理由；人工accepted需有真实确认引用，不由模型签批。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 5. 企业素材与证明材料匹配子步骤5

保留AND／OR与独立份数，合同多页只是一份，重复扫描不能重复计数；证书规格覆盖不凭“更大通常更好”推断。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 6. 企业素材与证明材料匹配子步骤6

引用锁定到确切原件修订和页／段位置；新资料版本产生新引用，不因文字相同改挂历史证据来源。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 7. 企业素材与证明材料匹配子步骤7

整理用于填文的字段与插页原件，确认脱敏是否影响效力；需要外部传输时先确认授权，禁止自动将私有文件发给外部工具。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 8. 企业素材与证明材料匹配子步骤8

输出证据对应表和缺口清单。缺关键证据阻止相关正式承诺，交10—12引用，交15复核。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

## 场景差异怎么处理

智能工厂：关注业务范围、接口、数据、部署与验收；工程：关注工作范围、工序条件、资源与专业审查；设备供货：关注型号、数量、规格、交期与证明范围；服务：关注SLA、人员、交付物与考核。只有原文明确要求才进入explicit；场景知识只决定“检查什么”，不决定“客户一定要什么”。

政府或企业采购配置独立于行业配置。规则适用需确认，补遗与原文冲突需保留双方来源，不按名称或文件顺序机械裁决。可将多个领域包并列使用，但同名参数冲突应保持命名空间并发出澄清。

## 缺工具时的降级

没有脚本权限：按输出契约填写并人工核验，声明脚本NOT_RUN。没有联网权限：不获取或宣称最新法规。没有图像／OCR／渲染能力：保留涉及区域待复核；已读文本可作限定范围探索，不作全面合格结论。
