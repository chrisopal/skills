# 强制目录与格式模板提取｜专项操作手册

## 目标与完成边界

忠实提取必须遵守的文件结构、固定表格与版式规则，为规划与排版提供约束。。这里的完成是当前职责产物形成且检查清楚，不是对整个投标项目作通过判断。

## 核心操作细则

### 1. 强制目录与格式模板提取子步骤1

查找格式章节及所有被引用附件；有原始可编辑模板时优先保留，不从PDF截图凭空重造表格。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 2. 强制目录与格式模板提取子步骤2

按F-ID记录强制章节、顺序、分册、表格、附件、封面、声明和签署区，附逐项来源。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 3. 强制目录与格式模板提取子步骤3

依据原文区分mandatory、reference、unknown；只有示例或推荐措辞时不能强制化。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 4. 强制目录与格式模板提取子步骤4

提取可编辑字段与不可编辑条款，保留表格列、合并结构、编号和脚注；无法确定的修改权限列为待确认。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 5. 强制目录与格式模板提取子步骤5

提取字体、字号、行距、页边距、页码、装订、纸型和电子格式要求；没有要求时留空，14再提出默认方案。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 6. 强制目录与格式模板提取子步骤6

暗标要求单独记录身份信息禁用范围，包括封面、图标、文件属性、页眉页脚、图片元数据和文件名，但不自动认定所有项目需要暗标。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 7. 强制目录与格式模板提取子步骤7

多文件规定冲突时保留两条规则及相互关系；不按文件顺序或“更美观”擅自取舍。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 8. 强制目录与格式模板提取子步骤8

输出格式约束和待填写模板索引，交08和12／14；未发现强制目录时明确检索范围和状态，禁止写“没有任何格式要求”。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

## 场景差异怎么处理

智能工厂：关注业务范围、接口、数据、部署与验收；工程：关注工作范围、工序条件、资源与专业审查；设备供货：关注型号、数量、规格、交期与证明范围；服务：关注SLA、人员、交付物与考核。只有原文明确要求才进入explicit；场景知识只决定“检查什么”，不决定“客户一定要什么”。

政府或企业采购配置独立于行业配置。规则适用需确认，补遗与原文冲突需保留双方来源，不按名称或文件顺序机械裁决。可将多个领域包并列使用，但同名参数冲突应保持命名空间并发出澄清。

## 错误输出与改正

**错误风险 1：** 招标文件自身目录不一定是投标文件目录。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**错误风险 2：** 内容齐全不代表分册与顺序合规。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**错误风险 3：** 统一品牌配色可能违反暗标要求。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**错误风险 4：** 保留签字区不等于已经签字。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

## 缺工具时的降级

没有脚本权限：按输出契约填写并人工核验，声明脚本NOT_RUN。没有联网权限：不获取或宣称最新法规。没有图像／OCR／渲染能力：保留涉及区域待复核；已读文本可作限定范围探索，不作全面合格结论。
