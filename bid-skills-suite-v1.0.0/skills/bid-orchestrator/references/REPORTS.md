# 招标理解报告

JSON为各Skill交接结果，Markdown便于文本阅读，HTML用于查看同一版本数据。HTML只展示候选提取，不是独立业务权威或正式投标成稿。

## 生成

完成17当前输入索引后，在项目目录之外运行：

```bash
python scripts/render_report.py --project /absolute/project --out reports/tender-report.html
```

脚本从17的stages/inputs读取当前01—06及分类路由，校验项目、版本、哈希与项目内路径。输入变化或路径越界时拒绝生成；缺资料保持未提供/待补，不显示资格通过。生成清单与报告一起保存，旧报告保留或以新名称重建，具体选项见`--help`。

## 展示

基础信息、标包与类别、评分层级/分值、完整需求、资格/否决/提交/履约风险、格式适用性、原文冲突和版本溯源分区展示。需求可搜索、按类别筛选并展开原文与页码。保留全部条目，不仅展示前几条。真实原件可通过项目内链接定位；缺企业材料、未确认分类和未检查事项可见。

报告离线打开，不加载远程CDN或字体。用户原文按数据转义，不执行文档中的代码。浏览器查看后验证1440px、宽屏及390px，检查长文字、筛选、展开、键盘、原件定位和打印；程序测试不替代视觉验收。

## 企业UI外观

默认按enterprise-ui-design的Upgrade规范呈现：单一蓝色体系、扁平面板、24px文件标题、16px分区标题、14px/1.7正文、4px控件/6px面板/3px标签，保留现有八个业务分区。打印报告和查看原件集中在文件工具栏；范围说明和长编号按需展开，真实缺口与待确认仍在相关分区可见。

`assets/ui/enterprise-tokens.json`为该Skill v1.0.0 tokens.json的随包副本，元数据保留来源；CSS消费项目内`--report-*`变量，不依赖其它已安装Skill。无外部字体、组件框架或CDN。打印采用浅色纸面，正文1.7行高遵循文档可读性规则；这些是明确的文档场景适配。

外观支持跟随系统、浅色、深色、原版浅色。原版CSS与历史HTML保留回退；外观切换不修改项目数据。移动导航始终可见，无隐藏菜单或焦点陷阱。检查1366/1440/1920/390的浅深色、全部分区、长内容、真实操作和对比度；未使用的登录、权限、Portal、业务加载/禁用状态不新增假界面，也不计入已验收范围。
