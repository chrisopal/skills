# 项目画像与场景适配｜专项操作手册

## 目标与完成边界

建立所有后续技能共同使用的项目上下文，并选择明确版本的场景配置。。这里的完成是当前职责产物形成且检查清楚，不是对整个投标项目作通过判断。

|---|---|---|---|---|
| 首轮 | 从实际文件计算 | 按用户授权范围 | 不留空掩盖问题 | 明确负责人或工具 |

## 核心操作细则

### 1. 项目画像与场景适配子步骤1

确认用户位于投标人侧，并确认本次是完整编标、理解分析、修订还是独立评审；不要混入招标人编制文件或组织评标任务。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 2. 项目画像与场景适配子步骤2

从明确原文提取项目名称、采购人、采购对象、地点、范围、标包、预算、时间、交付与验收条件；没有证据的字段使用null和待确认说明。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 3. 项目画像与场景适配子步骤3

将配置拆成招采规则、行业领域、文档模板、企业素材四层。工程、设备、软件集成、服务可组合；政府／企业不是行业分类。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 4. 项目画像与场景适配子步骤4

为推荐的配置列出证据、版本与适用理由。按TENDER_ROUTING对单包/多包/组合采购匹配模板：清楚的候选可继续提取；重大歧义、用户指定先确认或正式采纳响应范围时取得真实决定。无领域包时使用通用框架并声明专业规则缺口，不强行套最相似行业。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 5. 项目画像与场景适配子步骤5

处理时间：保留原文和明确时区，日期未说明年份或时区时不能自行补齐。不同附件的截止日期冲突进入待澄清项。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 6. 项目画像与场景适配子步骤6

已核验的适用法律规则与招标条款冲突时标记待专业判断，不机械设置“招标文件覆盖法律”；离线环境不宣称法规已最新核验。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 7. 项目画像与场景适配子步骤7

建立统一术语、项目简称、投标主体、币种、计量单位、能力边界和禁止承诺项，后续技能使用同一上下文版本。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

### 8. 项目画像与场景适配子步骤8

输出配置选择与用户确认点。配置种子只提供检查维度，不能自动变成项目要求或企业能力；经确认后冻结本轮上下文摘要。

执行记录应说明本步实际采用的文件、定位和决定；没有相关信息就保留未知，而不是套用行业经验。

## 场景差异怎么处理

智能工厂：关注业务范围、接口、数据、部署与验收；工程：关注工作范围、工序条件、资源与专业审查；设备供货：关注型号、数量、规格、交期与证明范围；服务：关注SLA、人员、交付物与考核。只有原文明确要求才进入explicit；场景知识只决定“检查什么”，不决定“客户一定要什么”。

政府或企业采购配置独立于行业配置。规则适用需确认，补遗与原文冲突需保留双方来源，不按名称或文件顺序机械裁决。可将多个领域包并列使用，但同名参数冲突应保持命名空间并发出澄清。

## 错误输出与改正

**错误风险 1：** 国有企业身份不足以自动确定具体采购制度。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**错误风险 2：** “标准模板”不能覆盖客户指定表格。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**错误风险 3：** 某行业常见功能不能自动加入客户需求。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

**错误风险 4：** 项目简称相近不等于同一标包。

**改正：** 返回相关原件/输入，明确本技能职责和未确定字段；保留问题，不以语言修饰替代核验。

## 缺工具时的降级

没有脚本权限：按输出契约填写并人工核验，声明脚本NOT_RUN。没有联网权限：不获取或宣称最新法规。没有图像／OCR／渲染能力：保留涉及区域待复核；已读文本可作限定范围探索，不作全面合格结论。
