# Changelog

## 1.0.1 — 2026-10-07

- 新增适合公开仓库的通用发行版；不发布客户资料、参考图片和历史调整记录。
- 用35页通用目录替代私有项目示例，保留needs_review与content_complete=false门禁。
- 更新文档链接与测试夹具；生产控制脚本、主题配置和内容schema保持原样。
- 增加独立技能状态记录和仓库索引；不覆盖现有PPT技能。

## 1.0.0 — 2026-10-07

- 基于本轮图片PPT迭代与35页故事线重构，提炼独立的咨询图片PPT生产技能。
- 保留既有咨询交接规范；固定事实、结论、架构、依赖、引用和审批边界。
- 增加纯白墨绿主题、图形关系驱动布局、单页任务与续做机制。
- 将内容包与图片生产manifest分离，增加稳定页ID、选版、审校、哈希与内容变更影响。
- 增加一页一图PPTX原图导出，核对每页形状数和嵌入图像字节。
- 添加32项本地回归测试、3页draft示例和35页outline示例；早期私有发行素材未随公开版发布。
