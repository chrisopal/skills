# 与现有PPT技能的分工

本包是独立技能，不覆盖仓库中其他PPT技能，不要求读取私有Library文件。

| 已有能力 | 本包的边界 |
|---|---|
| `ppt-maker-with-image` 的图片优先制作 | 本包额外关注咨询内容契约、稳定页ID、批次续做、版本审校与原图字节核验；不替换原目录 |
| `ppt-maker-direct-pptx`、SVG或HTML可编辑制作 | 用户需要可编辑图形时转交对应技能，不把单张图片冒称可编辑 |
| `image-to-editable-ppt` 的图像转可编辑 | 独立转换任务，不能在用户要求原图组装时自动调用 |
| 既有咨询套件的观点先行与页级审校 | 保留上游决定讲什么、下游决定怎么呈现的边界；不自动重写已批准结论 |

已有完整内容包时只验证和呈现；发现重复先提出变更，确认后sync。只有原始资料时可形成提纲草案，不据此产生未确认的咨询决策。

新增主题应创建theme profile；仅在明确切换主题时改变样式，不按页面或图片工具自动换色。
