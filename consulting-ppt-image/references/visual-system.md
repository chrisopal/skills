# 统一视觉，不统一成单调布局

## 固定样式

默认主题：纯白背景 #FFFFFF，深墨绿 #0B4F4A，绿色强调 #18A983，深灰正文 #4B5563，浅绿信息面 #EFF7F4。具体取值是本技能把已确认视觉规则参数化后的建议基线，不宣称从每张AI图逐像素测得一致色值。

照片内部可保留自然色。不要因为案例品牌色是蓝色就把整个案例页换成蓝色母版。只在真实风险或关键时间点用少量红色。页面外层不能出现山水、菊花、水印、角落口号；展厅内的自然装置属于内容图，可保留。

优先中文无衬线粗体标题与清晰正文；整套选同一种字体。字体名称用于调用宿主已有字体，本包不附任何字体文件。

所有页面有统一标题区、副标题、主体、结论和页码位置。页脚不堆品牌标语和英语口号。背景白不意味着删掉所有浅绿功能区域。

## 按关系选结构

| 内容关系 | 推荐布局 | 必须看清 |
|---|---|---|
| 背景/诉求 | 左场景或事实，右挑战与判断 | 事实和推断分别表达 |
| 产业价值 | 从资源到创新/制造/市场的链条，或价值树 | 业务动作如何产生价值 |
| 业务流程 | 横向流程＋角色泳道/支撑能力 | 输入、动作、输出和责任 |
| 统一架构 | 分层架构＋侧面边界解释 | 共用能力、专业控制、数据接口 |
| 对标案例 | 左官方证据、中做法与机制、右本项目借鉴 | 具体谁做了什么；不是企业介绍 |
| 追溯 | 来源—加工—成品—去向关系网＋异常处置 | 分批合批、证据与处置责任 |
| 场景概念 | 约60%主效果图＋3个解释点 | 设计意图、使用过程、运营价值 |
| 能力路线 | 阶段列×业务领域行 | 每阶段新增能力，不等同甘特 |
| 时间计划 | 原始日期数据驱动的甘特图 | 真实比例、里程碑、前置条件 |
| 下一步 | 工作/参与角色/输出的行动表 | 责任与近期决策，不以泛泛口号结束 |

三张连续同类布局触发提示，不自动换结构；一组连续案例/流程页可以有意保持一致。内容饱满指对象、关系、证据和业务意义充分，不是卡片越多越好。

## 参考页使用

公开版不附参考图片。由用户提供经授权的架构、流程、场景参考页，放在私有项目工作区；记录实际路径、用途、来源与确认版本。仅按需载入一到两页，不把全部历史错误版本塞进生成上下文。

参考页仍可能有生成式文字/示意画面的历史问题，不能将其中每个细节都复制为标准。验收要求以锁定主题与当前页内容包为准，尤其不能复制未经核验的百分比、工艺或产品标签。
