# 软件定制与系统集成完整交付演练

## 目标和范围

以“设备维保工单定制平台与 ERP 集成”运行一个目的明确为 simulation 的项目。使用现有 25 个交付 Skills，保存各次任务的输入、输出、来源和精确版本。合同、访谈、客户确认、UAT 和培训接收采用明确标注的模拟材料；代码、HTTP 集成、数据库持久化、测试、迁移与恢复在本机实际执行。

工程主线为创建与查询工单及幂等控制、角色审批、迁移核对与恢复。交付主线为合同交接、启动、调研、需求蓝图、详细设计、分线 WBS、实施证据、测试、上线演练、培训移交、里程碑确认、行政结项与持续质保。同步管理工时、成本差旅、风险、问题、变更、周报和交付审查。

## 实施与分工

1. 用现有运行工具登记完整项目，复用本地工程测试及操作回读；所有阶段使用同一组需求和构建引用。
2. 分别生成原始基线、批准变更和完整应用后的有效版本；保留有条件审查及整改复核。
3. 生成填有本项目数据的 Word 成果、Excel 管理台账、25 个 Skill 任务卡和原始证据索引。
4. 用 Enterprise UI Design 构建蓝色项目审阅页，展示阶段、计划、设计、质量、费用、风险和验收。
5. 回读所有文件、运行完整测试、核验版本及金额，检查实际浏览器交互和文档渲染；最后独立审查。
6. 更新说明与 STATUS，提交并推送可复用源码、测试和文档。模拟数据、Office、截图和审核证据仅在 output 保存。

两个独立实施分支分别负责案例生成与成果展示；主代理负责整体验证、实际文件回读、最终审核及仓库提交。

## UI Blueprint

面向项目经理和审核人员的内部模拟项目审阅页。最短路径为查看当前阶段和有效版本，沿需求到设计和测试读取证据，下载对应成果。页面七个区段为总览、计划与里程碑、调研与设计、实施与质量、成本与风险、验收与归档、成果与审核。

采用已有企业蓝色语义 tokens，紧凑表格和分组正文，浅色和深色主题。锚点导航、真实行筛选、无结果反馈、主题切换与文件下载均可操作。没有后台、账户或生产操作。手机导航换行，表格在自身容器滚动，焦点可见。来源和长引用按需展开；内部财务标为内部。

## 验证标准

- 全部 25 个 Skill 有任务记录、实际输入和输出，不能仅列名称。
- 当前与有效基线均通过 runtime 校验；计划和成本变更完整应用，不混入候选。
- 每项需求可追溯到模拟合同/调研、蓝图、详细设计、工作包和实际测试。
- 本地 HTTP/SQLite 测试与迁移恢复保存原始日志和操作回读；版本绑定实际代码哈希。
- 成本人工、费用、承诺和剩余估计不重复；保留币种和模拟来源。
- 蓝图、分线里程碑和最终交付的确认均绑定精确版本，模拟确认与真实客户接受分开。
- 行政结项、质保移交、质保结束和义务解除分别显示；本案例质保继续，不能宣称全部结束。
- 所有 DOCX/XLSX 可重新读取；渲染和浏览器检查与结构检查分别记录。无法检查的内容保留缺口。
- 审阅页在桌面与 390px、浅深色主题下检查导航、筛选、无结果状态、下载及页面溢出。
- 独立审核保留发现、整改、复核范围、未验证事项和交付建议。

## 验证边界

不连接真实 ERP，不执行生产部署，不伪造真实客户签字、UAT、培训或财务凭证。成功结果只证明这条本地模拟交付路径及已有工程夹具；安全认证、真实负载、实际 ERP 兼容性和商业验收须另行验证。
