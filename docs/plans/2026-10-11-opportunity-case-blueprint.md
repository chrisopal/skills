# 连续商机案例与页面蓝图

## 范围与真实性

以虚构的华辰装备售后工单平台为一个连续商机，展示首次拜访到合同签署的完整过程。所有客户、价格、评审和签署事实均为模拟输入；运行层的分析、增量写入、阶段校验、文件登记及回读实际执行。业务 Skill 是 Agent 执行指引，不将 CLI 日志冒充七个独立 Agent 调用。售前本次交付需求与两版方案工作稿，不扩展为 PPT 制作、真实 POC 或对外发送。

## 页面与操作

- 操作者：销售负责人、售前、商务及交接负责人。主任务是理解每次新证据如何改变判断与下一行动。
- 一个案例入口，左侧按业务日期导航 12 个时间点；首次拜访、需求、资格判断、方案 V1、客户退回、方案 V2、预算、报价、竞争介入、谈判、合同待签、签单。
- 每个时间点五个工作面：概览与评估、方案与客户评审、竞争与决策链、商务与合同、Skill 交接。展示截至该时点的有效数据，历史页面不泄漏后续签署与价格。
- 概览保留正式阶段与本次决定、真实运行层评分、18 个维度分组雷达、评分变化依据、责任明确的下一行动；链接同时间点运行层原始详情。
- 评审表以问题 ID 连接客户意见、需求、方案修订、责任与关闭证据；竞争表保留已知条件、来源及未知项；商务表保留方案/报价/谈判/合同版本。
- 原文、方案、评审、报价、合同均有实际文件链接。仅导航、页签、主题与原生展开可操作；不增加虚假编辑、审批或签约按钮。此为本地案例阅读工作台，不宣称 CRM 已上线。

## 视觉与状态

复用 enterprise-ui-design 的语义 Token，平面细边框、220px 侧栏、48px 顶栏、14px 正文和24px标题；亮/暗主题成对生成。桌面双列、手机单列，表格仅容器内滚动。每个时间点有完整、部分信息、未开始与已完成状态；静态案例不制造网络加载/权限错误状态。引用可下载，键盘页签焦点可见。

## 实施与验收

1. 编写可复用的分时模拟输入与两版方案/评审/商务文件，评分仅在相关证据变化时更新。
2. 用已有 CLI 顺序分析和管理同一 ID；每个时间点立即输出不可覆盖的生命周期、详情与评估数据。客户退回不自动推进；竞争介入评分下降；未签署赢单请求须失败且版本不变。
3. 从回读数据生成案例页面与总表；复用现有雷达生成逻辑，不复制评分公式。
4. 自动核验单商机、证据时间隔离、意见关闭、报价绑定、合同金额、阶段历史和本地链接。浏览器核验亮暗/窄屏、页签、文件链接及截图。
5. 更新 Skill 入口与 STATUS，验证后仅提交可复用源文件/文档并推送；输出、DB、截图留在 output。
