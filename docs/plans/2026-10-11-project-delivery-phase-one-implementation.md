# 项目交付 Skills 第一批落地计划

依据：2026-10-11 已认可的项目交付设计。范围为软件定制开发与系统集成。

## 交付范围

17 个技能：orchestrator、source-intake、contract-handover、initiation-kickoff、master-planning、discovery-planning、meeting-records、requirements-baseline、business-blueprint、progress-control、resource-timesheets、cost-expenses、risk-issue、change-control、reporting、milestone-acceptance、artifact-review，统一使用 `delivery-` 前缀。

第一批蓝图支持流程、UI、字段/权限、接口、验收场景附件；不提前宣称已实现第二批专业开发、迁移或上线技能。使用现有工程记录作为验证输入，不造真实客户确认。

## 工作分工与顺序

1. 定义共享产物契约和行为测试，先观察缺失工具/规则的失败。
2. 内容任务：17 个独立 Skill、可安装引用、Markdown 文档模板、CSV 台账模板和模板索引。
3. 主任务：标准库项目运行工具、单写登记、版本/来源回读、基线与变更应用、工时成本去重、确认/审核绑定、客户包准备、安装/套件校验。
4. 展示任务：复用现有 Office 库导出可编辑 DOCX/XLSX 模板；Enterprise UI Design 蓝色只读审阅页。无需引入依赖或生产部署。
5. 集成：结构/单元测试、隔离目录安装及真实安装回读；完整模拟项目运行及失败分支；Office 文件和浏览器实际回读；独立业务/代码复核。
6. 记录验证范围、更新 STATUS，提交和推送本轮相关源码/模板；项目案例和截图保留本地。

两个内容/展示任务可并行，但各自仅写分配目录；运行工具/索引由主任务维护。共享项目采用单写者。

## 关键验证

- 未确认蓝图不能伪装成客户确认；确认绑定精确版本/范围/来源，模拟确认始终标注 simulation。
- 来源或产物外改、引用漂移可检出；旧正式基线不因候选稿登记而被覆盖。
- 已批准变更先待应用，完整检查候选集合/依赖后一次激活；失败保留旧集合。
- 差旅申请/发生/报销/付款不重复计成本；外包工时不与结算重复累加；未知工时/费率不当作零。
- 客户包仅输出选定且允许对客的产物；内部财务信息不随依赖一起复制；实际外发和客户接受不由工具推断。
- 安装有差异先停止，不覆盖已有技能；安装后引用和工具可用。
- 模板有真实业务字段且可编辑；审阅页展示真实台账、缺口和证据，不放装饰指标或假按钮。

## 验证限制

模拟案例证明流程与工具集成，不代表真实客户验收。Agent 负责提取/判断；CLI 不认证确认人身份，不执行转录、工程开发、财务审批、外发或生产上线。DOCX/XLSX 渲染与语义/计算检查分别记录。
