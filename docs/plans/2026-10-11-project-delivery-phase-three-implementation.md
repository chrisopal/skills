# 项目交付 Skills 第三批实施计划

沿用已批准第三批范围，版本升级 0.3.0，补齐最后一个业务 Skill `delivery-closure-warranty`，总计 25 个。新增 11 套模板（5 Markdown、6 CSV），总计 58 套；复用总控和既有领域主账，不为视图/映射重复增加业务 Skill。

1. 收尾与质保：行政结项、责任移交、质保结束和全部履约分别计算，保留剩余义务、实际接收、资源释放、结算与归档引用及历史。
2. 项目模式：固定价/工时/混合计费，阶段/迭代/混合交付，按合同计费流明确币种、费率、封顶、验收/付款条件；计算仅为估算，非收入或发票。
3. 客户模板：以版本化目标字段规格与原模板为依据，精确映射输入字段、类型/必填/缺失、不适用理由；本轮实现 JSON 字段填充文件，复杂 Word 版式仍交文档工具按原模板制作并回读。
4. 多项目：只读读取实际项目快照，保留截止日、来源/hash、币种和缺口；拒绝重复项目和模拟/真实混算。人员负荷必须显式共享身份映射，不根据同名默认合并。
5. 系统交换：字段映射复用客户模板机制，准备 task/code/finance/document 的入站候选或出站文件；稳定操作/内外 ID、内容哈希及收据核对。既有连接器由 Agent 按实际授权调用，本工具不发网络请求或自动回写主账。

验证按收尾门槛、计费计算、字段映射、交换收据、多项目统计分段进行，覆盖空值、冲突、版本漂移、跨修订删除、重复/错币种/同名人员和模拟边界；再全量回归、独立行为复核、Office 实际导出回读、现有企业蓝审阅页验证和安装哈希比对。生成物留 output，验证后按仓库规则提交并推送。
