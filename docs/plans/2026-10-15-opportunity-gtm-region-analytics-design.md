# GTM 省市联动分析设计

## 范围与界面蓝图

沿用现有 GTM 工作台、行政区匹配、企业 UI tokens、六个记录页和当前计划快照。顶部「全国汇总」漏斗固定不变；分析页标题为当前省市，八项紧凑指标同时标全国值：企业、活动/渠道、实际跟进、有效线索、关联商机、已记录成本、缺少费用、签署金额。全国状态只显示一组数值。下方连续表格展示筛选企业、跟进（含计划）、渠道、活动与当前关联商机。空区域明确显示无对象，金额未知。保留原来的主操作与主题切换，不增加管理层、接口或依赖。

Keep：地图专业画布、表格/表单、主题和全国 API 统计。Adapt：分析页范围、指标对照、明细与归属口径。Retire：分析不随地图联动的说明、区域选择后仍混入全国商机和跨区跟进的行为。

## 统计边界

分析和记录页使用同一份 visibleObjects（省市、区域、类型、关键词交集）。跟进、商机、费用按可见目标企业归属；活动/渠道按可见举办地点归属。异地活动的跟进仍属于客户所在地，不因活动所在地重复算成本；活动行仅统计当前可见企业的已登记关联。类型筛选只看活动时企业指标为空，页面明确说明当前筛选范围。

实际跟进截至 min(as_of,今天)，计划和未来记录单独显示，不计实际成本/漏斗。商机关联截至 as_of；阶段/评分为当前回读，签署来自有效签署事实。企业里程碑去重累积；商机金额按 opportunity_id 去重，费用按币种分别累计；未登记费用保留未知。纯选择函数用 Python 原统计结果作一致性测试，避免漏斗与金额口径漂移。

## 验收
