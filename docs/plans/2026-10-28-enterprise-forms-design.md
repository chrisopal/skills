# Enterprise UI Design：表单构图与可操作参考

## 需求与基线

用户要求从 Git 更新 Enterprise UI Design Skill，改善不专业的表单设计，并展示多种表单。基于 origin/main `c74460d8` 隔离实现，保留原工作目录及本机安装副本的独有增强。截图是问题证据，不是要像素复刻的设计目标；没有实际应用源码，不能推断是 CSS 丢失或修改宿主 LIMS。

## 设计决定

统一字段结构、宽度、标签/控件/反馈间距、组间层级与动作区；按任务选择不同构图。优先采用分组编辑与轻分隔，简单任务可紧凑设置；复杂有前后依赖的申请才用步骤；重复明细用主从结构；局部修改用抽屉。拒绝全站统一 Wizard、每字段一张卡及纯换色变体。

样品签收参考截图的问题：身份、可编辑办理、只读事实、附件、库位和历史责任分开。保留必要业务字段及量差，不假设零值非法、不更改真实状态；示例明确为模拟，本地保存不称后端签收完成。身份/表单/历史各有唯一展示位置，不通过隐藏错误或缩小字体降低长度。

视觉：使用现有 Enterprise 语义 Token，蓝色默认动作；标准控件映射现有高度，标签持续可见，14px 正文、12px 辅助/反馈，20px 面板 inset、20px 字段纵距、24/32px 组距。浅色白底/中性边框，深色正确继承，不采用泛化渐变/玻璃/大阴影；容器驱动减列，390px 维持16px页面边距。已有组件优先，参考 CSS 仅作用于参考容器。
