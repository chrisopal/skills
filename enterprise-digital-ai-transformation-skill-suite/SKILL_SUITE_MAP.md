# Skill Suite Map

> Version 1.2 — Enterprise Architecture Skills use Huawei 4A as the canonical model; every stage ends with an independent quality review.

| 序号 | Skill | 主要职责 |
|---:|---|---|
| 0 | `dtx-consulting-orchestrator` | 管理项目状态、依赖、任务卡、人工门禁与子 Skill 调用顺序，并强制 4A 架构完整性。主 Skill 只做编排。 |
| 1 | `engagement-scoping` | 将客户诉求、合同边界和管理层预期转化为项目章程，并在 G0 建立华为 4A Architecture Framework Profile。 |
| 2 | `evidence-factbase` | 把文档、访谈、数据、观察和外部研究转化为可追溯的 Evidence、Fact、Assumption 与 Glossary。 |
| 3 | `strategy-value-agenda` | 把企业战略、经营目标和管理层关注点转化为价值议程、结果指标与转型设计原则。 |
| 4 | `external-benchmark-maturity` | 基于可配置成熟度模型和行业参考包，对 Operating Model 与 4A 能力进行证据化评分并定义目标成熟度。 |
| 5 | `as-is-operating-model` | 建立现状价值链、价值流、能力、流程、组织、治理、KPI 与痛点模型，作为 As-Is BA 的唯一业务源模型。 |
| 6 | `as-is-enterprise-architecture` | 将现状业务模型正式化为 BA，并建立 IA、AA、TA、横向视图及 4A 追溯矩阵。 |
| 7 | `issue-root-cause-opportunity` | 把分散痛点转化为有证据的 Issue Tree、根因链、影响量化和转型机会主题。 |
| 8 | `to-be-operating-model` | 围绕价值议程设计目标价值流、能力、流程、组织、决策权、治理、KPI、人才与工作方式，作为 Target BA 的业务源模型。 |
| 9 | `to-be-enterprise-architecture` | 将目标 Operating Model 转化为目标 BA，并设计 IA、AA、TA、横向架构和 Transition Architecture。 |
| 10 | `ai-transformation-overlay` | 分别设计 BA+AI、IA+AI、AA+AI、TA+AI，并补齐评测、Trace、安全和治理。 |
| 11 | `gap-initiative-design` | 按 BA/IA/AA/TA 与横向视图比较 As-Is/To-Be，形成 Gap、Initiative、工作包和依赖图。 |
| 12 | `portfolio-business-case` | 对转型举措进行价值、可行性、风险和依赖评估，形成投资组合、三年预算和价值实现模型。 |
| 13 | `roadmap-governance-change` | 把投资组合转化为按 4A Transition Architecture 演进的路线图、治理体系和变革计划。 |
| 14 | `scenario-process-detail-design` | 对优先灯塔场景下钻到 L3-L5，并同步形成 BA/IA/AA/TA 实施级需求。 |
| 15 | `transformation-storyline-builder` | 将已审批成果编排为管理层故事线、4A 蓝图页面和结构化 Slide Content Pack。 |
| 16 | `consulting-quality-review` | 独立检查证据、4A 完整性、跨域追溯、数字口径、逻辑链和 Gate 退出条件。 |
