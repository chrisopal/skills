# 咨询阅读版 PPT 排版契约

版本1.0.0；机器配置为 `shared/assets/consulting-ppt-style.json`。
这是本项目确认的阅读型咨询报告规范，不宣称麦肯锡等机构统一采用这些字号。

## 字号与字体

所有字号均为最终PowerPoint的pt：封面32，章节28，普通标题24，
分组标题18加粗，正文及流程节点18，表格/图表标签/次要解释14，
来源/脚注/页码12，独立关键数字28。表头14加粗，单位14或18。
重要假设、风险、审批边界必须用正文，不能藏进12磅脚注。
中文微软雅黑、英文数字Arial；先检查字体安装，替代时登记并重新渲染。
此配置只影响当前选定项目，不改PPT Skill全局默认值。

1280×720 SVG 对应13.333×7.5英寸时，pt=px×0.75：
正文24px，标题32px，表格18.67px，脚注16px，封面42.67px，章节/数字37.33px。
不要把SVG的18px当成PPT的18pt，也不要用缩放整个图组规避字号。

## 版式

16:9白底、深灰正文、深蓝重点；扁平细线，固定标题和页脚。
左右各0.5英寸，双栏间距至少0.3英寸，正文左对齐，
连续段落目标1.15倍行距，独立条目可增加段间距。
标题最多两行；超量时精简、重排或拆页，不静默缩字。

| 页面 | 主结构 |
| --- | --- |
| 诊断 | 约60%证据与问题，40%根因假设及验证；也可共同比较网格 |
| 方案比较 | 2—3列相同维度，清楚说明推荐及代价 |
| 流程 | 图为主体；包含、执行、条件分开，节点18pt |
| 架构 | 总览与分域分开；文字清单不能替代边界和追溯 |
| 组织绩效 | 权责与KPI分区，保留口径及反向约束 |
| 投资 | 表格/图加结论；单位、期间、现金口径和假设可见 |
| 路线图 | 时间与工作流/波次、依赖、退出条件；非比例波次明确说明 |

不强制每页采用同一组圆角卡片；不放咨询公司或慧新全智标识。

## 交给 PPT Skill 的必需输入

总控创建独立渲染任务，传递：内容包ID/版本/哈希、样式配置ID/版本/哈希、
逐页角色及图表规格、用户内容与样式确认记录、目标格式和可编辑性要求。
渲染器必须先读取自己的SKILL，再把pt换算到其坐标体系。
拆页先回写新内容包和页码映射，不能以14页旧内容包验收24页新稿。

## 导出验收

1. 回读PPTX中的DrawingML字号；普通标题24、正文/节点18、表格14、脚注12。
2. 核对封面、正文、表格、复杂流程样本的文字角色，不仅检查允许字号集合。
3. 核对全部页数、顺序、关键数字、来源、模拟标识和讲稿。
4. 在目标Office中复开，导出PDF检查24页或实际全部页，不以SVG预览替代。
5. 登记实际字体、渲染器版本、文件哈希和检查结果；技术通过不授予业务批准。
