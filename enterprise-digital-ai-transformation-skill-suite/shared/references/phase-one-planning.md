# 第一阶段：企业级转型规划交付约定

适用 `enterprise-planning`；保留 17 个技能，选择 G0—G6、G8，不调用 G7 实施级场景设计。输出是供管理层审议的诊断、蓝图、组织绩效、投资与路线图，不等于招标规格、工程设计或项目验收。

## 范围与流程层级

- 在 G0 明确企业、集团/分公司/工厂、价值流和工厂类型的边界，记录各实体共性与差异。
- 本工作流统一：L1 业务域 → L2 流程组 → L3 流程 → L4 子流程。每个下级仅有一个层级父节点；端到端跨域关系另记，不能以部门树替代流程树。
- 纳入范围的流程目录覆盖四级；不得为凑层级虚构现状。无资料的现状节点标待调查，未规划的范围标排除/待确认，不得宣称覆盖完整。
- L4 至少有 ID、父 ID、名称、目的/结果、触发、输入输出、责任角色、上下游、KPI、信息对象、应用服务、现状问题/目标变化、证据或设计假设。目标和现状分离，BA 引用 OM 相同节点。
- L4 是规划级子流程，不要求操作步骤、表单字段、接口报文、PLC 参数或测试用例；这些属于后续 L5/实施专项。
- 既有 `full-transformation` 等工作流的 L0-L3 沿用旧项目定义；不得与本 profile 直接混号。切换须登记语义映射、版本和覆盖差异。价值流层级也不能当作流程层级。

## 必交成果与最低深度

| 成果 | 必须可检查的内容 |
|---|---|
| 诊断 | 调研覆盖、事实/观点/假设隔离、现状4A、根因、影响与价值议程；评分有等级判据及证据 |
| BA与运营模式 | 四级流程目录、能力和价值流、集团/分公司/工厂责任、跨层级决策与例外升级 |
| 组织绩效 | 每个关键决策一个最终负责角色；KPI公式、单位、粒度、统计周期、来源、基线、目标、Owner、汇总规则、反向约束指标、激励适用条件；基线未知不得填数字 |
| IA | 核心业务对象、权威来源、数据责任、质量、信息流、指标口径、主数据与权限；不得省略此域 |
| AA | 应用域/服务边界、L4子流程与IA对象映射、CRUD/权威系统、集成语义/方向/频率/失败处理、利旧/改造/新建/整合/迁移/退役 |
| TA | 支撑AA/IA的技术服务、集团/工厂/边缘逻辑部署、IT/OT分区、断网降级、安全、容量假设、可用性/恢复目标、运维责任与成本；不承诺未经调研的设备协议或性能 |
| 投资 | 举措到差距/架构/KPI追溯；成本类别和年度现金流、收益归因去重、基准/保守/积极情景、资源与预算约束；估算、报价、财务批准分开 |
| 路线图 | 试点选择、推广条件、各波次4A状态、前置依赖、资源、数据迁移/双轨/退役/回退、责任、采用和收益复核 |
| 管理层报告 | 引用上述成果的版本和证据，列重大取舍、待决事项与局限；PPT只是同源表达 |

制造业项目读取 [制造业规划工具包](manufacturing-planning-toolkit.md)，选择适用调研/评分/测算底稿；参考材料不自动成为客户事实。

## 启动、阶段追溯与变更

G0 前总控只需初始 project-context、空 artifact-register、workflow-profile、空 gate-decisions/open-issues；由范围技能根据 sponsor-brief、proposal-or-contract、company-profile、known-constraints 生成方法配置草案。缺失客户输入登记并阻塞对应任务；不能要求先有 G0 批准成果才创建 G0 任务。G0 审查可以读取候选章程和候选方法配置，批准后才用于真实下游。

G4 检查目标 BA/IA/AA/TA、Owner、KPI/证据和架构选择，过渡仅为候选状态与演进约束；此时不要求 G5/G6 尚未产生的正式举措和波次。G5 补齐 Gap/Initiative/收益关系；G6 固化 Wave/Transition 和全链追溯。候选波次不得冒充投资决策。

变更申请登记触发原因、受影响 Artifact/Node、当前版本、假设和责任人。证据/基线变动复审 G1—G3 及引用成果；业务流程/组织/KPI变化复审 G4、投资 G5、路线图 G6；IA/AA/TA或AI边界变化复审 G4—G6；仅财务/资源变化复审 G5—G6，并评估目标架构是否受影响。所有相关汇报 G8 重新编排。旧批准版保留可追溯，新版标 draft、下游标待重审，未重审不沿用旧批准结论。

## 模拟验证与人工审批

真实咨询逐阶段独立审查和人工 Gate。模拟案例须在项目、任务、成果及报告标明 `simulation`，数据为合成/公开外部事实/假设，并保留来源分类。可以顺序推演后续阶段的草案，但 Gate 仍为未批准，不能写 approved/客户验收/财务签字，也不能宣称完成真实企业咨询。模拟报告/演示稿只引用显式列出的 draft 源版本，首页及关键数字标注模拟，不得走正式已批准内容通道。模拟检查通过仅代表内部一致性和方法可执行性，不代表客户事实验证或独立批准。
