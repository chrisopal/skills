# Quality Gates

阶段规则：G0可共同审查候选章程/方法配置，不要求事先批准。G4的Transition为候选状态与演进约束，不要求已批准G5举措/G6波次；G5补齐Gap/Initiative/Benefit，G6固化Wave并验证全链。`enterprise-planning` 按 `phase-one-planning.md` 覆盖L1-L4与组织绩效，跳过G7且记不适用。模拟项目可逐阶段推演草案，但所有人工Gate保持未批准；检查通过不是客户核验或审批。真实审批记录必须有审批人、时间和候选版本；变更按该参考的影响规则重审。

| Gate | 必须产物 | 退出条件 | 典型审批人 |
|---|---|---|---|
| G0 Scope | Charter、Scope、Stakeholder、Deliverables、Method Profile | 边界、目标、决策、成功标准、审批人和 4A 裁剪范围明确 | Sponsor / PM |
| G1 Evidence | Evidence、Facts、Assumptions、Glossary | 核心主题证据覆盖达到项目阈值；冲突和缺口已登记 | PM / Domain Leads |
| G2 As-Is | Operating Model、As-Is BA/IA/AA/TA、Maturity、Pain Points、4A Traceability | 业务和 IT Owner 验证；As-Is 未混入 To-Be；4A 关键节点可纵向追溯 | Business/IT Owners |
| G3 Diagnosis | Value Agenda、Issue Tree、Root Cause、Impact | 关键问题与价值优先级达成共识，问题已挂接到 4A 节点 | Sponsor / SteerCo |
| G4 To-Be | Target OM、Target BA/IA/AA/TA、AI Overlay、Cross-Cutting Views、Transition | BA、IA、AA、TA 纵向一致；安全、集成、AI、NFR 完整；关键取舍明确 | SteerCo / Architecture Board |
| G5 Portfolio | 4A Gaps、Initiatives、Business Case、Portfolio | 所有举措可追溯到 Gap、KPI 和架构对象；预算收益有口径；依赖可解释 | CFO/CIO/Business Sponsor |
| G6 Roadmap | Waves、Transition Architecture、Milestones、Governance、Change | 每个 Wave 有 4A 目标状态；资源、依赖、退役、价值实现和变革可执行 | SteerCo |
| G7 Detail | L3-L5、BA/IA/AA/TA Detail、Requirements、MVP、Acceptance | 可进入产品设计、招标或开发；异常、控制、权限、NFR 和运维完整 | Product/Business/IT Owner |
| G8 Deck | Storyline、Slide Pack、4A Blueprint Pages、Citation、QA | 一页一结论；无新造事实；4A 内容与批准 Artifact 一致；管理决策请求清晰 | Sponsor / Engagement Lead |
