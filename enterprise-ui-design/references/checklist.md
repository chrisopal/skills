## 设计与接入

- [ ] 保留目标产品的名称、Logo、业务菜单和信息架构，没有复制来源项目内容。
- [ ] 已识别现有组件库和主题入口，没有引入第二套组件框架。
- [ ] 使用所选品牌的单一动作体系和语义 Token（蓝色仅默认），没有新增零散视觉色值。
- [ ] `action-text` 与 `action-solid/on-action` 分开使用；没有暗色浅蓝按钮配白字。
- [ ] `inverse-surface/on-inverse` 成对验证。
- [ ] 通用Profile的页面、普通面板、按钮无装饰渐变/毛玻璃/光晕/厚阴影；显式Huixin仅使用已声明的受控材质，未扩大到其它Profile。
- [ ] 3D Logo 仅属于明确品牌例外，不把 3D 装饰扩展到日常控件。
- [ ] 14px正文及所选Profile的字号/几何统一：通用默认4px控件/6px面板圆角；显式Huixin按其三层合同覆盖，不修改frozen v1。
- [ ] 已按 [Typography Roles](typography.md) 选择正文、标签、区块、页面标题、指标和元信息角色；没有全局加粗、负字距或假粗体。
- [ ] 中英数字与单位的 requested/loaded/rendered 字体证据分开记录；`μm`、`℃`、`±`、`≤`、`≥`、上下标及 tabular 数字经过实际检查或明确未测。
- [ ] 品牌、Profile、主题、密度分开选择；Enterprise回退、Analytics及显式Huixin支持的主题组合已记录，Portal/Teleport 继承属性一致。

- [ ] 导航图标已按[专项规则](navigation-and-task-surfaces.md#导航图标专项)建立完整语义清单，覆盖折叠/滚动/权限项；检查键及实际图形的重复，合理复用有依据。
- [ ] 在实际导航尺寸、浅深色、桌面/390px 中检查图标辨识、同族线宽/对齐、文字、选中与焦点；路由/权限及移动关闭返回经过操作验证。

## 信息负担与正文密度

按 [提示准入约束](notice-economy.md) 同时核对设计、开发与最终运行结果。

- [ ] Blueprint 已记录常驻提示的当前用途、同义组、展示责任方及出现/解除条件，无必要就不展示。
- [ ] 同屏标签、步骤、摘要、横幅、字段、页脚和当前弹窗无重复完整解释；同次错误不双份播报，例外有独立任务依据。
- [ ] 作业终态、重试、模式/权限/对象/Tab/机构变化后无过期、相反或不可执行提示；必要风险与恢复仍可见。

- [ ] 首屏无口号、功能介绍、点击教学或重复统计定义；常驻文案均影响当前决策。
- [ ] 已按 [Product Polish](product-polish.md) 组织标题、筛选、真实概览、工作面和支持资料；少数据没有靠固定高度、虚构指标或卡片填充。
- [ ] 必要定义和长标识符按需查看，不为每项增加帮助图标。
- [ ] 必填、错误、缺失前提、风险与审批影响仍在对应操作处可见。
- [ ] 方案/文档的标题、状态、操作、元信息、覆盖表和正文分组清晰，长内容与窄屏不拥挤。

流程、详情或工具栏任务还须使用 [流程直观性规范](task-flow-and-hierarchy.md) 和 [评审模板](task-flow-review-template.md)。以下适用项逐项记录证据，未验证不勾选，不适用写理由。

## 流程直观性与视觉构图

- [ ] Blueprint 包含角色、对象范围、阶段/并行分支、事实来源、当前任务、动作、阻塞、交接和结束依据。
- [ ] 已按 [业务组件指南](business-component-patterns.md) 选择模式并写明例外；订单阶段连线、并行任务、历史时间线和输入向导没有混用。
- [ ] 阶段节点和连线有真实状态依据，横向/纵向按实际容器重排；未来节点不伪装为可以直接推进业务。
- [ ] 从入口到结果及返回路径连贯；覆盖实际存在的退回、部分完成、等待他人和失败恢复。
- [ ] 已建立逐流程范围账：角色、目标、入口、完成定义、来源/真实契约，以及 `main`、`recovery`、`handoff` 三类分支声明；不适用分支写 `N/A` 及原因，实际需要的分支可多个。
- [ ] 每一步都有可见 cue、实际 action、预期/实际 result 和路径/截图/回读证据；重复录入、无效往返、上下文丢失和必须记忆的内容只有在有依据时记录。
- [ ] 已按契约检查中断、超时、部分失败、草稿保留、恢复点和跨角色 handoff；未知结果的提交先验证再重试，没有编造后端契约。
- [ ] 当前阶段、子任务进度、整单完成分别表达；没有用绿色标签或局部 2/2 暗示整单结束。
- [ ] 当前待办默认可见且对应可执行入口；只读/等待状态说明真实原因，不强制虚构主动作。
- [ ] 业务动作、筛选与视图工具分组且权重合理；保留宿主要求的按钮边界、焦点和触控目标。
- [ ] 主对象/当前任务优先于重复名称、修订、内部标识和空分支信息；必要证据与警告仍可访问。
- [ ] 已按五个无讲解问题记录答案与实际路径，注明模型走查或真人观察，不用源码解释代替界面答案。
- [ ] 已逐图评审焦点、层级、接近性、节奏、信息经济性、长内容重排与一致性，并定位问题。
- [ ] 业务状态、任务理解、视觉与交互分别给出结果；自动检查/无溢出/截图存在不能替代通过。
- [ ] UX/任务直观性、视觉质量与业务正确性分别判定；模型启发式、模拟或浏览器自动化没有被写成真人用户研究。
- [ ] 真人观察若存在，记录参与者范围及实际完成、错误、回退、求助、耗时等指标；未知保持 Not tested，不使用通用点击数/时限阈值。
- [ ] 窄范围审查只覆盖声明的相关流程；全站审查引用已批准的完整流程清单，不把未批准的全局缺口当作门槛。

## 业务文案覆盖与语义

文案任务按 [业务文案规范](business-copy.md) 建立覆盖清单；非文案任务按实际范围应用。

- [ ] 清单覆盖主/子页面、Tab、弹窗/抽屉、流程分支，以及角色/条件触发的状态、校验和错误反馈；包含共享及服务端文案来源。
- [ ] 按角色和任务决定删除、改写或保留；业务界面不用实现解释，专业管理员必要技术词保持准确，未按关键词机械替换。
- [ ] 草稿/审核、发送登记/客户签收、未知/零值、局部/整单、提交/完成等事实边界保留；必要警告、权限和恢复动作仍可见。
- [ ] 逐项记录改前/改后或保留理由、业务依据、运行证据与结果；未测/阻塞/不适用单列，搜索清零和构建通过不代表全站文案验收。

## 空间、布局与对齐

- [ ] Blueprint 写明页面类型及流式/限宽策略；列表、阅读、表单、专业画布不机械共用同一宽度。
- [ ] Shell、页面、区块、组件的 inset 责任明确；无意的父子 padding 或 gap/margin 叠加已清除。
- [ ] 页面标题与一级区块外框的边线协调；面板内容、筛选与表格首末列的内容线明确，不混淆外框与文字起点。
- [ ] 组内、组间、区块间距表达关系；没有通过层层卡片或全页同一 gap 代替层级。
- [ ] 标签、控件、错误提示及数值列对齐；长文本、状态和换行后的操作组可读、可操作。
- [ ] 读取了实际 padding/gap/max-width 和关键边界；没有仅凭源码或 Token 数值宣称视觉通过。
- [ ] 标准/紧凑密度与浅/深主题独立；正文不因紧凑缩小，触控目标与页面层级仍可用。
- [ ] Profile 只覆盖声明的排版、表面、边框、圆角、节奏与组件表达；数据系列色没有冒充成功/警告/危险状态，默认/hover/focus/disabled 配对实际测量。
- [ ] 侧栏/辅助栏变化、多行筛选、窄可用宽度及低高度浮层下布局重排合理，无页面级横向溢出。
- [ ] 用同状态截图检查了整体层级和节奏；说明参考依据，没有参考图时不报告像素还原或相似度分数。

## 组件与状态

- [ ] 已按[通用场景目录](business-component-patterns.md)读取适用专项；在[组件评审记录](component-review-template.md)写明选型、组合、范围、例外及检查ID，未仅列组件名称。
- [ ] 甘特/日历/看板/阶段/历史表达不同语义；日期、依赖、完成度及图表口径有真实来源，未知不补成数值。
- [ ] 表格变体与任务匹配；筛选排序、跨页选择、父子关系、汇总、编辑与导出范围明确且经过适用检查。
- [ ] Tabs表达同级内容；草稿/过滤/活动项按契约保留，键盘切换与异步加载可用。
- [ ] 抽屉/侧面板/弹窗/独立页按任务规模和对照需求选择；模态性、焦点、关闭保护及返回路径实际验证。
- [ ] 表单联动、重复项、边界值、上传逐项状态和保存恢复真实；错误、Toast、消息条及空状态按范围分工。
- [ ] 有可执行主任务时页面主操作明确；只读/等待页面不虚构主动作，主/次/文字/危险操作的层级一致。
- [ ] 表格与筛选条视觉连贯，排序、分页和操作列没有被样式破坏。
- [ ] 详情按主体/任务/资料语义分组，使用 Descriptions 或 dl 等具名标签/值；短字段响应式排列，长叙述独占整行，不堆连续文字或伪装禁用输入；必要表格/时间线/编辑器保留任务语义（READ-01～03）。
- [ ] 空态在所属内容区居中且有实际四边留白，标题/状态/内容/恢复有层级；实测 padding 和边界并查看桌面/390px 浅深截图，覆盖有数据/空/失败/加载与角色（EMPTY-01～03）。
- [ ] 无记录、筛选空、无权限、对象不存在与失败按契约区分，零待办不推断报告不存在；必要风险/恢复保留，无同义提示重复。
- [ ] 表单标签、错误、帮助文案、必填与禁用状态可辨识。
- [ ] 表单构图符合任务；身份、编辑、只读结果和历史归属清楚，字段边界、组距与正文→动作有统一空间责任。
- [ ] 已走查长标签/量差/错误摘要定位、步骤返回、明细增删、抽屉关闭恢复及桌面/390px/窄容器浅深主题；未以纯换色或控件渲染代表表单专业性。
- [ ] 按钮/输入/选择器的 default、hover、active、focus、disabled、loading 状态都检查过。
- [ ] 按本次范围验证Profile/theme/density组合；通用基线覆盖Enterprise浅/深色与Analytics深色，Analytics浅色按声明回退。采用Huixin时另执行下述三层检查，不产生混合主题。
- [ ] 弹窗、Drawer、下拉菜单、Tooltip 等 body Portal 继承正确主题。
- [ ] 原生自研弹窗与组件库弹窗使用同一中性遮罩和表面层级。
- [ ] 空、加载、错误、无权限、无数据状态均有可理解反馈。

## 响应式与可访问性

- [ ] 用户指定或目标项目相关视口已实际打开检查；未指定时默认1366px、1440px、1920px和390px，不扩大明确限定的范围。
- [ ] 没有页面级横向溢出；必要表格滚动限制在容器内。
- [ ] 长中英文、放大、低高度窗口下主操作仍可达。
- [ ] 聊天输入区、固定页脚和弹窗按钮不被遮挡。
- [ ] 移动导航关闭后退出键盘交互范围；开启/关闭和焦点恢复可用。
- [ ] 键盘焦点可见；纯图标按钮有可访问名称。
- [ ] 普通文本达到 4.5:1、重要控件边界/状态达到 3:1 的本规范验收阈值。
- [ ] 状态和错误不只靠颜色表达。
- [ ] 浅色与深色均验证；关闭不必要动效并保留减少动态效果支持。

## 行为保护与验证

- [ ] 路由、权限、API、表单校验、缓存、语言、工作区和数据行为未被视觉改造改变。
- [ ] 保留经典主题/原主题的回退能力，切换不删除业务数据。
- [ ] 运行了项目现有 lint、typecheck、tests、build；结果与命令已记录。
- [ ] 原有失败与本次新增失败分开列明，没有把警告当作全部成功。
- [ ] 对照目标风格检查了登录、工作台/列表、表单/浮层及专业工作面截图。
- [ ] 明确区分源码完成、视觉验收、真实业务 E2E、构建发布和上线状态。

## Huixin 三层检查（仅显式采用时）

按[框架](huixin-framework.md)、[组件](huixin-components.md)与[颜色主题](huixin-themes.md)记录证据，不适用写理由；来源包历史实测不计为本轮通过。

- [ ] 仅`tokens.json`维护真值：common含字体/尺寸/材质几何且无字面颜色，modes仅含颜色/透明度；生成资源无手改分叉。
- [ ] 实测正文14、标题28、侧栏232、顶栏70、页面28、卡片24，以及控件40/紧凑32、圆角8/16/18；表格最小行高56/44、环图200，未混用来源52/128别名。
