# Huixin · 框架与排版固定层

仅在明确采用 `profile: 'huixin'` 时读取。本层保留2026-10-29提供的慧新视觉结构，覆盖通用Profile的字号、页面壳与空间默认值；不迁移检测、人事等来源业务。颜色交给[主题层](huixin-themes.md)，控件/表格交给[组件层](huixin-components.md)。

## 真值与范围

唯一维护源为 `assets/tokens.json` 的 `profiles.huixin.common` 及现有组件/布局配方；`assets/huixin-framework.css` 只消费生成变量。不要再维护独立 framework.tokens.json，不把本表变成另一个可手改Token源。尺寸、字重、阴影偏移/模糊、渐变角度属于固定层；颜色/透明度属于mode或brand。

在UI Blueprint中记录采用范围、现有PageShell/PageHeader/Panel/QueryBar/DetailPanel映射、滚动责任与响应式变体。保留路由、权限、数据绑定、打印纸张、签章和专业画布。显式采用允许调整页面视觉结构；单纯brand/theme切换必须保留现有DOM、输入、焦点与业务状态。

## 字体角色

| 角色 | 基线 | 用法 |
|---|---|---|
| 页面主标题 | 28px / 1.3 / 600 | 一个页面主标题，对齐内容外线 |
| 区块/弹窗标题 | 18px / 600 | 主要分组；子区块16px/600 |
| 紧凑卡标题 | 14px / 600 | 不把小指标卡统一放大到18px |
| 正文/表格/导航 | 14px / 400；导航400–500 | 名称可600；紧凑密度不缩字号 |
| 标签/按钮/说明 | 13px / 400–500 | 同类标签与控件基线一致 |
| 编号/时间/坐标 | 12px / 400 | 不承担唯一主操作或关键状态 |
| 导航组名 | 11px / 500 | 仅分组，不能推广为正文 |
| KPI数值 | 34px / 700 | 单位14px；tabular数字 |

优先使用 `'HarmonyOS Sans SC','PingFang SC','Microsoft YaHei',-apple-system,BlinkMacSystemFont,sans-serif` 的可用字体，不捆绑未许可字体，也不增加网络字体依赖。记录requested/loaded/rendered字体并检查中英符号；未安装时如实回退。保留通用[排版验收](typography.md)中的角色、混排与证据要求，以上显式角色覆盖其默认字号。新项目按100%逻辑尺寸实现，来源演示的80%壳不属于Token。

## 页面壳与空间

| 对象 | 固定基线 | 责任 |
|---|---|---|
| 桌面侧栏 | 232px | 不被内容挤窄，独立纵滚 |
| 顶栏 | 70px | 左右28px；已有公共工具，不造假按钮 |
| 页面inset | 四边28px | 一个容器负责，避免父子重复 |
| 侧栏内部 | 顶20/横12/底12px | 导航行44px、图标19px、图文12px |
| 标题后/一级区块 | 24px | 有意义的持续纵向节奏 |
| 同行卡片 | gap16px | 按行stretch，不左右独立堆叠 |
| 主从详情 | gap20px | 两个独立表面，顶部对齐 |
| 普通卡片 | inset24px | 表格卡另按列规则 |
| 表单/内部组 | gap20px / 16px | 标签、字段、错误各有归属 |
| 行内操作 | gap12px | 组内紧凑，窄时换行 |

桌面壳可用 `232px minmax(0,1fr)`；主内容 `min-width:0`，不用固定1600px宽或整体transform缩放。主从宽度由任务决定，可从 `minmax(0,1fr) 380px` 起步。表格首末列28px安全边距不与页面外线混淆。布局语义仍遵守[空间合同](spatial-system.md)，其通用页面/面板数值由上述Huixin数值覆盖；显式compact可用自身已声明inset，不与standard叠加。

KPI最小高132px与图表260px预算只用于相应组件，不强制所有卡片等高或填满视口。按同一行内容stretch；资料卡底部动作自然贴底。环图统一 `chart-donut-size: 200px`；来源128px别名不再保留。页面卡数、趋势、列宽与业务字段由宿主真实任务决定，不为了接近截图增加内容。

## 响应式与证据

来源包仅桌面验证的范围不适用于本Skill的交付结论。按约定视口实测；默认桌面1366/1440/1920px与390px。窄屏侧栏转为可关闭导航，关闭后退出焦点序列；页面留白与多列布局按容器重排，表格在自身容器滚动。正文保持14px，不自动切compact。具体窄屏inset以Token/组件配方为准，不把桌面28px强塞进每一层。

对同数据、同视口、同密度的light/dark及各品牌比较实际计算值，框架几何应一致。测量inset、关键边线、长标题/ID、低高度弹窗与同行卡片，再查看截图；无溢出不等于构图通过。采用[本地模拟参考](../assets/reference-huixin/index.html#overview)只能证明声明范围的fixture UI，不证明LIMS/人事系统已接入或业务E2E通过。
