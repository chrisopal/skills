# Tabs、导航、抽屉与弹层

先判断内容是否同级、用户是否必须同时看到主页面、任务持续多久。抽屉是任务承载面，不是图表；不能因为详情很多就不断叠加抽屉。

## 内容组织与导航

| 用户任务 | 首选 | 避免 |
|---|---|---|
| 在同一对象的概况、明细、历史之间切换 | **Tabs＋对应内容面板** | 不用Tabs表达已完成/当前/未来阶段；跨页业务主导航应使用路由导航 |
| 同一数据切换列表/看板、日/周视图 | 分段控件/视图切换 | 不把展示格式和对象内容混为同级Tab；切换保留有效过滤 |
| 阅读长详情并快速定位各节 | 锚点导航＋连续正文 | 需要同时比较的内容不藏进多个Tab；标题/目标位置有可读上下文 |
| 导航到模块与子模块 | 侧栏/顶部导航＋当前项 | 不以Tabs堆叠整套应用；折叠菜单仍能辨识当前路径 |
| 了解当前位置并回到父层级 | 面包屑＋页面标题 | 面包屑不是访问历史；标签和层级来自真实IA |
| 按需展开低频辅助信息 | Disclosure/折叠面板 | 当前阻塞、必填错误、主要操作不能默认藏起来 |
| 在很多对象间查找 | 搜索/筛选＋结果列表 | 搜索范围与权限清楚，不为每页装饰一个无效全局搜索框 |

### 导航图标专项

- 按业务对象或任务选择图标，让不同含义的入口可辨。不要把文档、流程、设置等通用图形机械分配给多个不相关模块；例如原始记录、标准、客户模板可以分别用记录页、书本、带客户标记的模板。
- 同一语义、同类公共动作可以复用；在 Blueprint 记录例外。目标是语义明确，不是所有图标强制唯一，也不为消除重复换成无关图形。
- 优先复用宿主图标库/注册表，保持网格、线宽、尺寸和 `currentColor` 一致；缺少适配图形时最小扩展现有图标族，不引入第二套依赖、Emoji 或混杂风格。
- 保留清晰文字标签，图标作为装饰时从可访问名称中隐藏；不能仅靠颜色或图标区分入口。检查实际导航尺寸下的轮廓，细碎差异在 16px 下可能无法辨认。
- 建立完整菜单的“标签 → 路由 → 业务含义 → 图标键/实际图形”清单，覆盖滚动区域、折叠项、动态权限项和移动抽屉。同时按键和实际图形查重，避免不同键映射相同 SVG；逐组判断重复是否合理。调整图标不得改动路由、权限、分组及选中规则。

### Tabs 专项

- 一个Tab对应一个稳定的同级主题，名称简短且可区分。计数仅展示真实同范围结果；徽标数量不当作装饰。
- 主对象摘要和跨Tab操作放在共同区域；仅对当前内容生效的操作放在面板内。没有内容权限时不能仅靠隐藏Tab充当授权。
- 面板切换保留应保留的筛选、滚动与草稿；深链接/刷新是否恢复活动Tab由产品契约确定。无保存机制时不得悄悄丢失编辑内容。
- 用 `tablist/tab/tabpanel`、`aria-selected` 和关联关系实现真正Tabs。横向方向键移动Tab焦点，Tab键进入面板；异步内容明显延迟时优先手动激活，方向键只移焦点、Enter/Space激活，避免每次方向键都阻塞。
- 异步请求与面板身份绑定；快速A→B切换后，A的迟到响应不得覆盖B。加载、失败和重试属于对应面板，切回按宿主缓存/刷新契约处理。这是业务交互要求，不是仅增加ARIA属性即可满足。
- 标签过多先检查分组；窄屏可用可识别的横向滚动/更多选择，当前项必须可见且可键盘到达。不以省略号掩盖所有相似标签，也不机械堆多层Tabs。

## 任务承载面选型

| 情况 | 首选 | 关键边界 |
|---|---|---|
| 连续查看记录，需保留列表定位 | **详情抽屉 Drawer** | 短详情或轻编辑；打开后对象身份清楚，关闭恢复触发记录焦点 |
| 操作时必须同时看主表或预览 | **非模态侧面板/inline drawer，或主从布局** | 主区域仍可交互，不设置假模态焦点陷阱；宽度不足转适合的任务页 |
| 短而聚焦的创建/编辑，需暂时停留在任务 | 模态抽屉或Dialog | 明确提交/取消/关闭；背景不可交互。以内容规模和上下文关系选择，不能只看字段数 |
| 确认删除、撤销、签发等明确决策 | 确认Dialog＋对象/影响＋具体动作名 | 不用模糊“确定”掩盖后果；普通浏览不弹确认 |
| 长表单、多步骤、复杂明细、文档持续工作 | 独立页面或工作区 | 不将整页压进窄抽屉；返回保留来源上下文 |
| 当前控件旁少量补充内容或轻操作 | Popover | 有交互就不是Tooltip；支持键盘、关闭、合理焦点和遮挡处理 |
| 对术语/图标提供简短补充说明 | Tooltip | 不能承载必读错误、唯一操作或可点击表单；触屏不依赖hover |
| 多个低频命令 | 操作菜单 | 菜单项是命令，选项值用选择器；危险动作与常规动作区分 |

### 抽屉与弹窗专项

- Blueprint 明确模态/非模态、打开来源、初始焦点、保存范围、关闭路径和数据丢失保护。外观在侧边不自动意味着模态。
- 头部显示对象身份；可关闭的抽屉/Dialog有可见关闭路径。持久非模态侧面板可以按宿主布局保持展开，不强加关闭状态。正文按任务分组，底部只保留当前任务操作；标题/底部固定以不遮挡内容为前提，低高度、软键盘和放大时允许自然滚动。
- 宽度依据内容决定。只看摘要可以较窄；编辑多列/阅读文档应给足空间或用全页。390px可全宽，但必要主上下文须能恢复。
- 模态打开后焦点进入合理位置，Tab循环在其中，Esc提供关闭路径，关闭恢复触发点或合理后继位置。背景真正不可操作；非模态不套用这个焦点陷阱。
- 有未保存修改时，Esc/遮罩/关闭/切记录遵循同一保护规则；不默默丢失。关闭确认应清楚表达放弃修改，保留可返回编辑的路径。
- 加载、保存失败、对象被删除、权限变化在当前面板解释；不得显示上一个对象的资料冒充新对象。不要把全页失败都塞成短暂Toast。
- 避免多个并列/层叠抽屉。需要关联对象时优先在当前面板替换并提供返回，或转独立页；确需嵌套确认时逐层管理焦点、层级、Esc及主题。

## 可观察验收

| ID | 检查动作 | 通过条件 |
|---|---|---|
| NAV-01 | 解释每个Tab/导航项，寻找一条具体信息 | 同级含义明确，步骤/历史/视图切换不混用；无需逐页猜测 |
| NAV-02 | 方向键/Enter/Space切Tab，快速A→B并让A晚返回，触发失败/重试、刷新与返回 | 激活符合模式，活动/焦点可辨，迟到结果不覆盖当前面板，错误与缓存按面板/契约处理 |
| NAV-03 | 编辑后切Tab、切记录或离开 | 草稿保留或明确处理，错误所在面板可定位 |
| NAV-ICON-01 | 展开/滚动完整菜单，对照路由、标签、语义及实际图形，复查重复组 | 不相关入口具有可辨且相关的图形；合理复用有依据，无缺图/别名重复，路由和权限保持正确 |
| NAV-ICON-02 | 浅/深色、桌面/390px 打开导航，查看实际尺寸图形，操作选中、键盘焦点和关闭返回 | 同族线宽/尺寸/对齐一致，轮廓清楚，文字和焦点可读；移动导航可达且关闭后焦点合理恢复 |
| SURFACE-01 | 从记录A打开抽屉，再查看B | 标题、范围、内容、操作都属于当前对象，无陈旧数据串位 |
| SURFACE-02 | Tab/Shift+Tab、Esc、关闭、重开 | 模态焦点约束正确，非模态不误困住；关闭后焦点合理返回 |
| SURFACE-03 | 未保存时走所有关闭路径，模拟保存失败 | 无静默丢失/假成功，错误与恢复入口可见 |
| SURFACE-04 | 390px、低高度、200%/400%放大及浅深主题 | 标题/正文/按钮可达，浮层不裁切，背景/遮罩与主题一致 |
| SURFACE-05 | 内容很长或需同时对照 | 所选承载面仍支持任务；否则调整为主从/独立页，不硬压缩 |

截图检验构图，键盘与关闭路径必须实际操作；按[组件评审模板](component-review-template.md)保存证据。

## 设计依据

查阅：2026-10-18。用途来自以下官方资料，本文的业务组合与验收条件属于本 Skill 的适配。

- [Carbon Tabs](https://www.carbondesignsystem.com/building-blocks/core/components/tabs/guidelines)：组织同级内容；需要并行比较时选择别的布局。
- [Fluent Drawer](https://fluent2.microsoft.design/components/web/react/core/drawer/usage)：补充内容/轻任务、inline与overlay差别，以及复杂任务、缩放、关闭保护的考虑。
- [Ant Design Drawer](https://ant.design/components/drawer/)：抽屉组件能力参考，映射到宿主的实际版本与主题接口。
- [WAI-ARIA Tabs](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)和[Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)：键盘、角色、焦点与关联语义。实现这些约定不等于已完成全部可访问性验收。
