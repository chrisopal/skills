# 运营工作台的布局决策

适用：指标首页、宽表、审核队列、统计编辑器和权限详情。与[空间规范](spatial-system.md)、[表格工作区](tables-and-data-workspaces.md)、[计划与可视化](planning-and-visualization.md)一起使用；这里只补充实际反馈暴露的决策边界，不另定配色、尺寸或组件体系。

来源：LIMS 飞书 UI 优化视图 2026-10-23 导出，20 条非空 UI 问题；项目原件 `artifacts/ui-optimization-20261023/issues.ndjson`。“修改意见”是待分析的建议，须结合任务、数据与宿主组件采用，不能逐字变成通用强制要求。record_id 仅作案例追溯，未表示已修复或已验收。

## Blueprint 增量

为相关页面记录：主阅读对象与重点指标、真实告警阈值、栅格跨列/断点、表格关键列和详情载体、内容高度/分页归属、长文完整访问、排序交互、权限分组和查询语义、编辑与预览关系。沿用既有 Blueprint，不新建重复门禁。

| 规则 | 设计决策与适用边界 | 来源 record_id |
| --- | --- | --- |
| EUI-O01 指标重点与状态分离 | 先确定哪些数值支持当前决策，再用宿主主题强调色与字号层级突出；不要所有数字一律高亮。到期、临期、正常、未知依真实日期/阈值分别表达，警告/危险用对应语义 Token，加文字或图标，不能只靠颜色。品牌色不是告警色，零值不是自动危险，未知不能伪装正常。 | `reczz28PxRVL4R1U`、`reczz28PxVjndsVr` |
| EUI-O02 连续响应式指标网格 | 同层指标沿一套网格、inset 和高度节奏排列；宽卡跨列须有内容理由。四列仅是满足内容最小宽度时的一种桌面配置，窄屏降列。尾卡优先通过合理分组/跨列消除视觉孤岛，不造指标、空卡或拉大间距填洞；不以强制等高裁掉内容。 | `reczz28PzkPi2ZLX` |
| EUI-O03 单一指标导航 | 一个指标到同一明细目标只保留一种主要入口：整卡链接或标题旁动作。可点击性在默认态可识别，键盘可达且名称含指标语义；整卡内不得再嵌套同目标按钮。必要的不同操作单独表达，不能因去重丢失目标筛选/权限。 | `reczz28Q07thJwjC` |
| EUI-O04 宽表优先保住可比信息 | 按任务、列宽与实际容器选择全宽列表＋按需详情抽屉、独立页或可收起分栏；不能仅按记录数切换布局。默认保住编号、名称、状态和必要行操作，次要字段可进详情；长期执行任务沿用独立页契约。用长中文/编码检查主字段不逐字折行；用户列偏好、排序、分页、选择、返回及焦点契约不丢。 | `reczz28Pzrgxiqlq`、`reczz28Q00Vh0tjL`、`reczz28Q0CZE7C2L`、`reczz28Q0EnEmXFd` |
| EUI-O05 行节奏与长文访问 | 标识/状态采用稳定单行节奏，说明按内容允许一至两行截断；不可将统一行高作为丢信息的理由。完整值须在详情、展开或可键盘/触屏访问的浮层中读取，原生 title 或仅悬停不足以覆盖移动端。操作成组，不被长文挤走。 | `reczz28Q07VaG8Z0` |
| EUI-O06 安静而可发现的排序 | 当前排序列持续显示方向；非活动列降低图标权重，可在 hover 与 focus-visible 时突出，表头默认仍保留可排序线索。使用实际表头按钮及 aria-sort，统一图标/文字基线与间距。不把排序图标设为仅鼠标用户才能发现的入口。 | `reczz28Q0JccZyt8` |
| EUI-O07 空区与内容高度有归属 | 无待办的子面板使用短空态；没有信息或动作价值时不占整块空间。沿用 [EMPTY-01～03](forms-and-feedback.md#只读详情与空状态构图)，不把零队列写成对象不存在。自然列表由内容决定高度、分页紧随内容；仅明确的滚动工作区才占剩余高度。可按真实可用空间调整每页数，但不造空行、重复记录或巨大 min-height 填满页面。 | `reczz28Q0EmHds3G`、`reczz28Q0GhwvvQO` |
| EUI-O08 统计选择、编辑与预览相邻 | 报表清单保持可读选择宽度并可按任务收起；编辑字段按业务组组织，宽屏可双列，长字段跨列。足够宽时编辑与预览相邻，窄屏顺序排列或切换，预览保持容易到达。固定/吸附预览不得遮挡控件或抢占全部高度；未生成只保留紧凑状态和真实生成动作，区分当前参数与过期预览。 | `reczz28Q0EnvLq8K`、`reczz28Q0GfvERxg` |
| EUI-O09 权限摘要与分组读取 | 角色表显示权限数量与主要模块摘要，详情按宿主业务模块分组、按需展开；权限很多时提供名称/模块搜索与展开/收起。数量明确是已授权、搜索命中还是总权限，不混分母。只读查看与授权编辑分开，过滤/折叠不能改变已授权值；同名权限保留稳定身份，未知权限不能静默丢失。 | `reczz28Q0Ggfj5zB`、`reczz28Q0GhJLtec` |
| EUI-O10 长值不破坏只读字段 | 复用[结构化只读字段](forms-and-feedback.md#只读详情与空状态构图)：按设备身份、归属、状态等语义分组，标签列/值列对齐，长名称独立换行，窄屏标签和值依次显示。不要缩小标签、挤成逐字竖排或做成灰色禁用输入。 | `reczz28Q0JfezQuQ` |
| EUI-O11 日期条件构成一个查询组 | 开始、结束日期和应用筛选在宽屏同一工具组，标签/控件对齐；窄屏按阅读/焦点顺序换行。明确指标时间字段、时区、包含边界及临时/已应用条件；与筛选无关的动作不能插在范围中间。沿用 EUI-F05 的查询一致性，不用视觉排列掩盖请求范围错误。 | `reczz28Q0Pk7ikYf` |
| EUI-O12 图表/数据表切换重排 | 同一数据的图表与表格共用范围、状态与选中视图，切换时按真实内容重新分配卡片宽高。表格有完整可读区与受控局部滚动，图例/状态/空态靠近所属内容；相邻卡片独立布局，不用绝对定位填洞。稀疏数据选择紧凑表达，不以假数据或放大图形填空。 | `reczz28Q0PmM3BZY` |

`reczz28PzukZn7wd` 的行内原始错误复用 [EUI-F08](feishu-lessons.md)：列表只呈现简短业务异常和真实恢复入口；技术详情按需查看。避免再次加入“异常说明＋重试提示＋重复按钮”。其余 19 条由上表覆盖。

## 评审与落地边界

- 先复用宿主指标、表格、抽屉、字段、空态、分组与反馈组件；局部样式修改落在所属容器，不通过全局选择器覆盖其他页面。
- 把适用 EUI-O ID、真实取舍及主字段最小可读条件写进 Blueprint；使用真实长值、空/少量/多量数据、权限分支与浅深/390px 检查。代码中的 gap、列数或颜色声明不能证明运行视觉合格。
- 页面固定留白并不必然是缺陷，判断是否割裂阅读或浪费工作区；不以占满屏幕、每卡等高或截图比例相似作为唯一验收目标。回归操作见配套 UI 验收 Skill 的 `operational-layout-checks.md`。
