# 计划、进度与数据图表

用于项目排程、设备预约、任务队列、经营分析等场景。先回答用户需要判断的是“顺序、日期、依赖、负载、状态还是数值”，再选组件。组件外观不能替代业务模型。

## 选型

| 用户任务 | 首选组合 | 不适用或替代 |
|---|---|---|
| 看一个对象走到哪一步 | 连线阶段条＋当前任务 | 不需要日期轴时不用甘特图；详见[阶段指南](business-component-patterns.md) |
| 回看谁在何时处理 | 时间线＋证据入口 | 不用计划日期伪装已发生事件 |
| 计划多项工作、观察起止和依赖 | **甘特图 Gantt：任务表＋共用时间轴＋任务条＋里程碑/依赖** | 没有可信起止日期时改任务列表；只有几个办理阶段时用阶段条 |
| 预约会议、设备、人员时段 | 日/周/月日历或资源日历＋事件详情 | 要看跨任务前置依赖时转甘特；大量并列资源要能筛选及定位冲突 |
| 跟进稳定状态中的工作队列 | 看板＋状态分组＋责任人/阻塞 | 多字段精确比较用表格；状态变更必须遵循业务权限，不能任意拖放 |
| 判断团队或设备是否超负荷 | 资源负载表/热力图＋时间范围＋容量口径 | 不用任务数量直接推算工时/产能；缺容量数据时仅展示分配量 |
| 查看真实可量化完成度 | 进度条＋已完成/总量＋单位 | 总量未知用不定进度或阶段文字；审批/阶段序号不能机械换算百分比 |
| 比较部门、项目、品类数值 | 条形/柱形图＋必要数据表 | 长类别名优先横条；不要以面积、3D或装饰气泡代替精确长度比较 |
| 看指标随时间变化 | 折线图＋统一时间轴＋缺数标识 | 无序类别用条形图；缺数不补零、不无说明连线 |
| 看组成占比 | 堆叠条形或少类别环图＋总量 | 分母不一致、可重叠类别、很多小项不宜环图；精确比较用条形/表格 |
| 看分布、离群或关系 | 直方图/箱线图、散点图、热力图 | 依据任务选一种；相关性不写成因果，颜色刻度和样本范围必须说明 |
| 监控关键指标并追查 | 少量KPI摘要＋相关趋势/对比＋有权限的明细入口 | 不拼装无决策意义的指标卡；没有真实目标值就不绘制达标进度 |

上述是本 Skill 的首选组合，不要求一页同时出现全部组件。图表内容和统计口径应来自产品已有契约。

## 甘特图专项契约

### 信息与构图

- 左侧任务表显示任务名及必要负责人/状态，右侧日期轴与行一一对齐。表与图共用纵向滚动位置、筛选及展开状态；列宽和分隔拖动不遮住主任务名。
- 条长表达起止区间；完成填充表达真实完成比例，两者不能混淆。计划、实际、基线、延期采用可辨的线型/标记与简短图例，只展示已有数据。
- 里程碑是无持续时间的业务节点；父任务汇总规则由业务定义。依赖连线说明真实前后关系，不把同组任务都自动连线。
- 今日线、周末/非工作时段、缩放粒度按实际需要显示。时区、全天任务、结束日期是否包含当天须统一；相同日期不能在表和图中相差一天。
- 大范围先给可读的阶段/分组概览，允许缩放、定位当前任务与展开；不要把一年压成无法点击的细线。
- 关键路径、自动排程、资源平衡需要对应计算与数据能力，不能靠视觉效果冒充。建议日期和已承诺日期分开呈现。

### 操作与恢复

- 只读计划不提供拖动柄；可编辑计划同时提供日期/时段表单，键盘和触屏用户不必精确拖拽。
- 拖动、调整时长、改依赖之前核对权限、工作日与真实约束；保存后回读。约束冲突显示受影响任务和原因，不能悄悄移动其它任务。
- 移动失败恢复原值并保留上下文；批量调整先呈现变更范围。版本冲突不能无提示覆盖他人排程。
- 390px 下优先提供同范围的任务/日程列表、日期和状态详情；需要专业横向时间轴时限制在具名可滚动容器内，保留固定任务身份。不得只缩小整张图，也不得给移动用户一个不同的数据集。

## 数据图表专项契约

- 标题说明指标与范围，轴/图例说明单位；过滤条件、数据截止时间及汇总口径在需要决策时可见。数值精度与领域一致，空值与零不同。
- 数量比较的柱条从零起点；趋势图若采用截断坐标须让范围清楚。不同对象对比保持可比较刻度，谨慎使用双轴。
- 颜色使用稳定业务映射，浅/深主题都可辨；线型、标签或图形补充颜色。选择、悬停、警告状态不能互相覆盖。
- Tooltip 只是补充，关键值能通过键盘/触屏或可访问的数据表读取。图表若可下钻，入口可识别且保留时间、过滤和权限范围；返回能恢复。
- 刷新失败保留旧数据时注明更新时间/失败，不把旧值当最新；加载骨架不显示虚构数字。统计图不能代替办理任务列表。

## 可观察验收

每项按[组件评审模板](component-review-template.md)记录实际结果，不适用须有理由。

| ID | 检查动作 | 通过条件 |
|---|---|---|
| PLAN-01 | 对照一项跨日任务、一个里程碑、两项真实依赖 | 日期、行、条长、连线与业务事实一致；能指出当前阻塞 |
| PLAN-02 | 缩放、筛选、折叠父任务、横纵滚动 | 表与图不失配，任务身份和时间范围保持可辨 |
| PLAN-03 | 修改日期并触发冲突/保存失败（如支持编辑） | 约束解释清楚、无暗中移动、失败恢复；表单可完成同一操作 |
| PLAN-04 | 390px、低高度、长名称和键盘使用 | 同范围的任务仍可查，操作不靠微小拖动柄，无页面级横向溢出 |
| PLAN-05 | 输入未知总量、退回、部分完成 | 不生成虚假百分比/关键路径；计划日期不冒充实际完成 |
| VIZ-01 | 从图中说出指标、单位、期间、过滤和分母 | 答案能在界面找到并与源数据核对 |
| VIZ-02 | 比较零值、缺数、极值、长类别与不同主题 | 没有误导的截断、补零、重叠或仅靠颜色的关键差异 |
| VIZ-03 | 键盘读取值并下钻、返回（若支持） | 不依赖悬停；明细与图同范围，返回保留上下文 |
| VIZ-04 | 初次加载、刷新失败、无数据、无权限 | 状态不同且真实；无数据不画有值的图，无权限不泄露统计 |

## 设计依据

查阅：2026-10-18。以下支持用途和基础语义；上述组合与验收项是本 Skill 的适配规则。

- [SAP Fiori Gantt Chart（版本化指南）](https://www.sap.com/design-system/fiori-design-web/v1-145/ui-elements/gantt-chart)：复杂活动/资源排程，任务表与时间图配合。其设备支持限制仅适用于该控件，不能推及所有甘特库。
- [DevExtreme Gantt Elements](https://js.devexpress.com/React/Documentation/Guide/UI_Components/Gantt/Gantt_Elements/)：任务起止、里程碑、资源及不同依赖类型的语义。作为能力参考，不要求安装此库。
- [Carbon 数据可视化](https://www.carbondesignsystem.com/building-blocks/data-visualization/overview)及[坐标轴与标签](https://carbondesignsystem.com/data-visualization/axes-and-labels/)：按表达目的选择图表，以标签、刻度和缺数处理保证可解释性。

宿主若缺少甘特/图表库，先评估现有能力能否做只读视图或列表；需要新依赖时遵循项目授权、许可和可访问性约束，不能为“企业感”引入大型组件。
