# 表格、列表与数据工作区

用于检索、比较、批量处理、层级展开与结构化编辑。先确定每行是什么业务对象、选择作用于哪里、用户主要是阅读还是编辑。不要把所有信息都塞进同一种表格。

## 表格变体选型

| 场景 | 首选 | 组合与边界 |
|---|---|---|
| 查找并处理订单、客户、记录 | 标准数据表＋筛选/排序/分页＋行操作 | 关键身份列靠前，状态与主判断字段可见；少量描述性记录可用列表 |
| 同一命令处理多条记录 | 可选择表＋选择数/作用域＋批量工具条 | 单页全选与全部查询结果明确区分；批量动作按权限与状态校验 |
| 主记录有少量补充信息 | 可展开行 | 子内容直接从属于该行；不能展开后藏另一套复杂应用或多层分页 |
| 部门、物料目录、项目WBS等父子关系 | 树形表＋层级缩进/展开 | 父子关系必须真实，显示层级与选择规则；普通状态分组不伪装父子关系 |
| 按部门/状态/日期聚合明细 | 分组表＋组标题＋明确口径的小计 | 分组不是树；小计说明当前页、当前筛选还是全部范围 |
| 高频修改少量独立字段 | 行内编辑表 | 保存粒度、校验、取消、脏状态可见；跨字段复杂表单转抽屉/独立页 |
| 连续录入测量值/报价明细 | 可编辑网格＋单元格校验＋明确提交范围 | 只有需要电子表格键盘行为时才用grid；支持粘贴前校验和失败定位 |
| 列表中连续检查一个对象 | 主从表/列表＋详情面板 | 选择与详情一一对应；窄屏进入详情后可恢复列表筛选、滚动和焦点 |
| 比较供应商方案、版本或指标 | 比较矩阵/差异表 | 行是比较维度、列是对象；相同单位/口径，窄屏可逐维度上下比较 |
| 从维度与指标看汇总 | 交叉表/透视表＋过滤＋口径 | 仅用于真实分析任务，汇总值有来源；聚合权限不自动等于明细权限 |
| 大量数据连续浏览 | 服务端分页，或确有需要的虚拟列表/表格 | 虚拟滚动不等于加载全库；校验焦点、行计数、定位与辅助技术表现 |
| 图片/摘要为主要识别方式 | 卡片列表＋筛选，必要时表格切换 | 需同时比较许多数字时首选表格；不为外观把每行拆成大卡片 |

## 共用构图

- 顶部沿同一内容线组织标题/记录数、查询控件和表格。业务新增/办理、查询动作、列设置/导出/刷新分组；没有新增权限时不强行补主按钮。
- 表头与正文对齐；文本按阅读方向对齐，数值右对齐并统一精度/单位，日期采用一致格式。缺失值与零区分，状态标签不过度着色。
- 列宽依据内容和任务分配。关键名称可换行，长标识允许按需展开/复制；不得靠极小字号或省略掉唯一身份来容纳全部列。
- 行操作保持一组；常用操作直接可见，其余进入可识别的更多菜单。整行导航不得吞掉选择框、链接或按钮点击，悬停不是唯一操作入口。
- 仅在确有扫描需要时固定表头/身份列/操作列；窄屏避免多个固定列挤掉正文。表内滚动不扩散成整页横向滚动。
- 筛选显示当前条件和清除入口，清空条件不等于删除数据。加载/空结果/无数据/读取失败/无权限分别处理；重试保留有效查询。

## 数据与交互契约

- Blueprint 写明筛选、排序、分页、分组与汇总发生在全部查询结果还是当前已载入部分。服务端排序不能只重排当前页却声称全局排序。
- 行身份使用稳定业务键；更新、重排或分页后不把已选/正在编辑状态串到另一行。
- 跨页选择和条件改变时明确保留/清除策略。工具条展示选择数量与范围；高影响批量动作展示实际对象范围，结果分别报告成功/失败并支持合理重试。
- 树选择明确父子联动、部分选中、禁用子项与隐藏结果的处理。树搜索需给命中项必要祖先上下文，折叠不能改变真实汇总值。
- 行/单元格编辑区分草稿、保存中、已保存与失败；验证位置靠近错误。切行、分页、切Tab或关抽屉时保护未保存修改；失败不能自动显示成功值。
- 并发修改遵循宿主版本/冲突策略；导出说明所选、筛选结果还是全量，且沿用权限。不能从当前可见几十行推断导出包含全部数据。
- 普通阅读表用原生表格语义及标题/表头关联；只有实现了相应键盘导航和编辑约定才使用交互grid，不靠添加ARIA角色获得可访问性。

## 通用表列布局契约

以下规则默认适用于普通只读数据表和已有通用主列表。Blueprint 必须记录表格实例、列定义来源、适用的自动适配触发、滚动容器和视图保存范围；不要机械套用于专业编辑网格、报告冻结排版或语义矩阵，这些例外需在接入账中说明理由和替代检查。

- **测量真实内容**：在实际主题、语言、字体和字号下测量已渲染的表头、代表性数据、状态/徽标、行操作组、空值/null、零值、最短与最长合法值；包含左右内边距、边框、图标和可见的排序/选择/链接线索。按列设置最小/最大宽度与合理换行规则，不能用字符数、英文经验值、隐藏文本或固定列数代替渲染测量。
- **分配可用空间**：先满足关键身份、状态和操作列的最小可读宽度，再在表格内容区分配剩余宽度；总宽超过内容区时让表内 scrollport 承担横向滚动，必要时按 Blueprint 固定少量身份列，不能把横向溢出扩散到整页，也不能缩小字体或省略唯一身份来“塞下”所有列。390px、浏览器缩放和长中英文都按同一契约测量。
- **响应内容变化**：首次渲染、数据/筛选/分页内容变化、语言或字体变化、主题变化以及用户明确执行“重新适配内容”时重新测量；用户手动宽度优先于自动结果，且要有“恢复默认”和“重新适配内容”两个可区分动作。默认值恢复列顺序、显隐和宽度；重新适配只重算当前允许显示列的内容宽度，不能悄悄改变排序、选择、分页或链接目标。
- **调整宽度**：默认以表头列边缘的细竖线表达可调边界，悬停、聚焦和拖动时高亮；扩大透明命中区，不给每列堆调宽图标/按钮，不与调序拖柄混淆。每个可调边界提供独立、可聚焦的拖柄，遵守最小/最大宽度和表内可用空间；鼠标、触屏和键盘都能调整，拖动中可取消并恢复开始值，结束后保留列语义。拖柄必须阻止事件误触表头排序；排序按钮仍是独立可访问目标，`aria-sort`、升降序和排序请求语义不因拖动改变。
- **重排列**：用独立拖柄或列设置面板重排列，不能把整个可排序表头当作拖拽区。键盘提供等价的移动/前移/后移操作，触屏有足够命中区和取消路径；重排不触发排序，不改变选择、分页、行链接或当前滚动上下文。
- **保存视图**：保存键至少区分用户身份、租户、表格稳定键和视图/列结构版本；保存内容只包含允许字段的稳定列 ID、顺序、显隐和用户宽度。兼容旧的列数组配置：读取后规范化为当前结构，未知/权限移除字段丢弃，新增列按当前默认补入，不能恢复越权列；结构版本变化必须可回退到默认视图。存储失败时保留当前会话内存状态，并给出可恢复的失败/重试反馈，不能静默回退或丢掉刚完成的调整。
- **保留基础语义**：自动适配、拖动和重排必须保持表头排序、选择/全选、分页、行内链接、焦点返回和可访问名称的原有语义；状态颜色、空值与零值的区分也不能因列宽不足被隐藏。

### 接入账与例外字段

每个接入的通用表至少登记：`tableId`、宿主组件/列定义来源、表格变体、关键列及 min/max、真实测量触发、表内 scrollport、拖动/重排入口、保存的 user/tenant/table/version 作用域、旧配置迁移规则、权限过滤规则、默认/重新适配行为和例外理由。只读表可以启用本契约；编辑网格、冻结报告和语义矩阵必须显式选择自己的列宽与键盘模型，并在 Blueprint 标为例外，不以本节的自动适配通过替代其专业验收。

## 可观察验收

使用[组件评审模板](component-review-template.md)。测试数据至少含长名称、重复显示名但不同ID、零/空值、不同权限与一页以上记录，按实际功能裁剪。

| ID | 检查动作 | 通过条件 |
|---|---|---|
| TABLE-01 | 用界面定位一个已知对象，并解释关键字段 | 身份、状态、单位、操作可辨；无须读内部ID才能区分同名对象 |
| TABLE-02 | 筛选→排序→翻页→打开详情→返回 | 结果口径正确，返回保留应保留的上下文，无行状态串位 |
| TABLE-03 | 选择本页/跨页，改变条件，执行批量动作 | 数量与实际对象范围一致；无权限项处理明确，部分失败可定位 |
| TABLE-04 | 展开、折叠、树搜索、父子选择（若适用） | 层级/范围清晰，半选态和汇总真实，隐藏项不会被意外处理 |
| TABLE-05 | 输入非法值、取消、保存失败、冲突、切走（若可编辑） | 错误就地可见，数据未丢，保存范围明确，没有假成功 |
| TABLE-06 | 390px、200%放大、键盘、长中英文 | 关键身份与动作仍可达；必要滚动在表内，焦点不丢失/被遮挡 |
| TABLE-07 | 打开列设置/更多菜单/过滤浮层，切浅深主题 | 浮层主题正确，键盘关闭并恢复焦点，选择/排序标记可辨 |
| TABLE-08 | 请求失败、空查询、无权限、导出（若有） | 状态与范围真实；失败可恢复，不泄露行/汇总，不虚构导出成功 |

列布局的真实浏览器走查沿用回归 Skill 的 [通用表列布局检查](../../ui-regression-acceptance/references/operational-layout-checks.md#通用表列布局检查)，使用 `TABLE-L01`～`TABLE-L09`；本参考只定义设计契约，不把文档阅读当作实现证据。

自动化可以检查范围、回读、键盘与几何；列优先级、扫描效率和视觉密度还要结合填充数据的截图与任务走查。

## 设计依据与宿主映射

查阅：2026-10-18。

- [Carbon Data table](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines)：表格工具条、排序、展开、选择及批量动作的组合。这里的跨页/权限/编辑契约是面向业务系统的补充要求。
- [Ant Design Table](https://ant.design/components/table/)：标准、树形、展开、选择与编辑等实现能力参考；用前核对宿主已安装版本。
- 已有Element Plus/Carbon/自研表格就沿用它的稳定能力。先查组件清单，再按真实共性抽取列表骨架；以明确列定义、props/slots/events承载业务差异，不制造万能配置表格。
