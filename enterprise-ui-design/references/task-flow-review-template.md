# 流程与视觉评审记录

按实际范围填写；不适用项写原因，未取得证据写“未验证”。本模板用于设计/UX评审，不代替项目代码审核或客户验收。

## 范围与证据

- 产品、页面/路由、版本或内容指纹：
- 操作者及权限、业务目标、对象范围：
- 数据来源：真实运行 / 隔离测试 / 模拟 / 用户截图。
- 视口、实际容器宽度、主题、密度、DPR/缩放（未知须注明）：
- 证据清单：截图路径、状态、采集时间/来源；源码位置；命令及结果。
- 本次类型：设计 / 只读审查 / 已授权整改。
