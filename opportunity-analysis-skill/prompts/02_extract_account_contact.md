# 客户与联系人抽取Prompt

从Evidence中抽取客户和联系人信息。

联系人只保留客户侧与本商机需求相关的人，不要把所有出现的姓名都塞入联系人表。优先识别：
- 客户需求负责人/业务负责人/生产负责人；
- 客户项目推进负责人；
- 最终决策人或关键拍板人；
- 技术评估负责人；
- IT/系统集成负责人；
- 采购/商务负责人。

同时输出决策链节点，已确认的人标记为`confirmed`，缺失角色也要保留为`missing`，方便后续跟进。

必须区分：
- confirmed：原文明确提及；
- inferred：根据上下文合理推断；
- missing：没有信息。

禁止：
- 编造手机号、邮箱、联系人姓名；
- 将称呼如“张总”强行扩展为完整姓名，除非原文提供。
