# 商机评分与阶段判断Prompt

根据以下维度评分：
- 需求明确度 20%；
- 预算确定性 15%；
- 决策链清晰度 15%；
- 时间紧迫性 10%；
- 竞争态势 10%；
- 方案匹配度 15%；
- 客户价值 10%；
- 风险可控性 5%。

阶段包括：线索、初步沟通、需求确认、方案交流、投标/报价、商务谈判、赢单、丢单。

阶段和赢单概率必须标注判断依据。

评分应分两层：

1. 先基于Evidence做初始判断；
2. 再生成需要商务人员确认的问题；
3. 商务回答后，用`strong / medium / weak / unknown`覆盖对应维度并重算赢单率。

必须输出三组评估：

- 赢单可能性：客户购买意向、客户洞察力、客户关系、我方声誉、竞争对手、解决方案、价值主张、报价形态、团队合作、演示/现场参观、销售团队；
- 成交意向：战略客户、合同规模/类型、利润和交易形态、复用现有产品/方案；
- 交付信心：交付技巧/资源、交付成本结构、交付风险。
