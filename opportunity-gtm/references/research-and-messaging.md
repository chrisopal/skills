# 研究任务与推广话术

## 研究表

| 对象 | 要核实的事实 | 适配判断与下一步 |
|---|---|---|
| 企业 | 主体/官网、业务、行业、基地城市、公开项目 | 使用场景交集；痛点/预算/联系人未知；确认具体工序及责任部门 |
| 区域 | 实际找到的企业点位、产业园/协会覆盖 | 有证据的集群＋团队可达性；不能将样本数量当市场容量 |
| 展会 | 届次、日程、地点、主办方、展区/受众、官网入口 | 买家角色是否吻合，参观/展位/议题选择；费用和名单待核 |
| 论坛 | 官方议程、发言者角色、交流主题、日期/地点 | 技术交流或议题合作；往届资料标历史，不承诺新届 |
| 渠道 | 业务、覆盖、准入、公开合作方式 | 引荐、联合验证、集成或内容分发；不假定可获得会员名单 |

来源优先级：对象官网/主办公告 > 官方行业名录/政府园区 > 独立可信报道。二手线索回到原件；同一事实冲突保留双方与核验任务。可按产品同义词、行业术语、工序、城市和角色组合查询；不要只搜索产品名称而漏掉使用问题。

适配分项：行业场景35%、可验证问题30%、可达路径20%、证据覆盖15%，每项0–5。说明打分理由；未核实用null，完整四项才计算0–100研究适配分。公开主营业务可支持行业分，通常不能支持痛点、采购或可达性高分。地域排序是当期取舍，不是市场规模测算。

## 按角色/渠道写话术

统一结构：公开可核实背景 → 条件式场景问题 → 已证明能力 → 低承诺下一步。客户产品资料先提供事实，未提供则写待补证明，不能用“领先/高精度/降本30%”填空。

| 场景 | 合适开场/CTA | 必须保留的边界 |
|---|---|---|
| 首次企业联系 | “看到贵司公开介绍涉及…，想了解…工序是否有外观检测评估计划。如适合，可约20分钟讨论样本及节拍。” | 未确认需求，不说“了解到贵司长期困扰” |
| 技术负责人 | “建议先对齐缺陷定义、样本覆盖和误检漏检口径，再决定是否做小范围验证。” | 不先承诺准确率，实际验证有独立结果 |
| 生产/质量负责人 | “可先梳理当前工位、复检流程和判定规则，确认是否值得进一步评估。” | 不假定现状成本，不把演示当效果 |
| 展会预约 | “计划围绕…场景交流，如贵司参会且有相关议题，可预约讨论。” | 目标企业参会未知；不可伪装已约见 |
| 论坛/协会合作 | “想核实是否有…专题交流与参与条件，若匹配可先提交不含敏感客户信息的议题。” | 主办许可/费用/名单未知 |
| 伙伴合作 | “希望评估贵方…方案与我们…能力是否互补，先对齐客户范围、交付边界与联合验证方式。” | 不默认代理权、分成或客户转交 |

异议回应：没有需求→确认是否结束跟进；已有供应商→了解是否有未覆盖场景而非贬低对手；要求案例→只给获准公开且真实的证据；直接要价格→先说明报价前提与范围，转商业Skill；质疑精度→明确样本验证与验收方法。

每条话术记录目标群/角色、渠道、开场、价值、证明、CTA、异议回应和来源。每次反馈更新后续动作，不把更多触达次数当成更有效。
