# Styles

Style owns communication method without official identity or page prototypes.

This Plus distribution bundles only the six Huixin Decks listed in
[`decks_index.json`](../decks/decks_index.json). Other theme presets were
removed; empty Brand/Style/Layout indexes are intentional.

Ordinary generation selects one Huixin Deck through
[`huixin-generate.md`](../../workflows/profiles/huixin-generate.md).
Read only its specification and prototypes needed by actual pages. Template
roles and capacity guide reuse; custom pages retain Huixin identity and the
selected narrative rules. Flat export does not claim reusable native masters.

Explicit external workspaces remain supported through
[`routing.md`](../../workflows/routing.md). New reusable workspaces use
[`create-template.md`](../../workflows/create-template.md), with the existing
kind schema and registry. Do not restore removed presets during discovery.
