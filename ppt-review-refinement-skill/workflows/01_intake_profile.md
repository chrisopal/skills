# 01｜接收与定位

## 目标

判断这份 PPT 的主题、受众、使用场景、沟通目标和应有气质，为后续评审建立参照系。

## 输入检查

- 文件能否打开、页数和比例。
- 是否有母版、备注、动画、图表、SmartArt、嵌入对象。
- 是否包含品牌 Logo、客户标识、保密标识。
- 是否存在多个语言、多个公司或多个项目版本混杂。

## 推断方法

从以下证据交叉判断：

1. 封面标题、副标题、文件名。
2. 目录和章节页。
3. 高频实体、行业词、客户名称和动作词。
4. 结尾页是否有明确行动或项目计划。
5. 页面视觉气质和品牌元素。
6. 演讲者备注。

## 必须输出

- `deck_type`：公司介绍、售前方案、项目汇报、战略规划等。
- `topic`：一句话描述主题。
- `audience.primary` 与 `audience.secondary`。
- `usage_context`：现场演讲、发送阅读、打印等。
- `communication_goal`：希望观众产生的认知、决策或行动。
- `single_takeaway`：希望观众记住的一句话。
- `recommended_personality`：3–5 个风格词。
- `brand_constraints`。
- `assumptions`：每项含置信度和确认需求。

## 置信度规则

- `high`：封面、目录、结尾和正文证据一致。
- `medium`：有两类证据支持，但存在矛盾或缺失。
- `low`：主要依赖文件名、零散词汇或视觉风格推断。

低置信度不会阻止 L0 评审，但会限制 L2/L3 的自动执行。
