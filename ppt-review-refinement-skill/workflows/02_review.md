# 02｜叙事与视觉评审

## 叙事评审

### 整体层面

1. 把每页归入“背景、问题、洞察、方案、机制、实施、价值、证据、行动”之一。
2. 绘制当前叙事路径。
3. 判断核心结论是否出现得足够早。
4. 检查问题—方案—价值是否闭环。
5. 检查章节比例、重复、跳跃和缺失。
6. 给出建议结构，但不在未授权时直接重排。

### 页面层面

每页回答五个问题：

- 页面角色是什么？
- 观众应记住什么？
- 标题是否已经表达结论？
- 正文、图表和图片是否支撑标题？
- 建议动作是保留、删减、拆分、合并、重构还是前移？

## 视觉评审

从八个维度评分：

1. 主题一致性。
2. 配色一致性与语义。
3. 字体、字号、字重和中英文混排。
4. 信息层级与视觉重点。
5. 页面网格、对齐和边距。
6. 间距、留白和密度。
7. 图形、图表、表格、流程和架构图。
8. 配图质量、裁切、风格和相关性。

增加技术检查：重叠、越界、溢出、异常字体、低清图片、不可编辑截图、链接和动画风险。

## 问题格式

每条问题至少包含：

```json
{
  "slide": 12,
  "scope": "slide",
  "category": "layout",
  "severity": "P1",
  "finding": "架构层级过多且视觉权重相同，主平台能力不突出",
  "impact": "管理层难以在10秒内理解方案主线",
  "recommendation": "保留三层主结构，支撑能力下沉为浅色底座",
  "action_type": "restructure",
  "approval_required": true,
  "confidence": "high"
}
```

## 评分说明

每个维度 0–5 分：

- 0：无法使用或存在严重错误。
- 1：明显不专业，严重影响理解。
- 2：问题较多，需要系统调整。
- 3：基本可用，但一致性或表达效率一般。
- 4：专业、清晰，仅需局部优化。
- 5：高度一致，视觉与叙事共同服务于目标。

总分只用于排序，不能替代具体问题。
