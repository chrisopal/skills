# 05｜逐页精修与配图

## 逐页精修

根据页面角色选择原型，不把所有内容套成同一种卡片布局。

### 可执行动作

- 把描述性标题改成结论式标题（需授权）。
- 减少视觉组数量，建立主次层级。
- 将长段落转成分层结构、流程、矩阵或价值链。
- 调整阅读路径和视觉重心。
- 把关键数字、结论和行动置于更高层级。
- 重画低质量流程、架构和表格，保持可编辑。
- 删除无意义装饰，增加必要留白。

### 页面密度

- 现场演讲：优先低密度、大结论和视觉辅助。
- 发送阅读：允许更高信息密度，但必须分层、可扫描。
- 打印材料：字体和对比度需适配纸张，减少依赖动画。

## 配图流程

1. 判断图片是否承担信息、证据、氛围或装饰角色。
2. 检查清晰度、语义相关性、风格、裁切和版权/来源风险。
3. 依次考虑保留、优化、替换、重绘/生成。
4. 任何替换必须在日志中记录原图、原因、来源和授权。

## 禁止行为

- 用泛化“数字大脑”“机器人握手”等图片替代具体工业流程。
- 用 AI 场景图冒充真实客户案例或工厂实景。
- 把数据图表、架构图和流程图生成成不可编辑位图。
- 为追求统一色调而让图片主体失真或不可辨识。
