# 售前逐页大纲

先读[成果契约](../presales-orchestrator/references/artifact-contract.md)。输入为有效脑图/方案、受众、时长与材料。读取已有方向/大纲确认，沿用已授权范围。

## 执行

1. 按受众决策顺序组织章节，为每页分配稳定SLIDE-ID；title写结论而非仅“背景/方案/价值”。
2. 每页给section、purpose、key_message、planned_content、requirement_ids、solution_ids、evidence_ids、material_ids、visual_type与duration_seconds。
3. 检查每个重点需求的实际落点、关键限定出现位置、重复页、叙事节奏和最后的决策请求。把参考细节放附录，但不能把关键风险藏进附录。
4. 形成JSON及派生审阅表，明确待确认页和对比前版变化。既有授权允许继续写作时直接推进，不重复请求同一确认。
5. 登记outline，inputs绑定脑图、方案及实际使用材料；删除/拆分/合并页面时保留旧新ID映射。

## 完成与异常

另一位作者能据每页计划写正文，不必猜业务结论。页数不足时说明合并或附录的取舍；不静默删需求。方案尚未确定的页面作为候选并标条件，不冒充已确认版。
