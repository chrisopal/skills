## 发现与修复

- 新并发测试实际暴露SQLite查询/插入竞争，保留原始失败代码/日志和修复后证据；采用`BEGIN IMMEDIATE`将幂等判断与写入串行执行。
- 将蓝图与测试中的HTTP故障陈述限定到实测路径，明确503/超时触发未验证。
- 补齐七项蓝图范围中的权限/数据对象及页面字段、按钮、状态、异常恢复；区分设计角色与夹具实际权限。
- 恢复证据从条数/业务键增强到备份前后完整审批工单行一致。
- 文件审核新增复制来源SHA及路径约束反例测试；防止只核验源JSON而漏验复制字节。
- 固定价与缺陷“已修复”按字段上下文翻译；引用放在文档版本说明处，复用现有样式。
- bundled LibreOffice默认中文字体发现失败；本次以局部`FONTCONFIG_FILE`配置`/Library/Fonts`和系统字体目录，不修改全局安装。全部52页重新渲染后中文可读。PDF抽取器对部分粗体中文重排字序，字符库存无缺字，字序以实际渲染审阅为准。
