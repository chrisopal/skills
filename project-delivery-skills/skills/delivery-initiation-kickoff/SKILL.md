# 项目启动与启动会

先读[共享产物契约](../delivery-orchestrator/references/artifact-contract.md)。输入为合同交接、项目目标、组织/人员资料、里程碑初稿和客户配合条件；输出章程、RACI、启动会议程/内容包、纪要和行动项。

## 处理

从合同义务与实际授权提取背景、范围内外、成功标准、系统/站点和近期路径。分别记录客户发起人、确认代表、业务/IT/安全/第三方和供应商角色，写清职责、决策权、替补、沟通渠道和升级时限。启动包必须含交付物、里程碑、关键依赖、调研/蓝图方法、周会/周报机制、文件命名与确认入口、客户准备项及初始风险。

拟定人员、邀请人员和已接受职责分开；参会不等于承担确认权。启动纪要只记录实际发言、决策、行动责任和期限，并关联来源/会议版本。客户确认必须另写确认对象、角色、范围、日期和证据，不能由 `ready` 或会后发送推断。

## 主责与完成

章程、角色/RACI和启动行动项由本 Skill 维护；计划和需求 Skill 维护各自主账。完成要求实际读取交接输入、角色授权依据、会议结果和行动项回读；缺客户关键人、确认权限、环境或目标仍列阻塞，不造齐全名单。

## 模板

使用 `../delivery-orchestrator/assets/templates/initiation-kickoff.md`、`roles.csv` 与 `actions.csv`。客户材料不显示内部费率、绩效或毛利。
