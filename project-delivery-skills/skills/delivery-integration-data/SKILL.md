# 接口、数据迁移与联调

先读[共享产物契约](../delivery-orchestrator/references/artifact-contract.md)与[软件实施契约](../delivery-orchestrator/references/software-delivery.md)。输入是有效需求/蓝图/方案版本、系统与版本清单、数据样本、接口资料、环境/账号条件、迁移范围和各方责任；输出接口设计、字段映射、联调记录、迁移方案、核对结果和未决依赖。

## 处理

接口记录双方系统及版本、业务目的、方向/触发、协议认证、环境、频率容量、字段映射、编码/时间/单位、幂等、超时重试、错误码与补偿、日志监测、样本、业务成功条件和负责人。字段映射同时说明转换、默认、空值、枚举、精度、敏感数据处理和版本兼容；“连接成功”不能替代业务结果核对。联调按精确 build、环境、参与方和场景留脱敏请求/响应、业务核对、缺陷、复测和结论。

迁移记录来源/目标、数据范围、抽取、清洗、映射、样本验证、演练、全量/增量、冻结窗口、备份、回滚和数据责任。至少核对条数、金额或关键记录等适用指标，并标明不适用的理由；只看到任务执行或文件生成不等于数据一致。第三方资料、许可、网络、账号、测试数据和交付日期未知时，登记阻塞、责任人和升级路径。缺少自动检查时由 Agent 按映射和核对证据逐项检查，不能伪造通过状态。

## 主责与完成

本 Skill 维护接口/数据设计、映射、迁移与核对主账；方案、UI/字段、工作包、测试和上线技能引用其稳定 ID。完成要求每个接口和迁移项均有需求关联、版本/环境、责任人、成功条件和证据，映射与核对结果可复现，失败/重试/回滚路径明确。`ready` 不等于第三方确认、联调通过、迁移成功或生产可用；模拟数据、模拟确认和演练结果必须标识其来源与边界。

接口资料变更先保留旧版本并生成候选映射，评估对工作包、测试和上线的影响，再由总控更新有效引用。任何实际网络、数据写入或生产迁移动作都需要已有任务授权；本 Skill 不自行执行未授权的外部动作。

## 模板

使用 `../delivery-orchestrator/assets/templates/integration-data.md`、`integration-mappings.csv` 和 `integration-migrations.csv`。CSV 是空白机器台账，不能把示例值当成真实接口或迁移事实。
