# 客户模板字段映射

## 产物信息

- 项目/文档 ID、客户模板名称、版本和状态：
- 客户原模板来源、读取范围、适用交付阶段：
- 内部对象版本、负责人、统计截止日：
- 审核/确认记录与客户可见范围：

## 字段映射

| 稳定ID | 客户字段/位置 | 内部对象/字段 | 映射状态/依据 |
|---|---|---|---|
|  |  |  |  |

同一 `mapping_id` 可在多行重复，分别表达同一字段的版本、附件或条件映射；不得用相似名称掩盖口径差异。

## 版本与实际文件回读

| 稳定ID | 实际文件/版本 | 回读范围 | 结果/缺口 |
|---|---|---|---|
|  |  |  |  |

回读须记录实际文件路径或受控引用、版本/hash、页码/表名/字段范围、打开或渲染结果；本地草稿、生成成功或聊天内容不替代实际文件回读。

## 缺口与处理

| 稳定ID | 缺失字段/差异 | 处理位置 | 责任/状态 |
|---|---|---|---|
|  |  |  |  |

- 客户原模板优先；缺失字段放附件或内部底稿，并记录对客户格式的影响：
- 客户模板版本、内部映射版本和最终交付文件版本必须分别可追溯：
- 未读附件、不可编辑字段、权限不足、格式冲突和待客户确认：
- `ready` 不表示客户已确认或允许外发：
