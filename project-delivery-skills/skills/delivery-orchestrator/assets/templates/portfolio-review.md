# 多项目组合审查

## 审查范围

- 审查 ID、统计截止日、负责人和纳入项目清单：
- 每个项目的有效版本、状态、客户可见范围和币种：
- 计划、资源、风险、成本与质保主账来源：
- 审查限制、未读来源和权限边界：

## 项目隔离

| 稳定ID | 项目/截止日 | 有效版本/币种 | 状态/依据 |
|---|---|---|---|
|  |  |  |  |

同一 `project_id` 在不同截止日或版本中分别成组；不能用最新文件名覆盖历史，也不能跨币种直接相加。组合视图不改写项目主账。

## 人员负荷与缺口

| 稳定ID | 人员/周期 | 项目分配与可用量 | 缺口/证据 |
|---|---|---|---|
|  |  |  |  |

| 稳定ID | 项目/资源缺口 | 影响与选项 | 责任/期限 |
|---|---|---|---|
|  |  |  |  |

分配、工时、可用容量和项目工期分别读取；组合负荷不自动等于完成度、关键路径或收入预测。

## 结论

- 截止日内可确认的事实、预测、待决事项：
- 跨项目冲突、资源替补、币种/版本隔离和缺口：
- 需回写单项目主账的候选事项及回写责任：
- `ready` 只表示组合审查视图可用，不表示任一项目验收或财务结清：
