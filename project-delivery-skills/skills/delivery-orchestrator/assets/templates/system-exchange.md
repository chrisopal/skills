# 外部系统交换

## 交换范围

- 交换 ID、项目/配置版本、负责人和统计截止日：
- 外部系统范围：飞书、任务、代码、财务及其他已授权系统：
- 内部主账、外部对象、授权边界和环境：
- 交换目的、来源版本、客户/内部可见范围：

## 对象与字段映射

| 稳定ID | 外部对象/字段 | 内部对象/字段 | 稳定内外ID/版本 |
|---|---|---|---|
|  |  |  |  |

| 稳定ID | 转换/默认/单位规则 | 冲突/重试规则 | 状态/责任 |
|---|---|---|---|
|  |  |  |  |

外部 ID 与内部稳定 ID 必须保留映射；字段冲突、重复、版本漂移、失败重试和人工补偿分别登记，不以文件名或显示标题充当稳定 ID。

## 准备、执行与确认

| 稳定ID | 准备内容/范围 | 外部执行动作 | 确认收据/实际结果 |
|---|---|---|---|
|  |  |  |  |

准备映射、生成待发送内容或模拟请求不等于外部执行；实际写入、发送、同步或财务记账须有当前授权、执行记录、结果和确认收据。凭据只引用受控位置，不写入模板。

## 缺口与边界

- 未授权、接口不可用、外部版本未知、字段冲突、重试上限和人工补偿：
- 交换结果回写哪个主账、由谁确认、以何种收据证明：
- 外部执行失败后的回滚、重放、去重和对账路径：
- `ready` 不表示外部系统已写入、任务已完成、代码已发布或财务已记账：
