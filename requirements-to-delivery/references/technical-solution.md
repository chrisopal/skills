# Technical Solution

Use the technical solution phase to choose a feasible implementation direction before detailed system design.

## Required Sections

- Context and goals
- Current system fit
- Candidate approaches
- Recommended approach
- Architecture overview
- Key data and integration flows
- Security, privacy, and permission impact
- Operational impact
- Risks and mitigations
- Rejected alternatives
- Delivery phases

## Decision Format

```text
DEC-001 | Decision | Context | Chosen option | Alternatives rejected | Consequences | Confidence
```

## Comparison Table

Compare options by:

- Requirement coverage
- Complexity
- Reuse of existing system
- Data migration impact
- Integration risk
- Testability
- Operational cost
- Reversibility

Prefer the lowest-complexity option that satisfies must-have requirements and preserves future change paths.
