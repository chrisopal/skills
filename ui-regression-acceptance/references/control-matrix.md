# 控件验收矩阵

只分配页面实际存在、契约适用的检查；每个控件实例至少有正常操作、失焦/离开后的显示和再次操作。记录不适用理由。所有关键业务流程需要实际串联，不能只孤立点控件。

| 控件 | 必测操作链与观察 |
|---|---|
| 输入框/文本域 | 输入中文/合法边界 → 点击其他控件/Tab → 内容仍可见 → 修改/清空 → 校验提示 → 提交与回显。只读不可输入；多行不遮挡操作。 |
| 下拉/树选择/级联/自动完成 | 展开 → 非首项 → 失焦 → 选中标签可见 → 重开确认 → 换项；可搜索时先过滤再选；远程项加载/空/失败；改变上游时下游值按契约清理，不提交旧 ID。 |
| 多选 | 多项选择 → 失焦 → 标签/计数正确 → 删除单项/清空 → 重开勾选一致；长标签和容器收缩不遮挡删除。 |
| 数字/金额 | 手输和步进 → 零值/上下界/小数 → 失焦不误变空/精度丢失 → 请求与回显一致；只读和禁用步进不能修改。 |
| 日期/时间/范围 | 选择 → 确认/取消 → 失焦 → 格式回显 → 清空/重选；起止限制、跨月、实际支持的时区与请求值一致。 |
| 单选/复选/开关 | 鼠标与键盘切换 → 同组/联动正确 → 保存重进；禁用不可变，异步失败时状态恢复或明确错误。 |
| 按钮/链接/菜单 | 正常执行与路由正确 → loading/禁用 → 重复点击不重复提交 → 失败可恢复；图标有可访问名称；菜单点击后目的动作真实发生。 |
| 表单整体 | 必填空/合法完整数据/服务端错误 → 错误贴近字段 → 编辑不意外丢失 → 保存/取消 → 刷新读取；多表单互不串值。 |
| 标签页/折叠/步骤条 | 切换再返回 → 值与校验状态按契约保留 → 隐藏内容不误提交/抢焦点；必需步骤不能被意外跳过。 |
| 弹窗/抽屉/浮层 | 打开 → 表单或选择 → 点击外部/Escape/取消按契约工作 → 再打开 → 无陈旧值/遮罩残留；焦点返回，滚动与底部按钮可达。 |
| 表格/列表 | 筛选 → 排序 → 分页 → 行动作命中正确记录 ID → 修改后刷新；选择跨页策略、空页、长内容、固定列；重复行按行为等价分组测。 |
| 上传/下载 | 实际支持类型/大小 → 成功/失败/重试/取消 → 服务端回读；下载文件非空、类型/内容正确，不能只检查 toast。 |
| 图/画布/拖拽 | 点击节点/边 → 详情对象正确 → 空白取消（适用）→ 缩放/拖拽后可交互 → 容器 resize 后坐标/命中正确；修改需保存回读。 |
| 通知/错误/加载 | 正确时机显示与消失，不遮挡后续动作；慢/失败状态可退出/重试，不无限 loading；真实与注入故障证据区分。 |
| 导航/角色/工作区 | 深链接/返回/刷新 → 当前对象与权限正确；切换后旧数据/弹窗/表单不得泄露或误写；非授权控件隐藏/禁用且无成功写请求。 |

## 本次缺陷对应的最小完整检查

1. 打开有实际数据的下拉；选第二项。
2. 点击旁边输入框，使下拉失焦。
3. 同时检查业务选中值、可见标签、控件宽度与标签可见区域。
4. 再展开，确认仍选中第二项；改选另一项后重复失焦。
5. 如该字段属于保存表单，再提交并刷新回读。

仅 DOM 文本存在、仅 `.value` 正确、仅选择时截图均不足。曾发生选中值仍存在，但内联表单的自适应下拉在失焦后收缩到只剩箭头；这需要真实布局检查才能发现。
