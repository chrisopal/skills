## 新反馈的判定

`reczz28PxIiaMgUF` 客户模板识别、`reczz28PxrQ6EDji` 审核范围、`reczz28PxwSVJlux` 统计期间/图表、`reczz28Py81qLd8G` 负责人、`reczz28PyAckVjj4` 身份标识、`reczz28PyB8QcGKM` 报告详情均无修复记录；`reczz28PzQGAHnjP` 是空行。新问题先建立正确契约和范围：没有实际执行标 NOT_RUN，前提缺失/冲突标 BLOCKED，不从相似旧问题推导 PASS。

统计期间必须按指标时间字段、时区、边界及支持的日期范围核对请求和结果；图表类型先确认真实能力和适用数据，不以增加装饰图响应反馈。负责人/身份字段若接口或领域缺能力，归为业务缺口，不用空列或自动造ID掩盖。

## 证据层级

L1 指静态、文件或台账结构检查，可验证引用、枚举、计数、路径和摘要。L1 不能证明证据语义真实，也不能证明表单生效、姓名映射、范围筛选、权限或布局正确。`check_coverage.py` 的通过仍须按 [证据格式](evidence.md) 查看实际脚本、日志、下载内容、截图和独立回读。此文件不修改现有 schema 或检查器，不新增一套 PASS 口径。
