# 信息结构、只读资料与列表工具栏

当页面能点击但难以读懂、详情连续堆叠、工具栏过重或提示重复时，按本表增加逐页面检查。与项目 Blueprint、组件清单及语义 Token 一起使用；不另定固定配色、像素尺寸或按钮数量上限。自动布局指标通过不能抵消已观察到的信息理解缺陷。

## 先确认结构契约

从业务需求与接口列出：对象身份、当前阶段、待办、关联样品/子对象、资源、依据、成品、历史资料。记录每类事实的所属分组或 Tab、主入口及权限；计数注明分母（实物、检测分配、工作包、报告不能混用）。没有数据的状态不能补造人员、进度或资源。原型示例值不得直接迁入正式页面。

| 检查 ID | 可观察的预期与执行 |
|---|---|
| IA-01 | 身份、阶段与当前可办理事项能区分。进入进行中/退回/已完成对象，按实际契约找出当前事项、对象、负责人和下一入口；已完成页面优先呈现成品及完成证据，不继续堆空待办或无效生成按钮。缺失负责人显示真实未知状态。 |
| IA-02 | 样品、执行、设备、依据、报告、资料等独立内容有具名边界。逐 Tab/分组进入、返回、刷新或深链接后仍指向同一对象；隐藏区域不抢焦点或误提交。选择已有表格/分组/Tab 组件，不能仅用更多说明句修补层级。 |
| IA-03 | 阶段连线区分完成/当前/未开始/未知，部分完成与归档来源真实。390px 下先能看到当前事项和数据，展开完整阶段、横向 Tab 滚动及键盘操作可达，无状态列被静默删除。 |
| FORM-READ-01 | 只读资料使用有标签的字段结构。姓名/时间、联系人/电话分开，长结论可跨列；设备名称、关联项目、适用样品与检测方法、执行标准、判定限分别标明。不能用无标签的多行字符串或横向串排让读者猜含义。 |
| FORM-READ-02 | 只读值不伪装成禁用输入框；标签和值对齐，长值换行不覆盖相邻字段。桌面与390px 均核对字段关联和完整值；业务名称优先，必要标准编号、单位和精度准确保留，技术标识按业务/审计需要收起且仍可访问。 |
| FORM-READ-03 | 按主体/任务/资料语义建立字段组，以委托详情式结构化阅读为参照，不复制业务字段。核对宿主 Descriptions 或 dl/dt/dd 等标签/值关系、分组标题及读屏顺序；短字段按可用宽度排网格，长结论/备注独占整行，不能只是把段落拆成更多卡片或禁用输入。 |
| FORM-READ-04 | 盘点全部详情路由、子页、Tab、弹窗/抽屉和角色条件区域，逐项标适用分组；跨记录比较表、历史时间线、专业编辑器保留原任务语义。桌面/390px 浅深、有数据/空/错误/加载分别核对，未知契约记 BLOCKED；共享样例不能代替各实例。 |
| EMPTY-01 | 依据接口/权限分别触发初次无记录、筛选无匹配、无权限、对象不存在、读取失败和加载。文案/恢复按真实状态，清除条件仅用于筛选空，创建仅给有权限且可执行者；对象不存在可返回、失败可实际重试。零工作队列不等于报告/历史不存在；缺契约不得猜状态。 |
| EMPTY-02 | 同一内容区保留标题/范围、状态/内容、必要错误/恢复的层级；空态在该内容区居中并有适当四边留白，标题和工具栏不随之居中。不用巨大固定高度撑满视口，不让状态文字/按钮贴外框；叙述、空态、错误均实际截图检查。 |
| EMPTY-03 | 执行加载→有数据/空/失败、重试成功、切换对象/角色/Tab。阅读边界稳定、旧提示及时解除，必要风险/权限/恢复仍可见；键盘焦点及恢复动作可达，同一事实不在标题、横幅、空态重复解释。 |
| TOOLBAR-01 | 业务命令、查询条件、视图工具有主次。默认、有筛选、空数据分别查看截图；不得让通用筛选/列设置/导出/刷新形成比对象数据更突出的等权大按钮带。不能为了制造主操作而新增无接口动作。 |
| TOOLBAR-02 | 同一刷新、导出或筛选只有一个合理入口；页头、列表、嵌套卡片一起检查。视图工具可用紧凑成组控件或具名菜单，真实操作仍有持续可辨认边界、可访问名称与键盘焦点，不以隐藏/删除必要能力换取简洁。 |
| TOOLBAR-03 | 实际打开条件编辑器、列设置及菜单并完成操作；排序/分页/清除条件、导出文件内容、刷新响应均正确。选择另一对象、切换角色后不沿用陈旧筛选或泄露数据。只测菜单展开不算通过。 |
| TOOLBAR-04 | 390px 下工具区不先堆满多行按钮、遮挡数据或挤掉状态；收起辅助操作后入口仍可见，弹层不出屏，键盘关闭后回到触发点。空表与有数据表分别验收，不能只选短标签截图。 |
| NOTICE-01 | 正常、无数据、无筛选结果、加载、失败、无权限分别显示恰当反馈。无筛选时不要求调整查询条件；同一前置条件不在横幅、禁用按钮说明、空状态中重复讲述。必要错误、风险和恢复入口必须保留。 |
| NOTICE-02 | 逐条说明记录必要性及所属位置；删去不会影响决定/操作的教学、内部技术术语与重复事实。状态变化后旧提示及时清除；不把所有说明改成信息图标。检查 Tab/抽屉/子页面与只读权限，不能只审首页。 |

## 详情阅读 recipe 的验证

沿用设计技能 [详情阅读的默认 recipe](../../enterprise-ui-design/references/forms-and-feedback.md#详情阅读的默认-recipe)。下表是 READ-04～07 的验收映射，SPACE-09 负责其中的几何断言；不以已有 `dl`、grid 或无横溢出免检。默认责任落在现有共享组件；若某实例依赖临时页面 CSS 才合格，记录组件能力缺口和受影响消费者。

| 检查族 → 设计规则 | 实际操作与断言 | 维度拆分 |
|---|---|---|
| DETAIL-01 → READ-04 | 进入/切换非首版本，核对对象、版本、正文与状态；圈出同一范围状态的全部位置及 owner。标题和当前状态在同一可换行身份组；不能相隔整幅页宽。选择器展开项可有各版本状态，不能误删；只读角色无伪主按钮。 | business：范围/状态真实；interaction：切换及回读；display：状态名称/重复责任；layout：标题/状态邻近 |
| DETAIL-02 → READ-05 | 大屏、详情侧栏挤窄、390px，使用短元数据、长名称、多行备注和未知值；量字段组宽、标签/值起点及距离，对照 Blueprint 阅读宽度。两列拉到面板两端仍判失败；叙述整行、不挤标签，读取完整值。 | display：关联/完整值；layout：组宽/对齐/重排；只读无写操作可按契约预先 N/A |
| DETAIL-03 → READ-06 | 不展开技术区先寻找内容/结论，再用键盘展开校验信息，读取/复制完整值并与真实来源比较，关闭后检查焦点。hash 不能叫“内容摘要”；真实校验任务直显须有任务依据。 | display：准确命名/主次；interaction：展开/复制/焦点；business：值和当前版本一致；layout：长码不破坏阅读区 |
| DETAIL-04 → READ-07 | 多条/单条/长正文/空/错误状态中识别标题、片段号、页码、正文及动作所属对象；实际执行获授权动作，核对其范围。片段动作与整体批准不能被同权重或贴近误认；几何另跑 SPACE-09。 | business：动作作用域；display：身份/位置/正文层级；interaction：动作结果；layout：引用 SPACE-09 独立检查 |

按现有 schema 3 将检查族拆成独立 ID，例如 `DETAIL-01.business`、`DETAIL-01.layout`，分别分配维度；`SPACE-09` 仅分配 layout。同一截图可复用，不能一个 ID 兼作四维通过。台账检查器接受这些 ID，不增加 schema 或宣称它能识别截图主次。

正反例复测：使用同一组对象/版本/长正文数据，反例为“标题/状态两端、短字段散开、hash 叫摘要、整体批准紧贴最后片段”，正例按 recipe 调整关系且保持事实/权限/动作不变。保留前后截图、字段及动作范围回读和实际测量。没有运行应用时只记录该用例为 NOT_RUN；示例文案、关键词扫描及合成 checker 测试均不能形成视觉 PASS。

## 验收与判定

为每个受影响页面绑定适用检查 ID、期望、契约来源及角色/状态；共享组件单测不能代替各页面集成实例。至少覆盖项目支持的桌面/390px、浅色/深色、长内容、有数据/空状态、可写/只读角色，并核对加载/错误恢复；没有真实服务时明确记录模拟范围。

每个适用路由和子上下文记录字段/空态所属容器、四边 inset、标签/值与标题/正文关键线；对应 SPACE-07/08 留存实际测量。截图必须实际查看；结合几何/样式、可访问树和键盘操作判断标签关系、主次、遮挡与焦点。记录“能否找到某项信息/动作”的具体步骤，不能只凭无溢出、文字存在、对比度或模型分数宣布易用。用户理解测试与审查者判断分开报告。

人员误认、计数范围错误、状态或业务动作不可见等按影响定为阻断；明显分组不清、工具栏压过内容、重复提示仍未修复时保留 FAIL，不能被其他通过项平均掉。缺少设计/权限/数据契约记 BLOCKED；未执行组合保留 NOT_RUN。修复后重跑原失败项及关联页面，不删除历史失败。
