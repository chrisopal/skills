# 信息结构、只读资料与列表工具栏

当页面能点击但难以读懂、详情连续堆叠、工具栏过重或提示重复时，按本表增加逐页面检查。与项目 Blueprint、组件清单及语义 Token 一起使用；不另定固定配色、像素尺寸或按钮数量上限。自动布局指标通过不能抵消已观察到的信息理解缺陷。

## 先确认结构契约

从业务需求与接口列出：对象身份、当前阶段、待办、关联样品/子对象、资源、依据、成品、历史资料。记录每类事实的所属分组或 Tab、主入口及权限；计数注明分母（实物、检测分配、工作包、报告不能混用）。没有数据的状态不能补造人员、进度或资源。原型示例值不得直接迁入正式页面。

| 检查 ID | 可观察的预期与执行 |
|---|---|
| IA-01 | 身份、阶段与当前可办理事项能区分。进入进行中/退回/已完成对象，按实际契约找出当前事项、对象、负责人和下一入口；已完成页面优先呈现成品及完成证据，不继续堆空待办或无效生成按钮。缺失负责人显示真实未知状态。 |
| IA-02 | 样品、执行、设备、依据、报告、资料等独立内容有具名边界。逐 Tab/分组进入、返回、刷新或深链接后仍指向同一对象；隐藏区域不抢焦点或误提交。选择已有表格/分组/Tab 组件，不能仅用更多说明句修补层级。 |
| IA-03 | 阶段连线区分完成/当前/未开始/未知，部分完成与归档来源真实。390px 下先能看到当前事项和数据，展开完整阶段、横向 Tab 滚动及键盘操作可达，无状态列被静默删除。 |
| FORM-READ-01 | 只读资料使用有标签的字段结构。姓名/时间、联系人/电话分开，长结论可跨列；设备名称、关联项目、适用样品与检测方法、执行标准、判定限分别标明。不能用无标签的多行字符串或横向串排让读者猜含义。 |
| FORM-READ-02 | 只读值不伪装成禁用输入框；标签和值对齐，长值换行不覆盖相邻字段。桌面与390px 均核对字段关联和完整值；业务名称优先，必要标准编号、单位和精度准确保留，技术标识按业务/审计需要收起且仍可访问。 |
| TOOLBAR-01 | 业务命令、查询条件、视图工具有主次。默认、有筛选、空数据分别查看截图；不得让通用筛选/列设置/导出/刷新形成比对象数据更突出的等权大按钮带。不能为了制造主操作而新增无接口动作。 |
| TOOLBAR-02 | 同一刷新、导出或筛选只有一个合理入口；页头、列表、嵌套卡片一起检查。视图工具可用紧凑成组控件或具名菜单，真实操作仍有持续可辨认边界、可访问名称与键盘焦点，不以隐藏/删除必要能力换取简洁。 |
| TOOLBAR-03 | 实际打开条件编辑器、列设置及菜单并完成操作；排序/分页/清除条件、导出文件内容、刷新响应均正确。选择另一对象、切换角色后不沿用陈旧筛选或泄露数据。只测菜单展开不算通过。 |
| TOOLBAR-04 | 390px 下工具区不先堆满多行按钮、遮挡数据或挤掉状态；收起辅助操作后入口仍可见，弹层不出屏，键盘关闭后回到触发点。空表与有数据表分别验收，不能只选短标签截图。 |
| NOTICE-01 | 正常、无数据、无筛选结果、加载、失败、无权限分别显示恰当反馈。无筛选时不要求调整查询条件；同一前置条件不在横幅、禁用按钮说明、空状态中重复讲述。必要错误、风险和恢复入口必须保留。 |
| NOTICE-02 | 逐条说明记录必要性及所属位置；删去不会影响决定/操作的教学、内部技术术语与重复事实。状态变化后旧提示及时清除；不把所有说明改成信息图标。检查 Tab/抽屉/子页面与只读权限，不能只审首页。 |

## 验收与判定

为每个受影响页面绑定适用检查 ID、期望、契约来源及角色/状态；共享组件单测不能代替各页面集成实例。至少覆盖项目支持的桌面/390px、浅色/深色、长内容、有数据/空状态、可写/只读角色，并核对加载/错误恢复；没有真实服务时明确记录模拟范围。

截图必须实际查看；结合几何/样式、可访问树和键盘操作判断标签关系、主次、遮挡与焦点。记录“能否找到某项信息/动作”的具体步骤，不能只凭无溢出、文字存在、对比度或模型分数宣布易用。用户理解测试与审查者判断分开报告。

人员误认、计数范围错误、状态或业务动作不可见等按影响定为阻断；明显分组不清、工具栏压过内容、重复提示仍未修复时保留 FAIL，不能被其他通过项平均掉。缺少设计/权限/数据契约记 BLOCKED；未执行组合保留 NOT_RUN。修复后重跑原失败项及关联页面，不删除历史失败。
