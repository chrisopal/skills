# 运营工作台布局的真实浏览器检查

适用：指标首页、宽表、审核队列、统计编辑器、权限详情。来源为 LIMS 2026-10-23 飞书 UI 导出的 20 条非空问题，项目原件 `artifacts/ui-optimization-20261023/issues.ndjson`。项目建议是选择断言的线索，不是其他应用的业务标准；先核对 Blueprint、数据/权限契约与宿主组件，再将下列检查族展开到实际页面/控件。

沿用现有 `scope.json`、`coverage.json` 和四维记录，不改变 schema 或 PASS 规则。每个独立断言归一个维度，截图可复用；相同组件的页面容器、权限、绑定不同，仍需各自集成检查。需要的组合至少涵盖问题原视图、长内容、浅深主题与受支持窄屏；项目支持 390px 时明确测量该宽度。缺契约记 BLOCKED，未执行记 NOT_RUN。

## 记录与判定

- 截图同时记录实际 URL/选中视图、角色、对象/数据前提、主题、视口和运行版本；图表切换、抽屉开关、权限搜索等先等待可观察稳定状态，不凭截图文件名推断当前主题或页面。
- 为每项保留原失败/反馈、当前修复范围和复测证据。静态检查、台账校验、真实浏览器、生产回读与人工接受分别报告；自动结果不得覆盖飞书原有人工否或空白结论。
- 检查重点是信息可读、任务连续和真实内容完整，不是把页面强行占满。缺少完整值访问、排序键盘路径、当前预览或真实告警依据，仍保留相应 FAIL/BLOCKED，不用其他通过项平均掉。
