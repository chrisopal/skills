# 统计视图真实浏览器检查

适用：折线、柱/条、饼/环、堆叠、直方图、散点或统计图表与数据表切换。先阅读 Enterprise UI Design 的[统计视图设计决策](../../enterprise-ui-design/references/statistical-views.md)，再将下面的检查绑定到实际页面、角色、接口和数据快照。这里补充四维台账的可观察断言，不改变 `scope.json`、`coverage.json` 或 PASS 规则。

## 开测前冻结的统计契约

为每个图表实例记录：指标/对象、数据源 API 或查询、时间字段与时区/边界、过滤器、粒度、单位/精度、分子/分母、有效样本数 `n`、缺失/零/异常规则、默认与用户选择的图类、权限范围、构建版本和数据截止时间。生产路径必须使用真实业务返回或批准的聚合接口；没有真实数据、来源、分母或图类能力时记 `BLOCKED`，不能用 fixture、随机数或填充行产生 PASS。

截图、网络证据、数据表和明细回读要使用同一角色、范围、数据快照与版本。独立记录 `business`、`interaction`、`display`、`layout` 四维断言；一张图或一份截图可被多个断言引用，但不能用“图看起来对”替代数据回读。

## 统计图类检查

| ID | 操作与真实数据前提 | 通过条件 |
|---|---|---|
| STAT-U01 口径可读 | 打开真实有值范围，读取标题、时间范围、粒度、单位、截止/更新时间、过滤摘要、`n` 与分母；对照请求和数据表 | UI 口径与接口/查询一致；比例可追溯分子/分母；精度符合契约；没有把内部字段名当指标名 |
| STAT-U02 趋势语义 | 准备至少两个期间、一个零值和一个缺失期间；切换筛选/粒度并比较折线、表格和请求 | 时间顺序正确；缺失期间断线/明确标记且不补零；零值落在零线上；切换后数据集合、排序和范围一致 |
| STAT-U03 对比语义 | 用长类别名、零、负值、极值和多个对象查看柱/条；读取轴与数据表 | 类别/排序可发现；条形长度与表值一致；从零线表达数量；负值方向正确；截断轴有明确提示；长名不裁切到无法辨认 |
| STAT-U04 组成语义 | 用可加总类别、未知/其他项和零占比数据打开堆叠或饼/环；核对总量和分母 | 类别加总与总量一致；环图适合少类别且中心/旁侧显示总量；未知不被静默塞入已知类；不同分母不被并排误导 |
| STAT-U05 真实直方图 | 使用同一数值测量字段的真实多条记录；读取数值轴、bin 边界/宽度、频数或占比、有效 `n`、无效/缺失数 | 柱表示连续数值区间且边界可解释；频数/占比分母正确；不是按类别各画一根柱的柱状图；图中值与表/明细可回读 |
| STAT-U06 小样本与显式选择 | 用户明确选择已支持图类，再以单点、少量记录、长尾或全零范围查看并切表/返回 | 支持且契约匹配的图类仍可见并如实标 `n`/稀疏/零；不自动吞掉选择；切换建议是可见操作；返回保留图类与筛选 |
| STAT-U07 不支持能力 | 选择不适用于当前字段的图类，例如分类状态选择直方图，或宿主声明未支持箱线图 | 界面如实显示“当前数据/能力不支持”及原因；不画伪图、不显示成功数字；可进入真实表格或已支持图类并记录缺口 |
| STAT-U08 异常与分母 | 准备真实离群、非法/缺失值、重复记录或分母为零/未知的范围；查看图、表、明细和错误恢复 | 原值可追查；异常有标记/说明，不静默截断、去重或改成零；分母为零/未知不伪造 0%/100%；修复/重试后重新回读 |

## 视图切换、响应式与主题

| ID | 操作 | 通过条件 |
|---|---|---|
| STAT-U09 图表/表格往返 | 同一真实范围依次图表→数据表→图表；修改筛选、排序、分页和选中对象；必要时下钻再返回 | 图与表使用同一快照/范围；全部列名、单位、行/分页可达；切换不丢筛选、图类或选中项；返回恢复上下文 |
| STAT-U10 浅深主题 | 在浅/深主题读取轴、零线、系列、选中、告警、无数据和失败态，检查键盘焦点/可访问名称 | 系列和状态在两主题均可辨；关键差异不只靠颜色；焦点、图例、表格和状态文字可读；主题不改变数据 |
| STAT-U11 桌面与 390px | 在项目支持的桌面宽度与 390px 打开长标题、长图例、宽表和多序列图；滚动、Tab、打开/关闭局部容器 | 无页面级横向溢出；图表局部滚动具名且不遮焦点；标题/图例/表头可达；表格完整值可读或按契约局部滚动；不以缩小文字隐藏内容 |
| STAT-U12 真实状态与刷新 | 观察加载、真实无数据、全零、网络失败/重试、无权限和成功刷新；保存 URL/版本/请求与截图 | 骨架不含虚构数字；零、空、失败、无权限分别表达；旧数据保留时显示旧更新时间/失败；权限不泄漏聚合；重试成功后图、表、明细一致 |

## 证据与判定

- 每项结果保存实际 URL、角色、构建/运行版本、主题、视口、筛选、对象/数据前提、数据截止时间和截图/测量路径。等待图表完成布局、接口返回、切换和分页稳定后再取证。
- 对统计数值至少保留一条独立回读链：图表序列或 bin 计数 → 数据表 → API/查询响应或有权限的明细。表面成功、HTTP 200、图例文字或截图单独都不算 PASS。
- 真实生产数据不可准备、接口来源不明、分母未定义、图类能力未实现或无法访问完整数据表时，按具体维度记 `BLOCKED`/`NOT_RUN`；不要用相似页面或模拟 fixture 抵消。
- 图表在小数据下仍支持且如实显示不代表统计结论可靠；报告同时记录样本量和产品约束。趋势缺期间、直方图分箱、组成分母等语义不清时保持 FAIL/BLOCKED，不能用视觉整齐替代。

适用时将 `STAT-U01` 至 `STAT-U12` 追加到现有 [运营工作台布局检查](operational-layout-checks.md) 的页面/控件台账；`UAT-O12` 继续检查图表与表格重排，不能替代本参考的口径、图类和真实数据回读。
