# 字号与文字层级

字号以最终 PPTX 的 **pt** 为准。图片像素、OCR 字形高度、PowerPoint 字号不是同一个量；不能把 `40px` 直接写成 `40pt`，也不能因为页面空白多就放大正文。先判断文字角色，再确定字号，最后从成品回读并检查真实渲染。

## 依据与适用范围

以下为既有参考记录（检索日期：2026-10-11），本次用户偏好修订未重新检索。

- [Microsoft：有效演示建议](https://support.microsoft.com/en-us/powerpoint/tips-for-creating-and-delivering-an-effective-presentation)：尽量避免低于18pt；大型会场、远距离观众需要更大字号。采用简单易读字体、短句和清楚对比。
- [University of Manchester：无障碍幻灯片指南](https://documents.manchester.ac.uk/display.aspx?DocID=51041)，2020版：正文18–22pt、标题约30pt；相同数字的不同字体，视觉大小仍有差异。文字过多时应提供配套材料。

以下默认值来自用户对**中文密集商务稿**的明确偏好：微软雅黑、普通内文四号（14pt）。这不是咨询公司官方模板或通用强制标准；14pt低于上述18pt无障碍建议，不能宣称符合该建议。以13⅓ × 7.5英寸宽屏页面、近距离屏幕阅读为基准，按观看距离、字形和实际内容验证。用户明确的品牌/大屏规范优先，覆盖值写入本项目主题 profile 并记录。

默认字体固定为 **Microsoft YaHei（微软雅黑）**，所有字号显式使用pt，以常规字重为主。生图前核对字体要求，可编辑重建与实际渲染前核实安装和目标应用解析；未安装或无法解析时报告缺口，不得静默换成苹方、冬青黑体、Noto等字体。用户明确授权替代时记录实际字体及差异。

| 文字角色 | 默认 | 使用边界 |
|---|---:|---|
| 内容页标题 | 28pt | 一页主标题，不把每段结论都升级成标题 |
| 副标题/主结论 | 16pt | 1–2行，不压过主标题 |
| 普通正文 | 14pt（四号） | 默认常规字重，不因留白放大 |
| 图内节点 | 14pt | 普通节点内容；只有模块短标题使用18pt |
| 图表/表格的必要标签 | 14pt | 类别、数值、单位和表格标签保持同级 |
| 模块标题/短标题 | 18pt | 仅模块层级，普通短标签不放大填空间 |
| 封面标题 | 44pt | 保留主题40–48pt范围；营销极短标题可到52pt，仅封面例外 |
| 非关键信息：页码/装饰性脚注 | 12pt | 重要来源、限定条件按正文14pt处理，不塞入小页脚 |

大型会场或无障碍要求由用户规范覆盖，可用更大字号并减少单页信息；不要把14pt密集阅读方案称为适合远距离投影。默认角色范围锁定目标值，不能从范围中随意放大或缩小；额外字号须有明确项目覆盖。

## 生图与重建之间的换算

主题的 `typography.roles_pt` 为权威值。参考画布的字体 **em尺寸** 换算：

`font_em_px = font_pt × image_width_px / (slide_width_in × 72)`

13⅓英寸页面宽为960pt；1920px参考图上的14pt正文约28px em尺寸，1672px原图约24.4px。这不是可见汉字墨迹包围框高度；字形、行距会影响实际占位。不要用浏览器96dpi换算代替PPT画布比例，也不要从OCR包围框高度直接认定字号。

生图工具不保证准确执行字号，必须查看结果；可编辑模式在 `manifest` 中按批准目标设置pt，并回读最终PPTX。运行时可能为文本框自动缩字，检查的是最终文件，不能只看请求字号。只有人工校准文本框并验证渲染后，才可关闭自动拟合。

## 排版与验收

- 内容页通常保留标题、模块标题、正文三个主要层级；页码独立。字号相同的标签用颜色/字重区分，不随意继续放大。
- 正文默认左对齐、常规字重。以约1.15–1.3倍行距为起点，按字体实际渲染微调；不要用加大行距掩盖过大的文字。
- 过满先扩框、换行或调整布局，必要时提出拆页方案；不自动缩字或删除已确认内容。过空保留留白，短标签不放大填空间。
- 14pt也必须查看实际PowerPoint/LibreOffice渲染，避免孤字行或拆散“数据基线”“异常闭环”“运维跳板”等术语。保留有语义的手动断行；不能因缩小字号就删除全部手动断行。必要时扩框或调整断行位置，再重新渲染核验。
- 明确写入Microsoft YaHei及每个文本run的pt目标；字体名称存在不等于目标应用正确解析。跨平台移交检查字体替代；只有许可允许时才嵌入字体，不承诺所有环境完全一致。缺失字体不能以静默替代判通过。
- 图片版没有原生文本，空的字号报告不能证明其字号合格；通过原图比例与实际渲染检查阅读性。
- 可编辑版用 `scripts/inspect_fonts.py 最终.pptx` 回读每段run的显式/段落默认字号、字体与文字；主题/母版继承无法确定时标为未知，不猜值。按角色核对范围，混合字号逐run检查。
- 查看PowerPoint或LibreOffice的实际渲染，检查换行、溢出、裁剪、字重、上下标和对比；Pillow预览不替代这一项。报告实际应用、实际字号、例外及未测环境。
- 忠实转换默认保留源图文字层级。如果用户明确要求缩小正文，本次授权允许调整字号/文本框并保留原文和图形语义；将这些记为有意修订，不冒称逐像素还原。
