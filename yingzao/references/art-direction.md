# 艺术指导方法

本文件在方案需要具体字体、构图、材质或文化转译判断时读取。它提供设计方法，不是必须逐条执行的检查表；生成前硬门只以 [preflight-gates.md](preflight-gates.md) 为准。

## 1. 从照片证据出发

先判断照片在说什么，而不是先套“中式复古”：

- **纪念碑尺度**：塔、城楼、正殿、完整正立面。字形可更稳定、更具构筑感；版面要保护垂直或水平重量。
- **构件尺度**：飞檐、斗栱、藻井、匾额、门环。适合局部巨像、切边、几何字形与结构性遮挡，不必补成完整建筑。
- **环境尺度**：街巷、村落、民居、庭院。用路径、层叠屋面、远近明度或共同色场组织，不把所有房子等权排列。
- **亲密尺度**：食物、器物、暖光室内。保留湿润、温度、手感和近距离景深；资料字可以轻巧，避免纪念碑粗黑。

观察轴比题材枚举更可靠：

| 照片轴 | 字体方向 | 材质与节奏 |
| --- | --- | --- |
| 硬光、锐利几何、远景 | 窄体、构筑型宋/黑、较紧字面 | 硬切、线刻、低频色块 |
| 柔光、暖色、近景 | 人文宋、圆润黑体、书写感点题字 | 羽化、颗粒、纸纤维、缓节奏 |
| 高密度纹样或木构 | 字腔更开、结构更简、避免繁上加繁 | 分区限色，局部保留细节 |
| 大留白、低饱和 | 可用高对比字形或偏置长行 | 单一强色场、克制纹理 |
| 夜景、霓虹或灯笼 | 字重稳定，小字无衬线 | 深底、发光边缘、局部高饱和 |

## 2. 字体不是宽泛标签

“宋体”“衬线”“书法”“高级复古”不能独立构成字形说明。展示字必须从可见形制描述：

- 谱系：碑刻、榜书、匾额、雕版、报刊标题、人文宋、几何宋、隶意、行楷、篆刻或实验字。
- 比例：方/窄/宽，长横与竖画的张力，重心高低，内白大小。
- 笔画：横竖对比、起收笔、折角、撇捺、钩挑、粗细是否均匀。
- 节奏：字间是独立、咬合、错落、连写还是共享边界。
- 媒介：木刻、石刻、手写墨迹、旧印刷、金漆、漆牌、现代纸张或数字几何。
- 建筑对应：屋坡对应斜势、柱列对应竖画、斗栱层叠对应横向节奏，但不能损坏汉字标准部件。

标题与小字承担不同角色。大字可以是定制形制，小字优先可读；可用人文无衬线、窄黑、另一种宋体或等宽数字建立层级，不要求全套同一宋体。书法字只在地点语义确实相关时点题，例如兰亭与书法传统；不要把所有古建都自动书法化。

## 3. 构图先解决照片问题

先用一句话诊断原构图，再只选一个主修复动作：

- **preserve**：偏心、框景、对角动势、横向跨越本来成立，只建立文字的进入方式。
- **deterministic-rectify-crop**：无意滚转或轻微透视破坏稳定性，用脚本校正。
- **semantic-recompose**：主体截断、支撑断裂、死负空间或多来源割裂，需要模型移位、补齐低风险连续区域并重建空间。

建筑处理不是“抠出来放正”这么单一。可选择：局部巨像、尺度跃迁、平面与照片双层、轮廓重复但不复制构件、分区限色、线刻与实景并置、负形咬合、色窗穿越或边缘出血。原来的仰视与对角若有表现力，应被强化而不是抹平。

主体与文字要共享空间：屋脊压住一部分标题、柱列穿过结构字、檐口与字的横画共边、圆形构件进入字腔、食物或果实连接标题笔画。遮挡不应破坏专名的关键识别部件。

## 4. 主动背景与材质层级

背景不是原天空，也不是默认渐变。它可以是：

- 从建筑原生色提取的拼色色场或色窗；
- 明度切片、局部反相或深浅底切换；
- 延伸后的天空、墙面、水面、纸张或夜色共同空间；
- 由屋面、城墙、山体或食物轮廓产生的负形；
- 服务阅读路径的低频纹理与一个高频局部。

材质至少有主次：主材质负责统一世界，辅助材质只强调一个区域。不要把纸纹、网点、线刻、噪点全部平均铺满。主体内部可按屋面、木构、墙体、牌匾、食物表面分区处理；共同光向、接触阴影和一致边缘语言决定它是否像一个场景而非贴纸。

配色优先来自照片的建筑漆色、砖石、天空、山体、植物、灯光或食物。两中性加一强调色是安全起点，不是固定公式；深底、朱红满版、高饱和双色和摄影本位的现代编辑风都可成立。

## 5. 语义装饰

装饰不是填空。花枝、果实、祥云、印章、砖纹、斗栱轮廓或地图线只有同时满足以下条件才加入：

1. 来自照片可见、用户确认或可靠事实；
2. 至少承担两项任务，例如主题识别 + 色彩桥接，方向引导 + 遮挡过渡；
3. 锚定到真实主体、标题或共同轴，不漂浮；
4. 不篡改主体身份，也不破坏汉字拓扑。

例如“沙棘”可把少量果实嵌入展示字的局部笔画，并在空白角落形成一次色彩回声；不能撒满整张图。普通留白有呼吸作用，不必全部装饰。

## 6. 多图融合与组照

用户要求“融合”时，不保留原始照片矩形：逐图提取店招、食物、器物、灯笼、室内木作等主体，在一个共同背景里重建透视、光向、色温、接触面与跨来源遮挡。主次必须明确，单个元素可局部出血或被文字遮挡。

用户明确要求“拼图、组照、左右对照”时才使用图片窗。即便如此，也要有主图、次图、共同轴和一个跨窗联系，不能做等权九宫格。

## 7. 文化转译

地域与朝代信息只使用可核实内容。可提取真实斗栱、屋脊、瓦当、彩画、碑刻、花窗、白族照壁、地方植物或食物形态作为机制；不能凭“古风”补龙凤祥云。

使用外国或纯英文参考时只迁移抽象机制：主体占幅、负空间、色场、字形节奏、材质层级、遮挡关系。目标照片的几何、中文语义和在地材料必须接管内容；删除原参考的建筑、人物、宗教符号、地名、品牌与徽章。

## 8. 克制原则

一个方案只需一个主构图、一个主体容器、一个主材质、最多一个辅助材质、一套有角色差的字体、一个配色来源、一个主要空间冲突和零或一个语义装饰。视觉权重大致为主导 60%、辅助 30%、点睛 10%，不是必须精算的公式。
