# 中文展示字形形制

本文件只处理海报中的短展示标题或结构性大字。它不替代字体文件，也不鼓励图像模型随意“造字”。目标是把“宋体、黑体、衬线”这类宽泛门类进一步编译成可观察的字形形制，使同一字体谱系能够产生真正不同的骨架、重心和表面语言。

截图、外国字体案例和纯文字海报只提供**字形方法**：比例、笔画、字腔、连接、节奏和材质。不得复制其中的品牌、拉丁语义、徽章、宗教符号或西式身份；最终形制必须由当前中式建筑的几何、材料与叙事语域接管。

## 1. 展示字与资料字分开

- 展示标题可进入 `reinterpret`：垫图锁定文字内容、字面边界、阅读顺序、共同轴和基线，但普通字体轮廓不是最终轮廓。模型要在这个空间内重绘字形。
- 地点、年代、事实、拼音和资料微字使用 `literal`：保持常规真实字体，不做连笔、变体、缺笔、异体或材质侵蚀。
- 一张海报只选一个展示字形形制。不同资料角色可换字族或字重，但不能再引入第二套表现型字形。
- 正式名称必须使用规范字。形制变化不能改变部件拓扑、增减笔画或把装饰当笔画。

## 2. 字形形制简报

进入提示词前必须填满以下字段。`高级、艺术、复古、克制、活泼` 等气质词有意义，它们说明审美目标与时代感；但必须与下面的可见形态字段成对出现。只有气质词、没有形态证据时，才视为未完成：

```text
glyph_design_mode: reinterpret / literal
字形谱系：宋明 / 碑额篆刻 / 隶意 / 几何黑体 / 民艺拙笔 / 其他 __
宽窄与重心：宽 / 方 / 窄；高 / 中 / 低重心
横竖对比：__ : 1；是否存在粗细突变 __
收笔：刀刻楔脚 / 方切木构 / 圆收 / 隶意外拓 / 干笔 / 其他 __
字腔：开放 / 方正 / 圆形 / 八角形 / 狭长；内部留白比例 __
连接：独立 / 共笔 / 榫接式桥连 / 局部连写；发生在哪些笔画 __
节奏：稳定等宽 / 疏密递进 / 轻微错落 / 跳跃；为何匹配照片 __
词组锁定：locked-wordmark / expressive-sequence；共同字高 __；共同基线 __；等宽字槽 __；允许变化只发生在 __
表面：净版 / 木版墨蚀 / 石拓 / 矿物颜料 / 旧匾磨损 / 其他 __
建筑对应：形制具体回应照片中的 __
不可变：规范字、部件拓扑、阅读顺序、字面边界、共同轴
```

至少写出五项能从最终图上直接看到的形态特征，且必须包含“建筑对应”。若删掉建筑名后仍适用于任何海报，简报过于泛化。

`locked-wordmark` 用于庄严建筑、匾额语境和需要稳定秩序的 2–5 字标题：各字先进入等宽字槽，保持相同光学字高与共同基线，再在字槽内部调整笔画。不得用书法感为理由改变单字字号、上下错位、形成对角阶梯或把三个字拆成独立图形。`expressive-sequence` 只有主导参考明确依靠错落节奏成立、且照片本身具有相应动势时才使用。

2–5 字标题还必须逐字填写光学补偿。字体家族只决定共同语法，真正的字形设计发生在每个字如何占据同一节奏中：

| 字 | 原字在本标题中的光学问题 | 本字轮廓动作 | 必须保持的标准部件 |
| --- | --- | --- | --- |
| 例：小 | 天然字面窄，和复杂字并排时显小 | 两侧点画外拓、中心竖画建立主脊，但仍落在共同基线 | 小的三笔结构与阅读顺序 |

不得把逐字补偿写成“更艺术、更复古”。至少指出字面占比、重心、局部横张、字腔开放度或端点中的一项具体改变；所有改变都服从词组锁定、共同字高、基线和规范字拓扑。

## 3. 六个中式形制家族

### A. 刊刻楔脚宋 `cap.type.glyph-carved-song`

- 谱系：宋/明体，但不是默认电脑宋体。
- 形态：横细竖粗约 `1:2.2–1:3`；竖画挺直，横画略有手工波动；末端为短促刀刻楔脚，而不是圆润三角衬线；字腔偏方、略收紧；外轮廓允许轻微木版缺口。
- 适用：文献、木构、古寺、旧匾、出版感建筑专题。
- 禁用：把全部笔画统一做成脏边，或让复杂字因墨蚀而缺笔。

### B. 碑额篆刻 `cap.type.glyph-seal-inscription`

- 谱系：篆额、题签与古印的结构记忆，不直接复制小篆字形。
- 形态：方整紧凑、转折略圆、收笔带凿刻顿点；字腔小而稳定；外框可产生额题般的横向压缩；1–4 字最合适。
- 适用：匾额、山门、题名、碑刻语境。
- 禁用：伪造印章、随意改成异体字、给长正文使用。

### C. 构架几何变体 `cap.type.glyph-architectural-modular`

- 谱系：几何黑体与明体骨架的中式再设计。
- 形态：竖画像柱，横画像梁；转折使用方切或短榫接；字腔为方形、圆形或八角形；局部重复模数来自斗拱、藻井或券洞；字重稳定但不是普通粗黑。
- 适用：藻井、斗拱、门洞、规整中轴、具有明确模块几何的建筑。
- 禁用：把所有笔画画成管线图；不得为追求几何而改变汉字部件关系。

### D. 横张隶意 `cap.type.glyph-clerical-wide`

- 谱系：碑刻隶意与横向展开的标题字。
- 形态：低重心、横向宽张；横画末端克制外拓，竖画短而稳；字腔扁方；各字同高同宽，适合全幅等宽行。
- 适用：城墙、城门、长桥、横向屋脊和纪念碑体量。
- 禁用：夸张蚕头燕尾或书法飞白；资料字不使用此形制。

### E. 民艺拙笔 `cap.type.glyph-folk-naive`

- 谱系：民间手绘、纸扎、壁画、店招和儿童般的拙趣。
- 形态：粗细突变、局部夸张伸展、边缘不规则、字与字可轻微错落；允许一处自然共笔或连接；整体仍能在缩略图辨认。
- 适用：民俗器物、手作、彩绘、轻松旅行叙事。
- 禁用：庄严佛殿、文保档案、长正文；不能把“拙”做成错字或随意缺笔。

### F. 理性明体 `cap.type.glyph-rational-ming`

- 谱系：高反差明体的编辑化、理性化版本。
- 形态：横画极细但不断裂，竖画清晰；收笔锐利短小；字面偏窄、重心稳定；字腔开放；轮廓干净，依靠比例而不是纹理产生气质。
- 适用：档案、摄影本位、安静室内、当代编辑海报。
- 禁用：在高频背景上使用过细横画；不得与另一套高表现标题争夺第一层级。

## 4. 垫图如何避免锁死普通宋体

`typeset-guide` 仍用真实字体计算 cmap、字面、尺度和轴线，但 `reinterpret` 不把全尺寸普通字体轮廓画进交给模型的图像：

- `glyph_design_mode: reinterpret` + `guide_render: scaffold`：Image 3 用字符槽和小型字面标签提供范围、共同轴、阅读顺序和遮挡位置；最终字形必须按选定形制在槽内重新设计，scaffold 不进入成图。
- `glyph_design_mode: literal` + `guide_render: text`：展示字保留常规字形；小字与资料字也保持 literal，不做表现型重绘。

字符槽是空间证据，不是矩形版式或最终色块。它只在输入垫图出现，使用中性低对比线框；精确字面由提示词的 `Text (verbatim)` 和槽内小标签共同锁定。若主导参考的展示字不足以支撑所选形制，优先换成能同时支撑主体、背景、图文关系和字形节奏的参考；不要用第二套完整海报稀释主导机制。

## 5. 最小提示词片段

只加入一段具体字形指令，不串接六个家族：

```text
Display glyph design — reinterpret only the large verified title “__” inside Image 3's measured bounds. Preserve its <locked-wordmark / expressive-sequence> group geometry, including the measured character slots, common optical height and baseline; do not copy the guide font silhouette. Use <谱系> with <宽窄/重心>, <横竖对比>, <收笔>, <字腔>, <连接或节奏>, and <表面材质>, derived from the target's <建筑几何/材料>. Keep every Chinese component and stroke topology legible. Keep all small metadata literal and conventional.
```

不完整示例：`make the font artistic, premium, vintage and Chinese`。这些词应保留为气质层，但还没有规定可见形态，模型容易回到默认宋体或粗黑体。应补上骨架、比例、收笔、字腔、节奏与材料证据。

## 6. 用户反馈触发的字形修订

成图后的快速读回会指出“字形仍普通、字写错、字形设计不足或小字被污染”，但不会自动调用或修图。只有用户明确要求修改时，才读取本节并执行一次受限 edit：

```text
Image 1: 用户正在反馈的当前海报，是 edit target
Image 2: 可选的字体方法参考，只提供字形证据
Primary request: change only the verified display title “__”
Locked invariants: preserve composition, subjects, palette, material zones, small text and all non-title pixels
Glyph action: compile the saved glyph brief plus every character's optical compensation
Requested result: exact text; same measured bounds; execute the named feedback and the saved per-character compensation
```

它仍由图像模型把文字融入原有油墨、纸张、遮挡和材质，不属于 `layered-final-type`。锁定用户没有要求改变的构图、主体、材质和小字；修改后交回用户，不自动继续第二轮。
