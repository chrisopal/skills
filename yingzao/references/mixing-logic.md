# Recipe 与参考选择

本文件只负责从候选中选出一套兼容方向；照片、简报、门控和提示词分别以 `photo-preflight.md`、`creative-brief.md`、`preflight-gates.md`、`image-generation-workflow.md` 为真源。

## 1. 先冻结命题

运行 `suggest` 前写下：`主体处理 / 主动背景 / 图文互动 / 非默认排版动作`。候选参考只能验证、强化或否决命题，不能把其中任何一项替换成“保留原照”“普通渐变”或“标题居中”。

## 2. 局部检索

```bash
python3 scripts/design_tokens.py suggest \
  --tag <受控标签> --count <数量+1> --maximize-distance \
  --history output/yingzao/<run-id>/recipe-history.json \
  --record-history
python3 scripts/design_tokens.py recipe <id> --json
```

零命中返回状态 2，换受控词重查。只读取候选 Recipe 和其 `reference_assets`，不要批量加载 Token JSON 或全部参考编码。高风格化任务必须解析出真实 plate；没有实图输入就换候选。

## 3. 四步适配

1. **几何**：照片主轴、身份轮廓与主体容器相容。横向桥/城墙不用窄塔字窗；宽阔多重檐不套高密度多窗；仰视飞檐不强行补成正立面。
2. **画面拓扑**：主体占幅带、负空间位置/形状和计划互动边界相近。只有字体或颜色好看，但主体仍是未处理照片的参考应淘汰。
3. **完整机制**：参考同时提供可迁移的主体处理、主动背景/色场、图文关系和材质层级。把准备迁移的 2–4 个强机制与禁止迁移内容分开写；如果禁项删掉了参考最醒目的图形、材质和主体处理，只剩抽象形容词，就不是有效主导参考。次要参考最多补充一个字体、取色或局部材质方法。
4. **身份边界**：明确只迁移抽象机制，不迁移参考中的建筑、地名、人物、品牌、徽章、宗教符号和广告。

## 4. Token 关系

每张海报只选一个 `layout-primary`、`subject-container`、`background-scale`、`context-material`、`expressive-type`、`glyph-morphology` 和 `line-policy`。递归展开 `requires`；任一 `conflicts` 或 mutex 超额即淘汰。兼容项可以加分，不要求启用所有 optional Token，也不逐条串接 Token 的通用 prompt/constraints；但已经进入 Recipe 的 resolved Token 与主动选择的 optional Token 必须全部并入 `design-plan.json` 的四域模型动作或允许的确定性预处理。

## 5. 常见照片方向

| 照片特征 | 适合 | 避免 |
| --- | --- | --- |
| 高塔、楼阁、中轴 | 完整轮廓、窄长塔身、竖题、细线刻 | 粗阈值吞檐口 |
| 桥、城墙、横向屋脊 | 横张标题、侧边切入、局部巨像 | 窄塔字窗、切碎拱洞 |
| 低机位重复飞檐 | 强对角、负空间大字、套印 | 补成完整正立面 |
| 构件特写 | 局部巨像、几何字形、分区材质 | 长正文、导览卡片 |
| 暖光木作、食物、器物 | 逐个主体提取、编辑字体角色、共同环境 | 纪念碑粗黑、等权图块 |
| 同址多图合一 | 逐图提取、共同光线与接触阴影 | 四宫格、卡片、完整矩形 |
| 用户明确要求组照 | 主次图片窗、共同轴、跨窗联系 | 等权网格、假装一体化 |
| 原生色强 | 限色照片、标题/边缘同色呼应 | 无来源强调色 |

## 6. 字体与文化适配

记录主导参考字体的气质语义，以及宽窄、重心、粗细对比、收笔、字腔、连接/节奏、表面媒介和大小字角色差。只写“衬线、宋体、复古、高级”视为未分析。外国/纯英文参考另写：`保留机制 / 目标几何对应 / 中文语义接管 / 地域材料接管 / 删除内容 / 身份锚点`。

## 7. 多方案距离

不同方案的 Recipe family 与主布局不能重复，并至少在两轴不同：`主体容器 / 明度极性 / 字形动作 / 边缘语言 / 纹理频率 / 颜色行为`。只换底色、短词、纸纹或噪点强度属于同一变体。

选定后把实际参考路径、适配结论、依赖/互斥、字体证据、主/辅助材质、配色来源和唯一空间冲突写入 `creative-brief.md`。
