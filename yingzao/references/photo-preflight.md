# 照片预检、分诊与风格轴

## 先运行量化预检

```bash
python3 scripts/photo_preflight.py INPUT \
  --json output/yingzao/<run-id>/analysis/preflight.json \
  --visual-dir output/yingzao/<run-id>/analysis/preflight-visuals
```

脚本输出像素尺寸、长宽比、曝光、画幅方向、清晰度、边缘密度、估计滚转角、主色、负空间候选、关注区域、EXIF 时间/GPS（若存在）、分诊建议与预检可视化。数值是生成前决策证据，不替代对建筑本体的视觉判断。

## 适配度分诊

| 角色 | 条件 | 动作 |
| --- | --- | --- |
| `hero` | 身份锚点清楚，像素与清晰度足够，主体可分离，构图可通过裁切/扶正改善 | 可作主海报底图 |
| `support` | 局部细节、器物或环境有价值，但主体不完整、清晰度一般或负空间不足 | 仅用于多图融合的局部来源 |
| `reject` | 严重虚焦、过曝/欠曝吞掉锚点、主体被不可恢复遮挡、分辨率太低或压缩破坏结构 | 建议换图，不用下游规则硬救 |

程序评分只给建议。主体虽小但剪影极强、或历史照片本就低清时，可人工覆盖为 `support`，并写理由。

## 几何校正

只有相机造成的滚转与梯形透视需要校正。真实屋坡、飞檐曲线、建筑不对称和有意斜拍不能被“拉直”。

```bash
# 自动估计滚转后旋转，并裁掉黑边
python3 scripts/rectify.py INPUT CORRECTED --auto-roll --crop auto --report analysis/rectify.json

# 显式四点透视；点序为左上、右上、右下、左下
python3 scripts/rectify.py INPUT CORRECTED \
  --quad "120,80;1820,95;1860,1260;90,1240" --crop auto
```

正立面/中轴方案以主轴接近竖直、主要水平参照不再整体倾斜为目标；不要把 ±0.5° 当成适用于所有斜拍的强制指标。校正后的图是 Image 1，后续“保护几何”只针对它。

`--auto-roll` 的估计绝对值不超过 `0.3°` 时视为“无需旋转”的成功 no-op，即使线段置信度略低也不应卡死流程；报告中的 `auto_roll_noop=true` 说明脚本有意保留原图。只有估计超过 no-op 阈值且置信度不足时，才要求人工查看并改用 `--rotate`。

## 构图缺陷分诊

量化预检之后再做人工视觉判断；脚本给出的负空间和关注区域只能提示问题，不能决定构图。至少回答：

1. 偏心、仰视、对角线和遮挡是摄影意图，还是无意失衡？
2. 主体是否在决定身份或承重关系的位置被截断？被截部分能否由同一直柱、墙、天空、水面或地面安全延续？
3. 最大负空间能否承载标题、资料字或呼吸感；若不能，它就是死负空间而不是“高级留白”。
4. 主体的视觉重心与承接路径是否完整；文字能否进入主体前后层、字腔或轮廓边，而不是只能堆在剩余角落？

输出 `preserve / deterministic-rectify-crop / semantic-recompose` 三选一，并把一个主问题和一个主修复动作写入简报。只有 `semantic-recompose` 才交给 imagegen 做尺度、位置、连续背景或低风险连续构件补齐；详见 [creative-brief.md](creative-brief.md)。

## 可观察照片轴 → 字体与材质

| 照片轴 | 低端 | 高端 | 对版式/材质的影响 |
| --- | --- | --- | --- |
| 光线硬度 | 阴天柔光 | 正午硬光 | 柔光适合细衬线、低频材质；硬光可承受几何字、硬切和高对比平涂 |
| 色温 | 冷蓝 | 暖黄/木色 | 冷色可走银灰、深底、现代编辑；暖色适合明体/宋体、出版随笔、低饱和纸与木刻，但不等于默认米色 |
| 主体尺度 | 器物/局部 | 纪念碑体量 | 小尺度需要亲密的衬线与资料层；大体量才可能触发宽体、巨型结构字 |
| 几何锐度 | 有机/残损 | 中轴/硬边 | 有机形态适合随形、墨蚀、局部拼贴；硬边适合严网格、全幅标题和切窗 |
| 边缘密度 | 平静负空间 | 高频装饰 | 高频主体需要低频字体和简背景；平静主体才允许更复杂文字场 |
| 饱和度 | 灰褐/低彩 | 高彩/霓虹 | 低彩不必自动纸纹，可走摄影本位；高彩优先限色或从原生色抽取强调色 |
| 负空间 | 少 | 多 | 少负空间用遮挡、边缘资料或局部结构字；多负空间可承载大标题或正文场 |
| 拍摄时间 | 日间 | 夜间/暖光 | 夜间可走深底、发光边缘与低密度微字；不要把夜景都做成蓝紫渐变 |

字体选择必须写成因果句，例如：“低色温、木作近景、景深柔和，因此选择高反差宋/明体展示字与窄资料字”；不能只写“高级”“醒目”或“上次成功”。

## 受控标签

照片标签必须从 `token-system.md` 的词表中选，并优先使用可观察属性，不用自由同义词。脚本返回 `unmatched_tags` 时，先查 `design_tokens.py tags --search <词>`；不要让零命中候选按字母序伪装成推荐。
