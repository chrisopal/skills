# 地点检索、事实卡与建筑注释

当用户给出建筑名、城市、街区或地址时，默认先检索，再决定海报里的文字。检索不是为了写一段百科，而是为了找到能够压缩成短词、建立地点语境并参与排版的信息；只有解释注释模式才要求这些信息与具体构件建立指向关系。

## 1. 来源优先级

按以下顺序寻找并交叉核对：

1. 文物主管部门、政府、官方文旅、项目官网、博物馆或档案馆；
2. 建筑设计/修缮机构、学术论文、地方志和正式出版物；
3. 可靠新闻机构和地图服务；
4. 百科、游记和社交内容只作检索线索，不能单独支撑文保级别、年代、原真性或设计者等高风险断言。

同一名称可能对应多个地点。先用城市、街区、照片可见匾额和地图位置消歧，再记录事实。无法消歧时请用户确认，不要混用资料。

## 2. 四类信息边界

建立事实卡时，每条内容必须标记为以下四类之一：

| 类型 | 定义 | 可否进入海报 |
| --- | --- | --- |
| `VERIFIED` | 有可靠来源直接支持 | 可以，保留来源链接 |
| `OBSERVED` | 从用户照片直接看见，如斗拱、匾额字样、屋脊兽 | 可以，但写成“照片观察”，不把外观推断成年代 |
| `USER-CONFIRMED` | 用户明确提供的名称、地点、拍摄语境 | 可以，必要时标注为用户信息 |
| `UNCONFIRMED` | 传说、旅游文案、单一低可信来源或由外观猜测 | 不进入海报，只保留在待核实列表 |

当代复建、迁建、修复和历史遗存必须区分。`始建于明代` 与 `现存建筑为当代复建` 可以同时成立，但不能缩写成会让人误解现存木构年代的 `明代古楼`。

## 3. 事实卡字段

```text
标准名称：
名称消歧：
地址/路口：
城市空间角色：
始建/重要年代：
现存状态：原存 / 修复 / 迁建 / 复建 / 当代新建
建筑类型与屋顶形制：
可见构件：
可见匾额/题字：
工艺或结构：
历史价值/保护身份：
用户提供信息：
待核实或禁用信息：
来源与访问日期：
```

地址优先压缩为 `街道 × 街道`、`街区 · 方位` 或 `景区 · 节点`，不要在主画面放完整导航地址。精确门牌和坐标只在旅行记录确有价值时进入资料栏。

## 4. 从事实卡编译成文案

每张单体建筑海报建议只保留 4–7 个信息单元：

- 1 个主标题：建筑标准名称；
- 1 个地点标签：城市/街区/路口；
- 1 个时间关系：例如 `明代始建 · 当代复建`；
- 1–3 个构件或形制标签：例如 `斗拱`、`三层三檐`、`十字歇山顶`；
- 0–1 个可见题字或城市关系：例如 `匾额 / 四海升平`、`古城东部标志性节点`。

同一事实不要中英重复两遍再算两个信息单元。英文可以作为术语译名或索引，但必须真实：`斗拱 / DOUGONG` 有不同语言任务，`太平楼 / TAIPING TOWER` 则通常是一主一结构字。

长句先压缩成名词短语；只有无法压缩而又重要的事实才使用两行资料文字。图像模型对微型长文不稳定，宁可少写，也不要用假字填充。

主题文字是默认输出：将事实卡编译为 `1372`、`和阳 / 永泰 / 清远 / 武定`、`城楼 / 城垣 / 雉堞` 这类短词，不附编号、逐条定义、解释句或指向线。英文只在准确且能承担结构字、地点索引或节奏时使用，不为每个术语机械配译名。它们仍必须真实，但视觉任务是建立节奏、尺度和语境，而不是教学。

选词按以下优先级：标准名称与地点 > 关键年代或状态 > 与画面主体相关的建筑词 > 城市关系或旅行主题。每个词都要分配字体角色和栏位；如果只能被塞进角落成为孤立小字，就删除而不是缩小。

## 5. 解释注释模式：注释必须指向真实对象

只有用户明确要求科普、导览、教学或构件解析时才执行本节。主题文字模式跳过本节，并关闭编号、引线、箭头、端点和构件定义。

构件标签只有在照片中能找到明确目标时才使用。每条注释填写：

```text
标签：斗拱 / DOUGONG
依据：OBSERVED + VERIFIED（如有）
目标点：第二层檐下斗拱群
文字框：第 3–4 栏，基线 27–30
引线路由：从文字框右边缘进入专用沟槽，水平—垂直两段折线
终点：目标轮廓外缘，不盖住构件
禁穿区：主标题、结构字、匾额、屋脊兽
```

### 引线规则

- 默认使用水平/垂直折线；斜线只在它与屋檐或街巷的主导角度相同、且不会穿字时使用。
- 引线从文字框边缘或编号点出发，不从字形内部出发。
- 每条线只指向一个目标；终点使用小圆点、短横或 90° 端帽，不使用无含义的长线。
- 引线经过专用沟槽或留白通道。不能穿过任何可读文字、匾额、主屋脊、塔刹、人物面部或关键构件。
- 线与普通字形边界至少留 `0.5em`，与展示字至少留 `0.25` 个字高；若刻意穿字，必须先定义文字蒙版、前后层级和语义目的，否则判为失败。
- 线条密度不能超过画面可用负空间；单体海报通常 2–4 条足够。
